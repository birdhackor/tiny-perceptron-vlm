# 易懂教材的寫作與審閱

## 使用範圍與文件分工

本 skill 可用 `$clear-tutorial` 明確指定。先遵守使用者本輪指定的階段與範圍；只要求分析、討論或審閱時，不自行修改教材或啟動實驗。更新 skill 不代表已重寫或重新驗收教材。

主入口與配套 prompt 保存跨主題的教學準則，不放待審教材的逐句改寫、同款算例或預期問題答案。專案入口、技術事實與操作約定另放專案參考；已知問題與修正案例保存於審閱紀錄，不作首次閱讀提示。

- 作者使用本文件與[寫作短 prompt](references/writing-prompt.md)。
- 審閱協調者依[審閱流程](references/review-protocol.md)安排閱讀與證據檢查。
- 本 repo 的作者及技術審閱者另查[專案背景與技術核對](references/project-context.md)。首次閱讀者的背景由實際閱讀路線設定，不提前取得該文件中的技術解說或檢查答案。

## 核心標準

讀者在使用一個概念推理、解讀結果或遵循使用規則前，應知道它當下必要的意義。允許先提出問題，再立即解釋；不靠後文、程式、選讀或專家常識替前面的必要介紹補洞。

重要新概念或命名方法首次進入正文教學時，交代它是什麼、扮演什麼角色、與前文如何銜接及為什麼在這裡學。重要縮寫給出完整名稱、中文意義與當下夠用的解釋；完整名稱與上位類別定義不能代替方法介紹。前文已完整教過者可引用，不必每頁重講。

每小節聚焦一個主要學習問題。先引用原文的問題與主張，判此刻是導覽／預告、教操作或性質，還是解釋設計理由；依原句、題目與後續實際推理決定深度，不能只由頁名或現有算例決定。同段不同承諾分開驗：算出結果、說明某個特例，不自動完成採用理由。局部操作或性質通過後，回到最近尚未答完的原問題：此結果如何幫它得到所需答案或完成工作？指出已連起或尚缺部分；後續用途可待教，在該問題收束處重新驗收，不要求每段完成全書最終任務。使用者指定與當下核心目標不可縮掉；無關旁支可刪、改寫或移後，不必為每個形容詞擴寫一節。

介紹方法時，應說明它如何改變需要解決的問題，而不只展示新的運算形式。例子須足以呈現當前要教的關係；會算出結果與能解釋設計用意分開判斷，不以其中一項代替另一項。

技術正確、在此處有教學用途與證據足夠分開檢查。「更有彈性」「增加能力」「更好」等概括不能單獨交代理由。準確的限定句也要回應當下理解需要；例子可用來解釋機制，不自動證明實際效果。

## 讀者背景與概念依賴

以使用者指定與教材已公布的入口為準，區分必要先備、較有幫助的經驗及本節負責教的內容。不得默默提高入口門檻，也不能假定讀者已懂教材正要教的知識。

順序讀者可使用前文實際教過的概念；「聽過」「提過名稱」「看過程式」不等於理解機制，也不把曾學過數學當成能立即熟用。前文選讀不自動算所有人的先備。跳讀路線另記其必要背景，不要求每節假設零背景。

寫作前列一份簡短安排，可與章節規劃合併，不要求放入學生正文：

| 必要概念或方法 | 第一次需要它的位置 | 先備及實際已教位置 | 本文的解釋位置 | 讀完能解釋或預測什麼 |
| --- | --- | --- | --- | --- |

按實際依賴建立，不以標題、粗體或名詞清單當作覆蓋證據。對重要設計、規則、轉換與限定，指出「此處要能理解或判斷什麼，必要前提在哪裡」。包含尚未命名的方法、介面約定、編號對應、狀態如何改變及動作的開始與結束；它們可能沒有正式概念名稱。規劃不提前交給首次閱讀者。

## 寫作流程

1. 確認讀者背景、必要概念順序及主要學習問題。不能縮小名義上的目標以迴避實際需要的先備；內容包含不同學習問題時，拆節或交代過渡。
2. 從讀者能理解的任務與材料開始，交代答案的含義，再引入表示、編號、公式或程式。需要看見素材才能理解時，展示實際素材或明確標示的示意。
3. 沿用例子與名稱，每一步增加一個主要變化。換資料、任務、模型、維度、表示或評分方式時，說清楚為什麼換、保留什麼及現在的新問題。
4. 讓正文形成「問題 → 材料與答案 → 做法 → 可觀察結果 → 原因」的連續關係。依教學目的調整敘述，不把每節套成固定欄位表。
5. 在首次需要處建立概念與方法的基本角色，再解釋操作。依已讀材料辨認最可能衍生的疑問與混淆，說清楚相關概念的差別和本次選擇，不必窮舉替代方法。公式交代符號、軸、單位與足夠的直覺；譬喻對應回實際機制，必要的意義不能只留在譬喻裡。
6. 按下方準則選擇例子、比較、限定與圖解。簡化例子說明省略什麼、哪些關係保留及怎麼連回一般方法；「簡化版」標記不能代替這個連結。
7. 解讀結果與失敗。紀錄連結、指令或得分表只能補充查證，不能代替任務、設計與結論的說明。保留影響理解或限制結論的失敗；開發試錯歷史依教學用途取捨。

### 方法理由：說明問題如何被改變

先用不依賴所選方法名稱與算出結果的說法，指出希望得到的答案、保留的性質或完成的工作，且能判斷是否符合。保持這項需要不變，再連起「原做法的工作 → 新設計改變什麼 → 為何有幫助」。若需要只是「得到新做法產生的性質」，還沒有解釋該性質何以有用。純粹教數學性質不必另編應用，但應用教材原本用來回答方法理由的算例不能縮成只教性質。理由可以來自不同方向，不要求舊法不可能完成：

| 引入理由 | 正文需要說清楚的關係 |
| --- | --- |
| 突破能力限制 | 原本能做什麼、哪種具體情況暴露限制、新機制如何回應及對任務的用途 |
| 改變表示或拆分工作 | 哪些關係被保留或轉成另一種表示、各部分現在處理什麼及這種安排如何利用問題的結構 |
| 利用已有資訊或結構 | 哪部分由既有結構直接提供、仍須處理什麼，以及省去或重新分配了什麼工作 |
| 降低成本、簡化使用或統一流程 | 減少哪種成本或操作、如何做到、適用條件及必要代價 |

這是辨認理由的方向，不是每節必填的四套模板。數學性質、運算規則與任務需求之間要有因果連結；展示新公式本身不能代替方法動機。

本節若承諾解釋設計用意，作者應主動指出原需要、讓關鍵作用可見的條件及其用途。一項成立的理由只完成它實際支持的作用；同段另有設計或用途時，須核對是否也已連起，不能把選出關鍵情況或判準全留給讀者。一般性因果文字、圖或由已教前提作出的短而有效推論即可，不要求多例或全面評測。改換已教的做法或實驗設定，仍需當下最低的選擇目的；不必教完整演算法不能反駁缺少基本選擇目的。若只選一組可完成示範的設定，就據實交代，不虛構舊法做不到。

### 例子：先確定要讓讀者看見什麼

先從本節承諾固定例子的教學目的，再決定材料是否足夠；檢查後不因材料不足而縮小原目的：

| 教學目的 | 例子應讓讀者看見 |
| --- | --- |
| 認識操作 | 輸入、步驟與輸出的對應 |
| 理解共同規則或模式 | 足夠的變化及其中保持的關係，並指出這個關係為何重要 |
| 理解設計用意或方法差異 | 可比較的條件、新舊做法各負責什麼、差異從何而來及如何回應當前問題 |
| 支持實際效果結論 | 對應主張的觀察、比較條件、判準與證據範圍 |

操作算例若只展示一組輸入輸出，可能足以教步驟；若目的在於共同規則或設計優勢，應檢查它是否足以揭示相關結構。可以增加有意義的變化、對照、圖解或文字推理，不硬性規定每個例子都用兩組數字，也不以增加數量代替指出關係。

涉及分工、重用或設計差異時，指出例子中哪部分實際利用了已有資訊、共同關係或分配後的工作，如何滿足同一需要。某部分未運作或某種需求未發生，仍可充分教那個情況；不能包辦未被呈現的更廣用途。輸入範圍廣不等於工作情況全涵蓋。文字、圖或正常推論都可接起關係，不規定數字組數，也不只列結果讓讀者猜。

明確標為假設或手工示意的數字，可用來說明機制，不要求每個理想值都有實驗來源。只有作者把它當成實測、學習成果、代表性資料或效果證據時，才核對相應來源與支持範圍；仍應檢查假設與運算是否一致。

### 公平比較與結論邊界

比較時區分「原方法也能完成」與「新設計以不同方式安排這項工作」。不能為突出新設計，把原方法說成只能記住個別答案、不能利用共同規則或必然失敗，除非有對應條件與證據。

當好處來自表示、分工、重用或結構，直接說明它改變了哪些工作及何時有幫助。不要把結構上的便利改寫成訓練必然更容易、效果必然更好或所有情況都適用。

分開機制示意、可表示某結果、實際成功學習及對新資料有效。比較效果時交代重要設定差異；寫作上一次增加一個主要變化，不自動構成控制變因的實驗。

### 限定與例外的用途

新增限定、例外或防誤解句前，確認它回應哪個由已讀內容產生或可合理預見的疑問、避免什麼具體誤解及依賴什麼已教知識。

暫去掉限定，先查前文已排除什麼誤解，再保留該子句自己的主詞、對象與限制，說明它相對前文新增什麼。若回答只是重述上一主句，尚未解釋新增關係；技術正確或想得到一個可能用途，也不能代替已教依據。原文若能支持它與當下問題的短而有效連結，就通過。需補未教對應才看懂此處關係、造成歧義或打斷必要推理，才列必要負擔；單純冗餘可保留或列編輯改善，不因換對象、刪句仍懂或用途未逐字寫出就升級。陌生名稱不要求立刻教完整機制。

### 全書入口與階段動機

全書入口先用不依賴細節的短敘事建立大局觀：想解決什麼、曾遇到哪些困難、什麼改變了做法，以及後續需求如何引出本書路線。必要歷史服務於任務關係，不以模型名稱或目錄代替背景，也不要求每節重講歷史。

歷史與版本主張核對原始來源；區分較早已有的想法、關鍵突破及後來的應用。導覽或預告可先交代問題、基本角色及後面為何值得學，可靠結果依來源陳述，不要求入口推導全部成因。當下判斷、操作或機制已用到的細節才必須在此教；不能用導覽包住無用途限定。階段轉折交代已有什麼與新增需求。

### 正文與選讀

先做「只讀主文」檢查：不開選讀、附錄或外部連結，依已讀必要前文是否仍能理解概念、圖、理由與下一步推理？若必須靠那些內容才能回答，必要說明回到正文。

依理解用途分界，不以公式長度、技術深度或安裝細節一概判定。基本直覺、必要算例及圖解放在首次需要處，完整推導、進階變體與重做紀錄可補充。必要圖與文字相鄰；正常複習已教前文可連結，反覆跳轉以補當下缺口則記為負擔。選讀不一律搬入主文。

## 圖解、頁面與實驗

- 檢查讀者是否必須自行想像空間位置、素材差異、資料流、答案對應或前後變化。缺少必要圖也要報出，不只清點既有圖檔。
- 圖中箭頭、框線、顏色與編號有明確意義，文字指出要看哪裡；圖、圖說、公式、數字與程式遵守相同約定。當前理解或操作需要的對象能辨認與追蹤；換名或換表示時建立對應，分清類型標籤、不同對象與同一量的重用。標記、圖說、明確位置或正常推論可建立必要區別，不要求每框異字，也不只憑數值相等判為同一對象。
- 在實際頁面檢查桌面與手機的文字、圖、數學排版、折疊及切換。必要細節合理可讀，基本理解不依賴點擊放大；動畫靜止時保留關鍵資訊。
- 圖檔存在、原始碼正確或建置成功不能代替視覺驗證。未看實際頁面時，明記未驗證版面與閱讀路徑。
- 實驗交代任務、輸入、答案規則、真正改變或更新的部分、評估材料與判定方式。分清手工算例、資料整理、梯度檢查、參數更新及訓練後評測。
- 涉及學習時，分開訓練材料、訓練後成果與使用時的輸入輸出；一般概念不強求訓練成果。
- 得分交代分母、判準與重要失敗。正常結束、資料增加、訓練損失降低與泛化能力各需要不同證據。
- 實測數字回查指定版本來源與紀錄；只為疑點做相稱的執行檢查，不因文句問題重跑全套訓練。

## 審閱與修正

依[審閱流程](references/review-protocol.md)分開保存三類證據：

1. **首次閱讀：**凍結版本，逐段提供正文及原位置的必要圖，每個必要新概念有首次使用檢查點。審閱者先保存自己的理解、引文、猜測、回讀及缺圖，才取得下一段。先完成本輪正文範圍，再補讀選讀，保留早期判斷。
2. **技術與證據：**在首讀紀錄保存後，核對實作、圖、數字、比較條件與原始來源。技術解答不能回寫成首次讀者當時已理解。
3. **前後銜接與頁面：**檢查相關前文、本節及範圍內的下一步，確認依賴、階段動機、例子與表示轉換；另看實際圖文位置、折疊、跳轉及累積負擔。

只審閱凍結稿時，三輪可核對同一版本，不先修改教材。已授權修正時，修後再複查受影響的閱讀單位、圖與過渡；不把局部複查說成全書驗收。

### 主要概念的四題檢查

在每個必要新概念首次用於機制、推理、使用規則或實作時，以及小節末，用自己的話回答：

1. 它是什麼、扮演什麼角色，與前文有什麼關係？
2. 為什麼在這裡教它？分別判「機制／性質」與「需要／用途」，不合併通過。
3. 如何使用？需要什麼、得到什麼及結果供後續如何使用？
4. 例子、圖表或推導呈現什麼關係，支持什麼理解或結論，哪些還不能推出？

首次使用分概念檢查，小節末連成整體；同段不同設計或動作不能只用整體流程的一份答案蓋過。四題不可互相代答：說明目的，不等於交代身分與操作。新動作若已用來解釋當前數字、流程或狀態，須能由已讀材料說出對什麼做什麼，以及解釋所用到的變化；不能只把名稱換成「先執行」就判足夠，也不要求完整實作。先提問、隨即解釋是合理安排。

涉及圖解時，第一、三、四題的依據須能定位當前必要的圖文對應；具體指認與追蹤依[審閱流程](references/review-protocol.md#圖與實際頁面)執行。能推得與辨認負擔分開判斷，不以數字正確或整體可懂代答。

**第二題分兩項保存答案與判定。**「機制／性質」回答新做法改變什麼、來源支持到哪裡；「需要／用途」回答原文或使用者要求的哪個目標、條件用得到這個改變，附需要的來源及連到用途的最短已教推論。各自記依據與足夠性；前項通過不能代答後項。需要若由審閱者從新做法產物反推，且沒有獨立原需求依據，標為自補；來源已給需要，正常推論可通過。純性質教學可將用途記為不適用；合理待教須記承接位置。原承諾已到驗收點而連結仍缺，才列待修。

**理由與例子分開核對。** 第四題查材料實際支持的關係，再對照原承諾。局部操作、特例或一項理由通過，保留其效力；其餘必要承諾仍缺，另記缺少與影響。分開記理解可達、作者呈現及必要性；能自行補出不等於作者已教，可以寫得更鮮明也不等於缺漏。

核心主張逐項附當下已讀的原文或圖中依據，區分「正文明說／導覽或前文已教／由已讀內容推得／目前不知道」。**出處與解釋充分性分開判。** 原文說「更快」「更有能力」只證明作者提出主張；判理由足夠時，須由已讀材料接起什麼需要、設計改變及其用途，不能重述主張充當理由。

合理推得要留下最短必要推論：已教前提如何得到當前結論，關鍵一步是否另用了未教領域事實或任意約定。若兩種不同規則都符合展示的例子，卻會使當前操作或解讀不同，例子尚未交代應採哪種規則。已教規則的直接應用可通過，不因省略完整證明就報缺。

重要新方法以同一份四題證據核對身分、設計理由、例子與方法的關係，不另抄表格。逐項判「已足夠／需補說明／合理待教／未驗證」：足夠須有對應當下目的的證據；待教須說明目前的解釋、判斷或操作不依賴它。已用於必要推理或使用規則的基本意義不可待教，完整內部推導可以。尚未判清影響時記未驗證，不計通過，也不自動升成缺陷。後文釐清追加位置，不改寫早期判斷；但未知的最終必要性按第一次真正需要的時點及有效推論重新判定，保存觀察不等於凍結嚴重程度。

依內容查證：一般概念不強求訓練產物，沒有效果比較主張不要求證明勝過其他方法；明確假設的機制示意不要求實測來源。未看的圖或未做的執行檢查記未驗證。

### 理解理由、覆蓋與通過門檻

對主要例子的核心關係，用已教範圍內的有意義小變化檢查預測與理由；不為每個數字另出題，也不偷渡未教變體。沿用原學習問題與承諾，在既有依據欄分清規則來源與需要來源：來源已給什麼目標、條件與理由，題目由誰另加了什麼需求、比較情境或用途？答對可證明能依已教規則遷移，不能把題目新增材料回算成作者原已呈現。撤去新增材料，來源若仍藉文字、圖或正常推論完成原問題就通過；自設題與新數值本身不是缺陷。再問：「只懂操作、不懂理由的人也能答對嗎？」若能，此題不能放行理由。小節末回收尚未答完的原問題；補教後答對屬修後證據。

正文首讀完成後，由銜接審閱者核對實際依賴覆蓋，並覆核主要方法的「已足夠」、涉及當下用途的「待教／可選／未知」及來源已使用卻未被讀者檢查的前提。查通過理由，不只查已報缺陷。主 Agent 另抽查未報問題的通過圖，親看原位圖文並核對必要對應的證據，保存覆核範圍；全部已報項的裁定不代替發現覆蓋。補查標明發現者、時點與當時可見資料，不算原讀者自行發現。

分開記名稱補充、概念介紹、理由、例子用途、時序、技術與證據問題，按實際影響分為「阻礙主要概念／增加理解負擔／選讀改善」。必要說明或圖缺漏，或仍需猜測、拼湊、回讀補足必要理解，即使屬增加理解負擔仍待修，不判首讀通過。正常複習不自動算缺漏；不影響主線者逐項記保留理由。

主 Agent 綜整時，逐項核對已報的必要問題與可選建議：來源支持它能讓目標讀者的哪項理解、判斷或操作更清楚？再權衡最小改動的收益、篇幅及新增先備，沿用處置欄記「採用／延後／保留原文／待查」與理由；同一缺口可合併。發現、必要性與處置分開保存，保留審閱者原分級與發現時點。可選不自動略過、升級或採用，也不自動表示應放選讀；必要缺口未修仍列待修。泛泛要求更多細節、未核實推測或主 Agent 事後補出的好處，不能代替具體理解收益。

若已授權獨立審閱，各類審閱由不同審閱者負責，技術與銜接審閱者不參與撰寫。首次閱讀者從無作者歷史的上下文開始，不提前提供全文、作者摘要、概念清單、技術答案、已知問題或舊審閱結論。共用檔案系統不是真正隔離；意外先讀後文或對應答案，記錄其影響，不聲稱未提示首讀。沒有獨立審閱者時標作者自查。

各角色先保存自己的來源判斷，再互看閱讀答案及交叉覆核；不能將同意別人的發現算第二份獨立發現。保存交叉覆核後，協調者才與既有問題比對。記錄重現、新發現、可能漏項、舊問題不成立或需改分級；以來源與讀者理解判斷，不以命中已知答案的數量作唯一驗收。既有問題不是不可推翻的答案表，差異不得靠事後重寫原始紀錄消除。

原始紀錄包括版本、來源與圖的指紋、當時可見內容、四題焦點與引文、理解與問題、後文釐清及修後複查。保留原始判斷，依專案約定保存。AI 審閱是輔助，不等同實際目標讀者測試。

## 完成條件

- 入口與實際讀者背景一致，必要依賴、階段動機及表示轉換已銜接。
- 必要新概念的名稱、角色、當下意義與理由在首次需要時可理解。
- 方法理由說明需要、設計改變與用途，未以概括好處或運算形式代替。
- 例子足以呈現其教學目的；操作結果、共同關係、設計用意與效果證據分開判斷。
- 比較未歪曲其他方法的能力；結構便利、可表示、成功學習與泛化未混用。
- 限定與例外有當下用途；只讀主文可成立，必要圖文相鄰且實際可讀。
- 首次使用與小節末紀錄有逐項依據，覆蓋與理解理由已查；未用後文或課外常識改寫早期判斷。
- 必要問題已修正並複查，或在審閱任務中清楚列為待修；獨立觀察與舊問題比對分開保存。
- 已報的必要與可選建議都有主 Agent 的來源核對、理解收益與處置理由，不以原分級代替審理，也不要求一律擴寫。
- 只報告實際完成的工作、查證範圍與限制，不將 skill 更新說成教材已通過。
