# 依閱讀順序審閱教材

## 目的與範圍

熟悉技術的人可以讀完整節後重建作者意圖，仍可能漏掉初學者在中途需要的說明。術語有定義、算例正確、程式能跑與圖檔存在，都不能單獨證明首次閱讀順暢。

依 [SKILL.md](../SKILL.md) 保存「第一次讀到這裡的理解」，再開放後文。使用者只要求審閱時，核對凍結稿而不修改；已授權修正時，再另存修後複查，不用後文或修正答案改寫早期紀錄。

## 審閱前準備

1. 指定工作範圍、目標讀者、必要先備及實際閱讀路線。不把較有幫助的經驗當成必要背景，不默默提高入口門檻。
2. 凍結版本，保存來源與圖的指紋、正文／選讀分界及必要前文。按有意義的單位拆開，不截斷一句或拆散必要圖說；保留圖的原位置與折疊狀態。
3. 協調者保留全文及概念安排。首次閱讀者每次只取得當前正文單位和已讀前文，不提前取得選讀以補洞，也不取得作者目標摘要、概念清單、舊問題、同款正誤例、技術答案或預期結論。
4. 保留必要圖在原稿中的位置；不能把頁尾圖提早搬進閱讀包，讓缺圖問題消失。圖本就相鄰時，與說明一起提供。
5. 每個必要新概念首次用於機制、推理、規則或實作時設檢查點，小節末再檢查整體；同一單位多個必要概念分別記理解，不以流程的一份答案涵蓋全部。
6. 銜接審閱者自行從正文建立實際依賴：在重要設計、規則、轉換與限定處記「此處要能理解／判斷什麼，必要前提在哪裡」。包含未命名的方法、介面約定、編號、狀態變化及動作界線；標題與名詞清單只能定位，不能證明覆蓋。清單不提前交讀者。
7. 若已授權獨立審閱，各類審閱由不同審閱者負責，技術與銜接審閱者不參與撰寫。使用 subagent 時，首次閱讀者從無作者歷史的上下文開始，提供通用判準、讀者背景及當前閱讀包，要求不搜尋未讀內容或外部解答。共用檔案系統不是真正隔離；提前看過全文或對應答案者記錄影響，不聲稱未提示首讀。沒有獨立審閱者則標作者自查。

順序讀者可使用實際已教的必要前文，不把名稱出現當成機制已教。選讀不自動算先備；跳讀路線另開紀錄，明列必要背景。局部審閱沒有首次使用處的紀錄，就不宣稱驗證過介紹時序。

## 第一輪：逐段正文首讀

取得下一段前，用自己的話保存：

- 現在在做什麼，為什麼要做。
- 輸入、答案、編號、符號、圖中元素與箭頭代表什麼。
- 下一步預期改變什麼，當下有哪些原句或圖支持。
- 哪裡需要猜測、回讀、跳轉或課外知識；引用位置與原文。
- 尚未看見卻需要理解的素材、對應或圖解。
- 我能解釋設計用意與相關概念的差別，還是只能操作。
- 更換材料、任務、表示、維度、模型或評分方式的理由，及簡化例子與一般方法的關係。

閱讀程式前確認它要實現什麼、這段是操作示意、梯度檢查、參數更新或評測；程式後確認輸出意義及可支持的結論，不只復述形狀。

作者先提問、隨即解答是合理安排，不要求讀者未學先知。概念已被拿來推理或解釋規則而必要意義仍不清楚時，才具體列缺口。後文釐清追加位置，保留當時判斷。

### 先讀正文，再補選讀

完成本輪整段正文路線並保存判斷後，才補讀選讀、附錄或外部解釋，另記新增理解與是否應放回首次需要處。連結存在不等於說明已讀；必要圖在正文缺席時報出，不由協調者悄悄補上。

主文可用明確列為必要且實際已讀的前文，不以選讀替所有順序讀者補知識。讀者補讀後若繼續後續正文，明記這項先備差異，不能再稱純正文首讀。

### 四題與原句依據

每個必要新概念首次需要時及小節末，依 SKILL 四題檢查。先引用來源的學習問題、原句承諾與當下用途，判深度；同段不同承諾分開回答，不能以自訂短目的替代。局部操作或性質通過後，回收最近尚未答完的原問題，指出結果與所需答案／工作的連結或缺口。判純性質段時，交代它完成哪個子問題、上層用途在哪裡完成或為何仍可待教；在該原問題收束處重驗，不要求每段完成全書任務。導覽只需相稱的基本角色與路線。不同概念分判，方法總覽不由子步驟或上位類別代替；記錄沿用現有目的與依據欄，不增清單。

核心主張附當下已讀引文或具體圖中依據，區分正文明說、已教前文、合理推得與未知。**引文的出處不等於解釋充分。** 宣稱有能力或好處，只證明提出主張；理由須接起需要、設計改變與用途。合理推得保存最短必要推論；任意約定、未教領域知識及同例相容的不同規則不能默默補入。

以同一份證據判身分、理由與例子關係，沿用已教部分／缺少連結／實際影響，不增題目或表格。第二題依 SKILL 分存「機制／性質」與「需要／用途」兩項回答、來源及判定；不得只留一份整體通過。先對讀[校準例](calibration.md)中欠缺版與充分版：差別在哪一個必要關係，而非例子數量。套回來源時，將最強支持寫成有條件、有對象的完成範圍，再核對同一原承諾是否尚有未完成部分；不能只寫有合理理由便通過。理解已可達與作者呈現待修可以並存，但呈現缺口須有原句及實際影響。仍用已足夠／需補說明／合理待教／未驗證；純性質的用途可記不適用，待教須指出目前推理不依賴它及承接位置，未知不算通過也不自動算缺陷。

保存原始答案：

    小節／閱讀單位／首次需要或小節末：
    當時可見內容及實際已讀範圍：
    正文或補讀選讀路線／可用先備與位置：
    題號／焦點／自己的回答：
    核心主張逐項：主張／來源狀態／位置與引文／推論關係
    未知部分及當下是否需要／後來有效推論與最終分級：
    具體問題與影響（沒有則記無）：
    後來釐清的位置（追加，不改早期判斷）：

### 理由、例子與比較的核對

第二題先指出獨立於所選方法、能判符合與否的答案需要或工作，再保持需要不變，查「設計改變 → 為何有幫助」。不能讓新做法產生的性質反過來定義需要；純數學性質段不另編應用。理由不限於突破能力限制，也可能是轉換表示、拆分工作、利用已有結構或降低成本。涉及分工時，查明哪些已有部分被保留或直接提供、哪些仍需處理，及此安排如何回應問題；不要求先證明舊法做不到。

第四題按事先固定的教學目的查例子是否足夠。涉及分工或重用時，指出關鍵作用在例中是否實際發揮、覆蓋哪種工作情況、如何滿足同一需要。特例可充分教特例，不包辦未呈現的更廣用途；文字／圖／正常推論可以補足，不強制新增例數。分開判斷會算結果、看見共同關係、理解設計用意與支持實際效果；其中一項成立不能代替其他必要項。若原文宣稱例子說明優勢，讀者卻只能復述運算，列出缺少的關係及實際影響，不接受概括好處代替解釋。

例子需要呈現模式時，檢查是否有足夠變化、對照、圖解或文字推理及明確指出的共同關係；不以兩組數字作固定門檻。提出缺口時說明「目前目的需要讀者看見什麼，現有材料只能顯示什麼」，而非只要求多加例子。

公平核對新舊方法的角色，不因新設計方便而推定原方法只能記答案或無法利用共同規則。結構的幫助、可能的收益與已驗證效果分開記錄，檢查來源是否說清楚適用條件。

明確假設或手工示意的數字，可解釋機制；只核對一致性與結論邊界，不因沒有實驗來源而報缺。若來源把數字當成實測、學習成果或效果證據，再核對相應紀錄。不把合理簡化的每個數值都追問成實際標籤問題。

限定與例外先暫去掉，再查前文是否已排除它要防的具體誤解。換主詞／對象／層次的子句，指出相對前文新增什麼關係、此刻有何用途及已教依據。整段可懂不能替新關係放行；刪句仍懂也不自動等於必要缺陷。新增未教對應造成當下歧義、需讀者補足或打斷必要推理，才列必要負擔；單純冗餘可改而不自動升級，陌生名稱不要求完整機制。有效限定保留。

### 小變化與覆蓋查漏

對主要例子的核心關係，以已教範圍的小變化請讀者預測並說理由；可合併檢查點，不為每個數字另出題。記要驗的關係、題答、理由與依據，分清規則來源與需要來源：來源原有的目標／條件／用途，和題目新增的材料由誰提出？答對是遷移的正面證據，不把新增情境當作者既有材料。撤去它後，若來源仍以文字、圖或正常推論完成原問題便通過；自設題本身不構成缺陷。只懂操作者也能答對的題，不放行方法理由。對準因果或混淆，不偷渡未教規則。

題目需要的理由未教時列缺口；先補教再答對，只算修後證據。答對但理由來自課外知識，也不能算正文已教會。

各角色先保存自己的來源初判，才互看他人答案。正文首讀完成後，銜接角色對照實際依賴，覆核主要通過項、涉及當下用途的待教／可選／未知，以及未被檢查的前提。對關鍵通過項，直接比對原承諾與最強支持的範圍：同段不同設計是否各有理由，新動作的目的是否代答了最低操作，新增限定是否以本句對象得到解釋。只檢查來源實際提出或使用的關係，不補想更多承諾。反駁缺口時回應所缺的最小關係；不能拿不必完整演算法、全面評測或所有變體，代替回答它。來源已有正常推論便通過；不足仍保留已教部分。補查標明角色、時點與可見材料，不算原讀者自行發現，追加復述不清除原始斷點。

## 圖與實際頁面

即使沒有圖，也回答讀者是否必須自行想像素材、位置、資料流或答案對應，哪個問題需要圖解，以及文字是否已足夠。已有圖則查它是否呈現當前要教的關係，不能只是一張架構裝飾。

以實際頁面檢查桌面與手機，可採 1280×800 與 390×844 等合理尺寸，保存實際使用的尺寸與畫面。逐段首讀不展示尚未開放內容；整頁與版面檢查另記時點。

核對必要字、線、箭頭、圖說、公式與單位；基本理解不依賴放大，動畫靜止時保留關鍵資訊。檢查第一次需要說明的位置、圖文相鄰關係、折疊、浮動介面遮擋及跳轉。按實際閱讀任務評估；能多捲一下不會自動解除反覆遮擋必要文字的負擔。圖存在且字清楚不能代替位置與閱讀路徑檢查；未看實際頁面就標未驗證。

按原學習問題或當前操作，將必要對象對到可定位的圖中標記／位置，以及相應的正文名稱／符號，沿用第一、三、四題的依據保存。沿連接或跨表示追蹤何者沿用、改變或只是同類；只查當前需要的區別。相同對應規則可合併記錄，仍保留當前需要區分的對象。數值相同不能單獨證明同一對象，也不要求每個框都用不同字。

正常推得對應時保留最短依據，另判呈現負擔。報辨認負擔時，指出需回找的具體對應，或現有標示容許而影響當前理解／操作的另一種讀法，再說明具體影響。已觀察的回讀與依來源合理預見的困難分開記；未逐字命名不自動算缺漏，字清楚、運算正確或概括「圖文一致」也不能代替必要對應的核對。

正常複習前文與補當下缺口分開記，再評估多個小斷點的累積負擔。

## 第二輪：技術與證據

首讀紀錄保存後，技術審閱者查專案參考、實作與原始來源：

- 任務、答案、表示、圖與實驗設計是否一致。
- 程式真正做什麼、更新什麼；介面參數的約定、讀取／寫入／累積等狀態變化、動作與計量的界線是否已在使用前交代。分開手算、梯度檢查、參數更新與評測。
- 數字來源、版本、分母、判準、計時範圍與評估材料是否清楚。
- 比較是否存在重要設定差異、資料洩漏或其他混淆；因果與泛化主張是否有相應證據。
- 淺白敘事是否歪曲舊方法、誇大設計優勢或混淆可能能力與已證明效果。
- 名稱補充、概念缺口、時序負擔、技術錯誤與證據不足是否分開判斷。

逐項核對閱讀問題，保留原文已教部分，只指出仍缺的銜接；不把局部缺項擴大成完全未教。不確定的知識查原論文或官方文件，保存支持位置；只為疑點做相稱執行，不因文句問題重跑全套訓練。

只審凍結稿時保存本輪處置；修改獲授權且完成後，另核對修後版本。不提前把專案技術參考、實作或本輪解答給首次閱讀者。

## 第三輪：銜接與累積負擔

從相關前文讀到本節及範圍內的下一步，確認進入知識與學習結果、新概念依賴、例子到一般方法、表示與評分轉換及術語一致性。先走只讀正文的路線，再檢查選讀分界及實際圖文位置。

主 Agent 從未報問題的通過圖選樣，親看原位圖文，核對必要對應及其通過依據。依換名或換表示、重複標記、分流／合流等來源特徵選樣；這些特徵本身不構成缺陷，也不以技術難度或已報問題作唯一選樣方式。保存自己實看、依賴同行及未查的範圍；受使用者或同行具體問題提示後追加的發現，另記提示來源與時點。全部已報必要與可選項的裁定，不能代替這項來源覆核。

若修正改變教學目標或順序，回查受影響的前文與導覽；局部修正重查相關單位、圖與過渡，不盲目重做全書。範圍外的下一章不得自行擴大審閱；可檢查過渡是否交代下一步目的。

## 新判斷與舊問題分開

新一輪獨立審閱開始前，協調者保存已知問題及使用者澄清，不將它們混入通用準則或首次閱讀包。更換 skill 後先凍結該版本，避免途中補入待抓問題的解法。

各角色的來源初判先獨立封存，再保存未受舊清單提示的交叉覆核，最後由協調者比對舊紀錄。三種來源分開標記；只有互看發現前的初判能支持不同角色獨立重現。逐項記重現、新發現、可能漏項、舊問題不成立、來源已變或分級差異及理由。

舊問題清單可幫助查漏，但不是不可推翻的答案表；以來源、實際讀者理解與通用準則裁定。若比對後追加檢查，明標受舊問題提示，不改寫成自行發現。不得用命中數量作唯一驗收，也不得為消除差異事後修改原始首讀紀錄。

比較時分開報「已報且核實有助理解的發現覆蓋」與「審閱者列為必要的發現覆蓋」，並明列計分口徑。前者可納入主 Agent 核實的可選建議，但合格初判須已提出同一缺少關係與讀者影響，同一題只計一次；不能只因位置或名稱相近便配對。名稱補充可有自身價值，不代替不同的概念、理由或操作缺口。未知、泛泛補充、主 Agent 事後新增的問題、受提示同意或後見升級不得補算。改變口徑時另存重算與理由，保留原分數、原紀錄及原分級，不宣稱重新執行過獨立審閱。
