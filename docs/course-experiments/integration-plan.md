# 後訓練與整合專題：實驗、寫作與驗收順序

這輪補上訓練階段的理由、RLHF／PPO 的方法關係，以及一個共用語言底座的小助理。教學仍先用具體例子，再擴展方法；既有可跳讀的小實驗繼續保留。以下是工作計畫，未完成項目不構成結果或審閱通過紀錄。

## 新內容的閱讀位置

- 第 7 章：在讀過 7.11 的 SFT 實例後，讀 7.17 的預訓練／後訓練分工，以及 7.18 的三種學習訊號。既有小世界的額外文字更新不能證明產業配方的普遍因果效果。
- 第 13 章：保留先比較兩篇回答的起點，新增 13.10–13.17，逐步理解評分模型、回饋、PPO 的機率比例與 clipping、不同基準模型，以及 DPO 的另一條路。PPO 的實驗選擇有限候選回答，範圍與逐 token 語言模型分開說明。
- 第 19 章：先試成品，再追蹤同一個小 MoE 底座的資料、訓練、圖音入口、工具迴圈、偏好調整、效能與壓縮。主成品是受控小世界助理，能力由實際留出評測決定。

每件完成後先讀原始結果、修改對應教材，再進下一件。固定訓練配方後才作最後檢查；不使用測試集選步數或隱藏失敗。資料、圖片、聲音、問法與偏好對沿用可追溯的家族切分。工具的答案由計算器算出時，明確記錄模型產生的要求、程式執行與模型讀回的回答。

MoE 是本輪主要整合版本；總權重記憶體、每 token 啟用容量、路由成本與實際速度各自量測。Dense／MoE、PPO／DPO、PTQ／QAT 等按目的選擇，不能把所有方法當成必須串行的步驟。原有 30 組已完成實驗保留；只有新內容、必要回歸與整合部分需要新增運算。

## 費用與儲存

沿用 US$10 累計保留額上限、一次一件 GPU、每件 600 秒及零自動重試。2026-10-04 的既有公開保留紀錄為 US$8.22；首件預訓練完成後累計 US$8.44。尚未生成正式 test 回答時，資料檢查發現音訊留出題全為高音、1+2 未留出；因此保留舊實報與保留額，改用 `course-integration-v2` 重新固定家族切分，四站全部從頭接續，不混用兩版資料。六件新增 L4 工作與兩件 CPU 匯出按上限另保留 US$1.40，累計最多 US$9.84。新工作啟動前由既有 Modal 帳本核對可用額度。每個 L4 工作保守保留 US$0.22，公開匯出另使用原有 CPU 保留額。這是運算上限的保留紀錄，不是實際帳單。

完整訓練狀態沿用私有 Hugging Face 備份。學生版提供固定版本與 SHA-256 的推論必要檔案，剔除更新器、隨機狀態與參考模型。新資料以固定種子生成並保存 manifest；權重不寫進 Git。

## 依序審閱與閱讀時間

1. 完成實驗與作者修改後，派新的讀者逐節檢查理解、程式與數據對應；修正後回讀。
2. 再派另一批全新技術審閱者，按原始論文、官方文件、程式與完整實報核對；不以作者摘要代替來源。
3. 再派第三批從前置小節向後閱讀，核對新增內容的銜接與必要跳讀入口。
4. 上述內容完成後，另由多位 subagent 逐頁估計閱讀時間：以數學不錯的高中生或具基本數學能力的大學生為讀者，包含讀正文、圖解、程式與短暫思考，排除安裝、執行、下載、訓練與自行實作。保存每頁理由、時間範圍與完整教材總量。
5. 最後執行乾淨 Notebook、審閱指紋、網站與下載檢查，提交程式與教材、發布權重與網站，再實查公開入口。
