# B：從結構化回答到工具使用

當問題需要精確計算，模型可以先提出一張包含工具名稱與參數的請求單，再由本地程式真正運算。[B.1–B.4](0B.md#B.1)先從123乘45出發，檢查請求格式、執行與返回紀錄，再核對完成信號及步數上限。你會看到模型生成的文字、程式執行的結果與任務是否完成，各自需要留下什麼證據。

工具流程接通後，[B.5–B.7](0B.md#B.5)再把問題移到請求之前：面對自然語言提問，何時直接回答、何時用計算器、何時先求助？我們會訂策略、訓練一個小模型選動作，再用新數字組合與新問法檢查。[B.8](0B.md#B.8)最後用人工算例比較回答的可靠性與工具成本，說明要如何往依能力選擇的方向擴展。選對動作、工具真的執行與最後答對，會一路分開核對。
