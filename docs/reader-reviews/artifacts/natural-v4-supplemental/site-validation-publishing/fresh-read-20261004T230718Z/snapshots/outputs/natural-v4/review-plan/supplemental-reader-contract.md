# Independent whole-document readability contract

This file defines only the role, permitted tools and evidence fields for a future explicitly authorized whole-document assignment. It does not authorize dispatch, contain an expected verdict or claim that any document has been reviewed. The coordinator must provide the actual frozen file/page scope after root authorizes it.

Read as a mathematically capable high-school or college student with basic mathematics encountering this project for the first time. Read every assigned document completely in its actual order, including introduction, links, commands, tables, exercises and limitations. Follow only explicit prerequisites actually necessary for understanding; record each such read. Do not inspect old review conclusions, author reasoning or editorial checks. Do not spawn agents or edit product source, figures, code, checker rules, navigation, time records, Git or environment configuration.

Personally render and view every assigned and actually necessary SVG. Preserve exact source snapshots, original file/figure byte hashes, render commands/output and genuine view notes. Hashing or reading SVG XML is not a view. Use the existing environment for bounded offline CPU examples when useful, preserving predictions separately from actual outputs. Never run installation, data/model downloads, GPU work or long training under this reader assignment. Commands read but not executed must be identified honestly, including what inputs and expected outputs the reader can explain from the text.

When actual exported pages/navigation are explicitly included in the frozen scope, read and inspect those pages and follow the requested links personally. Record destinations, visible labels, headings and what the destination means. Existence checks do not prove that a destination teaches the named prerequisite. A source-only read cannot be reported as an actual exported-page inspection. Do not build or publish the site unless root explicitly authorizes that action separately.

Write your own supplemental report and evidence only in the assigned supplemental directory, not under an invented numbered lesson ID. Required contents:

- Actual full canonical reviewer task and fresh context; exact assigned scope and what was really inspected.
- For each complete document: repository-relative file, full-file raw UTF-8 SHA-256, preserved snapshot, actual read order, own summary and understanding assessment. For each inspected page: real page ID/path or public URL, actual retrieved/rendered evidence and provenance.
- Original SVG figure map, actual render/view receipts and necessary prerequisite source receipts.
- Your own explanation of the workflow, data/model count and roles, command inputs/outputs, symbols/numbers, exercise/check steps and any cross-document transition necessary to understanding.
- Your own background/link, terminology, example, program/command and exercise assessments; truthful not-applicable explanations where appropriate.
- Own pass or revise verdict, every blocker/nonblocking issue with concrete location and proposed correction, unresolved issues and scope limits. Do not copy prior verdicts or infer correctness from a successful link check.
- Genuine execution evidence and honest unexecuted-command limits; no benchmark replication or technical review claim based on readability.

Before replacing any prior supplemental report, preserve it unread. Before revising your own report, preserve your genuine previous report, source snapshots and evidence separately. Completely reread the revised assigned documents and affected necessary figures yourself; close issues in your own words. Reuse unchanged render/CPU evidence only after exact-byte comparison and actual renewed image viewing, without claiming rerender/rerun. Do not insert reading-time estimates: that stage comes after all readability, factual and continuity work.
