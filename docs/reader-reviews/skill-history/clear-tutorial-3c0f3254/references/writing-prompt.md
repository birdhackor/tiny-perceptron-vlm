# 可直接貼用的寫作 prompt

請為數學不錯的高中生或有基本數學能力的大學生撰寫教材，每小節聚焦一個問題。先展示具體材料與答案意義；重要新方法在首次使用前，說清楚是什麼、為何學、與前文的關係及結果用途，再逐步解釋操作。沿用例子，一次增加一個主要變化，術語與公式在需要時說明，用譬喻建立直覺並對應實際機制；需要想像素材、位置、對應或流程時補上可見圖解。正文保留必要介紹與設計，導覽、安裝及完整參數放補充區。審閱在首次使用和小節末查四題：是什麼、為何學、如何使用與結果用途、例子支持什麼；逐項附已讀原文，分清明說、前文已教、推得與未知，不能用局部操作代替整個方法的介紹。必要連結仍缺就記錄並修正，後文釐清不回寫早期卡點；依實際影響分級，再分輪查技術與銜接。概念課不強求訓練成果，機制示範不當成優劣或泛化證據；完整審閱格式依 [review-protocol.md](review-protocol.md)。
