# capstone-build 本人銜接閱讀摘要

本人是第三批全新獨立銜接讀者，按數學良好高中生／有基本但不熟數學的大學生的起點閱讀，沒有以repo作者背景补解釋。主分配37節全部本人完整讀；遇到必要前置回讀後返回原段，首遇18份章／附錄導言也完整讀。本輪沒有發現仍會阻住這条路線的具體卡點，結論為pass。

資料與訓練段先給我可追的約定：5.7分開推論權重與含更新器、亂數和排程的續訓快照；5.10分開更新、選設定和最後檢查；5.12分開整筆重複和同題家族；5.13分開示意預算與正式有效回答目標。後面19章沿用家族切分、固定資料版本與父檔案SHA，不需要把檔名相同當成同一模型。

對話路線先講角色與byte ID，再把shift、-100回答遮罩、因果可讀遮罩分開。中文一字常有多個byte，EOS也算有效回答目標；忽略問題位置loss不會從輸入刪掉問題。4章、暖身、1章與3章的明示背景讓我能跟上查表、軸、softmax與求導；7.11的直接SFT和先讀短文字再SFT是独立受控實驗，不是故事底座一路延長。

風格、缺資訊和安全部分把固定模板、資料規則、程式評分與真正模型生成分開。8.7可用相同內容、不同權重改偏好；9.4的授權小世界不能外推為完整安全判斷。19.5也明说成品的短答只是一種指定行為，文字驗證成功仍受固定問法與常數答案限制。

圖音路線先從畫素和振幅建立數字，再處理展開位置、對齊及真正看素材的證據。12.12的獨立模型要求形狀與音高，既報遮蔽也報按新真值核對的替換／成對結果；其兩條非零梯度只證明計算路線，沒有冒充已學會。19.6改用48項圖片摘要、16帶log-mel時間平均，各投影成一個前文位置，明確区别於10–12章的多向量展開；純音兩群約440／880Hz也区别於第12章300Hz界線。

MoE部分從独立參數、top-k選擇和加總走向負載與成本。total是全部需存的參數，active是每位置使用的結構代理，不能直接當實測FLOPs或記憶體。15章短FFN／完整更新與19.2同批前向＋反向不更新的量測範圍各自說明；19章另建的隨機Dense只比機制，沒有聲稱同品質，MoE當次較慢的結果也保留。

查資料與工具附錄能接到成品，但模型與協定没有被混成一條線。A章提示已有文件不等於模型永久記住，也不等於已正確使用。B.1–4是固定ASCII請求與實際工具迴圈；B.5–7另教自然語句選動作卡，明说還沒串回前面的JSON模型，新問法失敗保留；B.8是人工成本例。19.7改成緊湊TOOL字串，但仍分解析、allowlist、可用性、實際執行及同一模型第二次生成。

13章必要前置解釋chosen／rejected同題、回答sum log機率、固定reference與policy，以及負log sigmoid的可手算梯度。13.10是本輪首次讀，已讀到當前版本新增的exp／sigmoid與差0、差2換算；這是估計偏好勝出機率，不能當答對率。13.12分開每輪old policy與全程reference，13.14分開reward與critic，13.17圖與正文把PPO／DPO從同起點分叉，CPU有限選卡實驗不等於整個逐token語言模型或成品權重。

補完上述前置後，本人重新完整讀19導言與19.1–7。19.4給pretrain→SFT→joint，以及從joint接出的DPO分支和父子指紋；每站驗證先於最後考卷。推荐joint的75／84高於DPO的71／84，DPO仍保留文字卻讓聯合顏色退步，讀者可理解為何不能直接用最後更新的一版。19.3原圖固定答案基準和19.6換圖成對結果相接：形狀原圖0／9、換後9／9却成對0／9，不能說看懂形狀；顏色與音高在這個小世界有較明確的替換支持。19.7則保留工具12／12執行成功但讀回只有10／12，完整參數吻合含數字順序與EOS，不能簡稱數學能力。

本人只判斷分配與必要前置的易懂易學銜接，沒有閱讀別人的review、作者歷史或預期結論，沒有執行教材CPU實驗、GPU訓練、模型下載或重建環境。33張引用SVG本人完整讀XML，核對root現成render的SVG／PNG SHA後保存本人副本、receipt並逐一view_image實看。這是静態圖文閱讀，不表示動畫或GPU實機已測。首次11.4輸出曾被工具截短，已在下一回合完整重讀，read_sequence保留那次部分閱讀而不算完整。所有SHA均由本人實際讀的immutable snapshot計算。
