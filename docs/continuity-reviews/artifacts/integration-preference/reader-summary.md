# 本人第三批獨立銜接閱讀：preference

我以數學不錯的高中生／基本數學但不熟的大學生，從第7章導讀指向的7.11走入7.17–7.18。7.17用兩份材料與假設整理成本，解釋大量文字預訓練與後訓練的分工；它沒有把這個人工成本算例當成訓練實測。7.18先給示範、同題兩篇比較、作答後評分三張資料卡，再解釋SFT、DPO、RLHF、PPO和可驗證回饋，因而我不必先背縮寫才知道資料在教什麼。

第13章導言明示兩條路。我先讀13.1–13.2，再進13.10–13.15的有限選卡PPO路線。看到13.16與13.17的13.5前置後，我真的折返13.3–13.6，補了完整回答log分數、固定reference、相對margin、sigmoid代價和beta，再補7.13並回讀13.15–13.17。13.7–13.9把長度、附和及只教單一偏好的風險接回共同任務要求和分項驗收。這條路有超連結可走，沒有把PPO與DPO當成必須依序跑過的階段。

分數與機率能接順。13.10是先教獎勵模型把比較排對；13.11才談作答得到的reward、情境下的baseline以及兩者差advantage。13.12保存本輪取樣當時的old log機率作分母；13.13只讓沿有利方向改得夠多的那份舊評語暫停額外鼓勵；13.14另教critic並用固定reference檢查整段後訓練偏離。四個角色的圖讓我能分出評分、估計、記錄及固定尺。

DPO的比較是完整回答log機率差再扣參考差，沒有獨立評分員，卻仍用偏好標籤。相對改善、chosen勝過rejected、模型自行生成正確答案被逐一分開：例如13.5的6比7更常見仍可能自行生成8，13.6的候選與自由生成表也沒有混成一種成功。有限選卡148參數模型、241參數評分員、97參數critic與141,568參數語言模型各有明示範圍。

C.2用等式、接續與最後答案三種檢查說明驗證器只懂自己的窄規則；C.6再把整份文字的嚴格解析及真值比較轉成0/1回饋。它和7.18的程式驗算来源相接，也和13.16的獎勵漏洞相接。補讀C.7後，能把打分與改策略機率分開看：可驗證回饋是來源，PPO或REINFORCE是更新方法。C.6的24題×16次=384動作、C.2的360候選都不被當成不同新題數。
