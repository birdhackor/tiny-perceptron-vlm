## 5.5 怎麼獨立控制權重衰減？

如果訓練只追求眼前答案，某些權重可能越長越大。我們可以額外讓每步把權重稍微縮小，稱權重衰減（weight decay）。它像給放大的旋鈕一份輕微回拉，不表示把所有參數立刻清零，也不代替答案梯度。想要多強的回拉，應能和 [5.4](#5.4) 的Adam自適應縮放分開控制。

一種傳統做法是在代價加上權重平方的懲罰，叫L2懲罰；求導後會把與權重大小成比例的一項加進梯度。若接Adam，這個合併梯度還會進入m、v歷史再被縮放，回拉大小便受那些歷史影響。AdamW改用分開的規則：先將w乘 `1-ηλ`，再減去Adam方向的步子。η是學習率，λ是衰減強度，所以縮小幅度由它們直接決定。

```python
import torch
from torch import nn

w = nn.Parameter(torch.tensor([2.0]))
optimizer = torch.optim.AdamW([w], lr=0.1, weight_decay=0.2)
w.grad = torch.zeros_like(w)
optimizer.step()
print(w.detach())
assert torch.allclose(w.detach(), torch.tensor([1.96]))
```

輸入參數w=2，學習率0.1，衰減0.2。我們故意給任務梯度0，讓這次只觀察衰減。`torch.zeros_like(w)` 建立同形狀的零梯度tensor；`step()` 後w變 `2×(1-0.1×0.2)=1.96`。它沒有因為任務梯度為0就維持2，最後檢查可核對縮小量0.04。

這裡的0梯度和沒有梯度還不同。在本段PyTorch的AdamW實現裡，若 `.grad=None`，該參數本次會被跳過；若有一份零梯度，優化器知道它參與了這一輪，仍可應用衰減。不要把 [1.13](01.md#1.13) 清梯度的None與實際算出0梯度當同一狀態，它們會影響是否更新。

衰減不是讓loss一定下降的保證。某個大權重若真的對答案有用，縮小它可能讓任務loss暫時變高；我們採用它，是想控制複雜度與數值大小，再用驗證資料判斷是否對新題更好。驗證資料是沒有參與權重更新、用來比較設定的一組題目，與計算任務梯度的訓練題分開；選定衰減強度後，還要用另留的測試題做最後檢查，分組原則見[1.2](01.md#1.2)。衰減強度太大也可能讓模型學不動，所以報告實驗時要同時記錄學習率與weight_decay。

也不一定所有參數都衰減。[2.3的偏移bias](02.md#2.3)是不看輸入也會加在加權和上的數字；[4.3的正規化縮放](04.md#4.3)則在整理尺度後，替各特徵乘上可學習的倍率。模型有時把這些參數另分一組，設定不同的衰減強度，但選擇規則必須明確，不能看名字類似就預設所有實現一致。當前只有一格w，避免參數分組把一步算式遮住。

練習只把weight_decay改為0，先預測零任務梯度下w維持2，再跑核對，並將預期值改為2。接着保留衰減0.2、把 `w.grad` 改為None，觀察這份實現同樣不改w。兩次實驗各回答一個問題：衰減開沒開，以及參數有沒有進入本輪更新。
