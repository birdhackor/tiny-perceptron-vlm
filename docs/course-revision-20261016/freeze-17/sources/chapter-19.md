# 第 19 章：三個自行訓練的成品與 Auto 整合

前面學過文字模型、感知入口、機率判斷與循環深度。現在沿三條路線做可使用的成品：既有 MoE 多模態助理、Looped 文字解題器，以及 Jev 式機率判斷服務。本章依節號順讀：19.1–19.12完成既有助理的資料、訓練與驗收；19.13對照三個成品的用途，再由19.14–19.20讀共同資料、兩個新增產品與Auto整合。

第一條路使用已訓練並公開權重的 **V2 有限多模態助理**。文字核心、三個感知入口及它們的接頭，都由本專案從零訓練，沒有沿用既有預訓練神經權重；圖片、字型與錄音則取自明確列出的資料來源。先看它真正怎麼回答，再拆開模型、資料與訓練流程，最後在[19.12](19.md#19.12)核對整份考卷的能力與不足。另兩個成品也已完成GPU訓練與固定最後測試；從[19.13](19.md#19.13)看用途，再到19.20核對成績與失敗。第20章再把視野擴到成熟模型的應用。
