# 17.2：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 4

```python
import torch

x = torch.tensor([-0.7, 0.2, 0.7, 1.2])
scale = 0.5
q = (x / scale).round().clamp(-127, 127).to(torch.int8)
restored = q.float() * scale
print("整數格", q.tolist())
print("還原值", restored.tolist())
print("差值", (x - restored).round(decimals=4).tolist())
```
