# 3.5：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
import math
import torch

torch.manual_seed(42)
for d in [4, 64]:
    q = torch.randn(1000, d)
    k = torch.randn(1000, d)
    scores = (q * k).sum(dim=-1)
    scaled = scores / math.sqrt(d)
    print(d, scores.std().item(), scaled.std().item())
```
