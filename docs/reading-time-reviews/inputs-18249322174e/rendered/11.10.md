# 11.10：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
height = 16
text_tokens = 20
for patch_size in [8, 4, 2]:
    visual_tokens = (height // patch_size) ** 2
    total = text_tokens + visual_tokens
    print("邊長", patch_size, "視覺位置", visual_tokens, "總長度", total, "注意力格數", total**2)
```

```text
邊長 8 視覺位置 4 總長度 24 注意力格數 576
邊長 4 視覺位置 16 總長度 36 注意力格數 1296
邊長 2 視覺位置 64 總長度 84 注意力格數 7056

```
