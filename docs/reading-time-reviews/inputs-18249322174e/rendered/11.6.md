# 11.6：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
budget = 10000
plans = {
    "兩階段": {"描述對齊": 4000, "問答微調": 6000},
    "直接問答": {"描述對齊": 0, "問答微調": 10000},
}
for name, plan in plans.items():
    total = sum(plan.values())
    print(name, plan, "總有效位置", total, "符合預算", total == budget)
```

```text
兩階段 {'描述對齊': 4000, '問答微調': 6000} 總有效位置 10000 符合預算 True
直接問答 {'描述對齊': 0, '問答微調': 10000} 總有效位置 10000 符合預算 True

```
