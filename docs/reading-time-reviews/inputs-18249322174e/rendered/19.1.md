# 19.1：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
from tiny_perceptron.capstone import parse_action

examples = ["DIRECT:red", "ASK:請提供數量", "TOOL:calculator:1+2"]
for text in examples:
    action = parse_action({"raw": text, "eos": True})
    print(text, "→", action)
```

```text
DIRECT:red → {'status': 'direct', 'content': 'red'}
ASK:請提供數量 → {'status': 'ask', 'content': '請提供數量'}
TOOL:calculator:1+2 → {'status': 'tool', 'name': 'calculator', 'a': 1, 'b': 2}

```
