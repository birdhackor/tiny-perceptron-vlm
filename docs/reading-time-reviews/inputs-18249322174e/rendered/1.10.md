# 1.10：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
import torch

w = torch.tensor(3.0, requires_grad=True)
u = 2 * w
loss = u.square()
loss.backward()
print("中間值", u.item(), "代價", loss.item())
print("兩段敏感度", 2 * u.detach().item(), 2)
print("合成梯度", w.grad.item())
assert w.grad.item() == 24
```

```text
中間值 6.0 代價 36.0
兩段敏感度 12.0 2
合成梯度 24.0

```
