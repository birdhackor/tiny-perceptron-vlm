# 13.7：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
from tiny_perceptron.data import ByteTokenizer

tok = ByteTokenizer()
answers = ["4", "4。" * 8]
for answer in answers:
    body = tok.encode(answer)
    print("回答", answer, "正文位元組tokens", len(body), "含結束學習位置", len(body) + 1)
```

```text
回答 4 正文位元組tokens 1 含結束學習位置 2
回答 4。4。4。4。4。4。4。4。 正文位元組tokens 32 含結束學習位置 33

```
