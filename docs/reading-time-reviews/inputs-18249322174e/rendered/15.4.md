# 15.4：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
import torch

prob = torch.tensor([[0.1, 0.7, 0.2], [0.6, 0.3, 0.1]])
for k in (2, 1):
    weights, chosen = prob.topk(k, dim=-1)
    print("k", k, "expert索引", chosen.tolist())
    print("原比例", weights.tolist())
    print("保留比例總和", weights.sum(-1).tolist())
```
