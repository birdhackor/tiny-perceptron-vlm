# 4.2：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 4

```python
import torch

x = torch.tensor([1.0, 2.0], requires_grad=True)
correction = 2 * x
y = x + correction
y.sum().backward()
print("結果", y.detach())
print("對輸入的敏感度", x.grad)
assert torch.equal(x.grad, torch.tensor([3.0, 3.0]))
```
