# 6.1：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
texts = ["小小貓", "cat", "🙂"]
for text in texts:
    raw = text.encode("utf-8")
    print(text, "Unicode碼點", len(text), "UTF-8 bytes", len(raw))
```

```text
小小貓 Unicode碼點 3 UTF-8 bytes 9
cat Unicode碼點 3 UTF-8 bytes 3
🙂 Unicode碼點 1 UTF-8 bytes 4

```
