# 10.4：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
import torch

patches = torch.ones(1, 4, 3)
position = torch.arange(4.0)[None, :, None]
x = patches + position
print("形狀", tuple(x.shape))
print("位置0", x[0, 0].tolist())
print("位置3", x[0, 3].tolist())
print("仍相同", torch.equal(x[:, 0], x[:, 3]))
```

```text
形狀 (1, 4, 3)
位置0 [1.0, 1.0, 1.0]
位置3 [4.0, 4.0, 4.0]
仍相同 False
```
