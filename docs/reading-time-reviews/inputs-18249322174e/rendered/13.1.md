# 13.1：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
pair = {"prompt": "只回數字：2+2=?", "A": "4", "B": "4，就像兩雙筷子共有四根。"}
rule = "先正確，再遵循只回數字"
chosen = "A"
print("條件", pair["prompt"])
print("比較", pair["A"], "／", pair["B"])
print("理由", rule, "選擇", chosen)
```

```text
條件 只回數字：2+2=?
比較 4 ／ 4，就像兩雙筷子共有四根。
理由 先正確，再遵循只回數字 選擇 A

```
