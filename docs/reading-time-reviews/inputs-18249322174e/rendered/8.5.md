# 8.5：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
import json

answers = ['{"answer":4}', '答案是：{"answer":4}', '{"answer":5}']
for text in answers:
    try:
        value = json.loads(text)
        valid = isinstance(value, dict) and set(value) == {"answer"}
        correct = valid and value["answer"] == 4
    except json.JSONDecodeError:
        valid = correct = False
    print(text, "格式", valid, "內容", correct)
```

```text
{"answer":4} 格式 True 內容 True
答案是：{"answer":4} 格式 False 內容 False
{"answer":5} 格式 True 內容 False

```
