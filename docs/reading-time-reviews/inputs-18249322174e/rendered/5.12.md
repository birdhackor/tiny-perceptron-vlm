# 5.12：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
def grams(text, n=2):
    return {text[i : i + n] for i in range(len(text) - n + 1)}


a = grams("紅色圓形在左邊")
b = grams("紅色圓形在右邊")
common = a & b
all_parts = a | b
score = len(common) / len(all_parts)
print("共有片段", sorted(common))
print("共有數", len(common), "聯集數", len(all_parts), "相似度", score)
```

```text
共有片段 ['圓形', '形在', '紅色', '色圓']
共有數 4 聯集數 8 相似度 0.5

```
