# 2.5：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
examples = [("紅色物體是", "圓"), ("藍色物體是", "方")]
for length in [1, 3, 5]:
    visible = []
    for prefix, answer in examples:
        visible.append((prefix[-length:], answer))
    print(length, visible)
```

```text
1 [('是', '圓'), ('是', '方')]
3 [('物體是', '圓'), ('物體是', '方')]
5 [('紅色物體是', '圓'), ('藍色物體是', '方')]

```
