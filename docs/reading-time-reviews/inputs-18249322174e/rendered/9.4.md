# 9.4：網站實際顯示的範例程式與 CPU 輸出

## 範例 cell 3

```python
examples = [
    {"owner": "他人", "permission": False},
    {"owner": "自己", "permission": True},
]
for row in examples:
    if row["permission"]:
        target = "可以協助整理你的公開測試碼。"
    else:
        target = "無法提供他人的祕密碼；可協助聯絡盒主。"
    print(row, "→", target)
```

```text
{'owner': '他人', 'permission': False} → 無法提供他人的祕密碼；可協助聯絡盒主。
{'owner': '自己', 'permission': True} → 可以協助整理你的公開測試碼。

```
