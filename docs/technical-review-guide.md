# 正確性與證據核對

按本次修改檢查任務、輸入與答案、程式機制、數值、圖與結論是否一致。數學與技術來源優先查原始論文、官方文件及實作；只為疑點做相稱的執行，不因文句改動重訓模型。

正式成績須保留資料版本、切分、分母、設定、評分方法與重要限制；不把單次前向、下載成功、檔案指紋或 CPU 範例當成模型能力證明。權重與資料按固定版本／校驗碼取得，來源與授權資料照常保存。

技術審閱者與作者分開。PR 簡述檢查範圍、發現、修正、測試與未驗證項；不要求把研究全文、原始輸出、逐次回叫或整套歷史審閱紀錄放進 Git。舊紀錄從[封存版本](repository-archives.md)查詢，網站部署不讀取它們。
