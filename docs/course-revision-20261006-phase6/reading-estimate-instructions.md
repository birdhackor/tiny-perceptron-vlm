# 本輪逐頁閱讀時間估計

這份方法供內容、正確性及銜接修正完成後的新讀者使用。方法準備不表示估計工作已開始。

以數學不錯的高中生，或具基本數學但不熟機器學習的大學生為對象，以本教材暖身所教的 Python 用法為基礎。各頁假定讀者沿該頁指定路線，已理解先前內容；前文的閱讀時間不重複計入。每個指定 canonical 頁面須實際閱讀凍結原始正文、實際查看必要圖解，並閱讀範例程式及已執行 Notebook 中與範例配對的真輸出。正文頁、獨立章導言、整份入門／參考文件是不同單位；只按派發的 canonical ID 計算，不把導覽或索引重複算進去。

讀每頁後由本人判斷分鐘上下限與具體理由，包含閱讀、看圖、理解程式／輸出及停下思考。不包含安裝、下載、操作練習、訓練等待、額外回讀未分派前置的時間。這是 AI 估計，不是人類計時實驗；實際花幾秒讀完不代表模擬讀者也只需幾秒。

不讀舊 reading-times.json，不讀其他審閱者或作者的估計，不使用字數、行數、字速公式、自動頁面分類或腳本代填分鐘與理由。腳本只能列清單、凍結版本、核對 SHA、渲染必要圖、記錄本人已作的逐頁判斷及加总。批次讀檔後必須確實讀其內容，不能只取標題或計數就聲稱完成。

每一頁的原文與實際引用圖的 SHA 來自派发的 inventory。輸出 JSON：schema_version=1，estimate_kind="ai_estimate"，pages 陣列；每筆包含 page_id、minutes_min、minutes_max、reviewer_task、reason、source_sha256、figures_sha256。分钟是正整數，下限不得大於上限；無圖時 figures_sha256 是空 map。reason 是本頁具體的理解負擔，例如哪個例子、程式、圖或算式需要停下來理解，不能所有頁同一句。

另保存實際閱讀順序的逐頁 trace，包括來源版本、必要圖實際查看紀錄、已執行 Notebook 的對應輸出檔及本人本頁摘要。圖可在同一位讀者的範圍內只實際看一次，再在重用頁引用該查看紀錄；不能拿 SVG 原始文字或其他人的圖片檢查當成本人看圖。來源或必要圖變動時，原估時者實讀新版本後再更新自己那頁判斷；協調者不得只替換 hash。

只写本人被分派的估計／trace，不改教材、圖、全站 metadata 或他人的報告。全部指定頁實讀完成且每頁有本人判斷後，才報告完成。未讀／未看／未核對的范围必須明列；不得給未檢查的範圍 pass。估計工具的 validate 通過只證明版本和範圍一致。
