# 第 6 章：自己的中英文 tokenizer

「小小貓」是幾個字、幾個 byte，又是模型的幾個 token？本章從看得見的文字一路追到模型收到的 ID：先數字元與 byte，合併一次常見片段，再訓練一個能還原沒見過文字的 BPE。接著看字表大小的取捨、換了 tokenizer 之後怎麼在同一份原文上比較模型、特殊 token 怎麼和普通文字分開、半個字怎麼處理，再分清訓練視窗與讀檔分段。最後問一個研究問題：分塊邊界能否配合預測任務，甚至和語言模型一起學？從預先建立的字表到模型內部的區塊，都是在安排每個位置要處理原文的哪一部分。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
