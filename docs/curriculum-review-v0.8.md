# 大綱 v0.8：多角度審閱與取捨

日期：2026-10-01。四位 subagents 分別從初學者認知負荷、技術正確性／前置依賴、CPU 實驗／Notebook 可行性、課程範圍與使用者目標獨立審閱 v0.7。主代理綜合判斷後修訂；本輪沒有新增外部研究或執行模型訓練。

## 1. 判斷

大章順序基本合理。主要問題是「可跳讀」仍以整章路線呈現，讓比較、除錯與延伸看起來都要先讀完；另一問題是把程式接通和模型已具備任務能力混在一起。優先改善導航、首次成果與實驗契約，不擴充完整方法清單。

採用標準：能解除實際前置障礙、讓讀者更早看到可信成果、能在一個小實驗中觀察，而且不削弱使用者指定的個性／安全、Dense／MoE、量化／蒸餾。可用既有小節補例者，優先補例；新小節限於真正缺漏的概念。

## 3. 保留與暫緩

- **保留大章次序。** 字元 → MLP → Attention → Dense → SFT 的基礎，以及行為範例先於 DPO、Dense 先於 MoE、數值量化先於 kernel、教師答案先於 KL 的順序已有清楚依賴。
- **MoE 不必先讀完整現代 Dense。** 第 14 章的 RoPE／norm／activation 可獨立比較；第 15 章可以直接從初始 Dense FFN 出發。
- **CLIP、OCR、calibration、RAG／工具／推理保留支線。** 它們有價值，但不因公開課或社群提到就變成首次 VLM 先修。
- **自然語言的洞察與廣泛安全泛化留較大模型延伸。** 入門保留可訓練、可量的小世界行為；結果不外推為成熟模型能力。
- **GPU kernel、分散式訓練及更多研究方法暫不擴充。** 等讀者遇到瓶頸且已有前置，再進入原有延伸清單。

本輪新增兩個明確小節，其餘以導航、前置、對照與驗收修補為主。指定資產、Notebook、CPU 時間及模型能力仍待實作／量測。文件核對涵蓋連續編號、路線節號、相對連結與原有主題保留；沒有以文件檢查宣稱模型訓練已通過。

修訂後再由技術與範圍審閱者只讀複查。技術描述無必要修正；導航複查發現 6.7 的支線措辭與 byte-level 前置不一致，已統一；並收窄梯度補課建議的紀錄，避免誤含 autograd／step。
