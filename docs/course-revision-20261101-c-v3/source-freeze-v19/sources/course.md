# 小小感知機：從接話開始理解模型

輸入「今天天氣」，手機會提供幾種接法。程式怎麼猜下一個字？這套教材把問題縮到幾個字，讓你看見它如何整理例子、分配機率、衡量猜錯的代價，再修改自己的猜法。接著才逐步加入較長前文、對話、圖片、聲音與工具。

## R.1 先讀一節，不必先安裝

從[第一節：文字怎麼變成可還原的編號？](chapters/01.md#1.1)開始。材料是「貓看狗，狗看貓。」：先替字編號，再換回原句。你可以在紙上列字表，確認兩次「貓」使用相同編號，最後能還原原文。這件事弄清楚後，再看程式怎麼做。

理解需要的程式碼、關鍵輸出與解說直接放在正文，網站也提供CPU執行輸出，可以當書讀，不必先安裝或開Colab。想改數字再跑，才開同一節的Notebook（一份包含文字與可執行程式的文件），可在本機或Colab執行；Colab需要Google帳號，雲端執行尚未實測。操作見[W.1](first-steps.md#W.1)。

不熟 Python 時，先看[W.2 的清單與字典](first-steps.md#W.2)。遇到數字表的形狀，再看[W.3](first-steps.md#W.3)。數學暖身可以隨用隨查；正文會在需要時解釋術語，你不用先背一份名詞清單，忘了某個詞再查[名詞頁](glossary.md)。

第一節讀完，可以試著解釋：為什麼同一個字需要固定編號？編號和字的意義有什麼不同？說得出來，就已經完成這一小步。

## R.2 依你想理解的問題選路

第一次接觸語言模型，先沿第1–4章閱讀。前面材料中的「貓看」與「狗看」都以「看」結尾；只按上一字查表，兩者會得到同一組接字機率，前面的「貓／狗」無法參與判斷。這幾章改讓模型把前文變成可用的數字，再比較、讀取不同位置的線索，最後組成第一個Transformer；看過做法，再記零件組合的名字。

接續文章之後，還要用問答示範分清哪一段是提問、哪一段該回覆及何時停止。回覆要用來選服務時，還得判斷任務是否支援、資料是否足夠；線索若在圖片、聲音或某一時刻的畫面裡，則得保留內容和發生時間。更長的材料、多題重複讀取與要及早播放的聲音，又會增加重算、等待與記憶體需求，後面的架構、效率與壓縮便要解決「怎樣在有限資源內完成工作」。

之後照[下一節](#R.3)列出的主線順序往下讀。下表是想先弄懂某個問題、或讀完後回頭查時的起點；表中的名詞（例如 token、MTP、Auto、Jev、Looped）要到主線讀到那裡才解釋，現在看不懂沒關係。A、B 單元與第 20 章是延伸，可以按興趣選讀。

## R.4 理解零件，再驗收整合

一個只有幾個數字的小例子，能讓你追蹤每一步。例如查表得到向量，再把向量混合成下一字的分數。它的價值是把機制看清楚；真正訓練時，再用許多例子反覆更新，並留下不參與更新的題目檢查能力。

譬喻幫我們找到起點，實際數字讓譬喻落地。例如[暖身 W.5](first-steps.md#W.5) 把加權和比作飲料配方，實際計算仍是逐項相乘再加總；這類說法不代表模型像人一樣理解內容。每節會指出眼前結果能支持哪件事，讓你逐步學會判讀。

模型中會隨訓練調整的數字稱為參數（parameter）；習慣上也把整組參數叫權重，例如保存它們的「權重檔」。第19章的三個成品分別是產品A（MoE助理）、產品B（Looped解題器）與產品C（機率判斷器）；產品代號與A／B延伸單元、C必修單元的編號分開。三個成品都由本課從隨機的初始參數開始，用我們提供的資料訓練，沒有借用別人已訓練好的參數。三者任務不同，使用者依任務選用，見[19.13](chapters/19.md#19.13)；其中機率判斷器還能接到 Looped 解題器，先判斷題目是否支援、資訊是否齊全，再依規則選 Looped 解題器要跑的輪數，這個流程叫 Auto，見[19.17](chapters/19.md#19.17)。它們只會少數教過的題型，也各有沒做好的地方；MoE 助理的能力與限制見[19.12](chapters/19.md#19.12)，下載與重做見[19.11](chapters/19.md#19.11)；另外兩個成品的實測見[19.20](chapters/19.md#19.20)，下載與版本核對見[19.19](chapters/19.md#19.19)。第 20 章則練習接手 Qwen、Whisper 這類別人已訓練好的成熟模型，和自己從零訓練的成品分開驗收。

本輪在前面章節教候選變化、影音共同時間、聲音碼、共享材料與分塊輸出，再於[19.21–19.24](chapters/19.md#19.21)接到真正訓練與量測。產品A保留自家舊權重處理原任務，另訓練影音模組；有限聲音模組輸出音調與節奏，尚不涵蓋真人語音。十個正式訓練工作與固定最終測試已完成：影音與有限聲音通過事前主要門檻，波形互換仍有失敗；該批C-v2雖有共享計算的正確實作，候選判斷與接受風險未達標，保留為研究候選。後續[19.25](chapters/19.md#19.25)的C-v3改用明確裝置欄位、分筆記憶與新訓練資料覆蓋，完成獨立驗收，成為目前裝置決策的推薦成品；下載及三份CPU範例見[合格C-v3操作](../docs/decision-product/README.md)。它不替換原B的文字Auto effort。產品B不重訓，原能力邊界保留。完整結果與可操作權重見[新版模型操作](../docs/omni-products/README.md)，不以舊成功題代替新能力。

後面各章會教很多方法，它們各自回答不同問題，有些還可以互相替代。第一次完成小助理，不必把每個方法都套一次：先看任務需要什麼，再選架構、訓練訊號與交付方式。各局部實驗的操作見[操作頁](training.md)。
