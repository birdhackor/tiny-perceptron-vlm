## 19.21 新版助理怎樣學會對齊短片與聲音？

回到[12.17](12.md#12.17)的問題：短片在 2000 ms 從圓切成方，同一段聲音的發聲中心移到 1300／2300 ms，答案應各是圓／方。前面的解析規則能教我們查時間；現在要讓可調參數的影音分支從示範學出這個對應，並把自己的判斷交給對話與發聲流程。

這是助理產品 A 的**模組擴充**。舊 A 的自訓權重、tokenizer 與前處理版本固定，舊任務仍走原路。新增影格入口、局部聲音入口、時間表示、融合與有限答案 head（把特徵轉成類別分數的輸出層），都從隨機權重開始；不能把它說成原文字 LM 已重新預訓練或端到端學會影片理解。

圖中兩條新入口先保留局部觀測，再共同判斷。head 的三類是 `circle`／`square`／`unknown`，顯示為圓／方／不可判定。它的實際預測寫入唯一的 **canonical record**：後續共同使用的語義紀錄。正式包裝器回傳`answer`、`logits`與`source`；圖下方的「回傳紀錄」交給應用顯示或保存，Talker直接用同一個`answer`查音型字典。下面機制小例把這個欄位叫`semantic`，兩者都指三類head的判斷。`unknown`轉交，不把靜音當成答對形狀。

![固定舊A處理舊任務，新影音分支經局部入口、時間表示、融合與三類head，將同一語義紀錄交給對話和Talker](../figures/omni-19.21-av-module.svg)

輸入契約是最多四秒、16 張 `[1,32,32]` 灰階影格與 `frame_ms`，畫面保持到下一格／片尾。聲音是 16000 Hz 波形，另記 `audio_start_ms`、有效長度與模態是否存在。先用[12.17](12.md#12.17)的小例建立計算路徑：各 200 ms 獨立處理，將 16 個 mel 摘要與能量合成一條 17 維向量，再作可學投影。節末會列出正式訓練版：它保留每塊完整的 24×37 聲音特徵圖、用固定振幅尺度，不沿用此摘要及逐塊正規化。兩者的聲音入口都只能讀本塊；補零不擴大原始支持區間。

每 250 ms 取一格，與每 200 ms 切一個聲音塊，是兩種不同間隔。發聲塊索引 1 的中心可以是 1300 ms，不等於影格索引 1。沿用[14.19](14.md#14.19)，下面先換成 250 ms 一單位的物理座標，比較把時間特徵加進向量的 **additive embedding**，與用時間旋轉 Q、K 的 **time-RoPE**。這個 CPU 小例的兩版共享 12 維寬度、時間與頻率；正式六次訓練的兩版則共享 64 維寬度及每個 head 的同一組頻率，見節末。`index` 版只作 CPU「缺少物理時間」控制，不是另一組正式訓練。

下面的小例依「影片標記、影格、聲音標記、聲音塊、讀答案位置」排列。融合分兩層：第一層讓每個聲音 token 依自己的時間比對並讀入影格；第二層讓最後的讀出位置，讀到已含畫面資訊的聲音表示。這需要兩層各自的 Q、K、V 參數，而不是讀出位置只加權原始的聲音向量。每層還有殘差加法與逐位置的前饋網路，接續[4.5](04.md#4.5)的區塊。此小例用序列因果遮罩；正式版用前置讀出位置及雙向讀取，並非同一個遮罩。兩者都處理已取得的完整片段，不能稱為即時影片模型。

先拆開圖中的影格 CNN，看像素怎樣變成向量。`Conv2d(1,4,3,padding=1)` 的 1、4 是輸入、輸出通道數，3 是小窗邊長。每個輸出通道有自己的 3×3 權重：對窗內九個值逐項相乘、相加，再加偏置；同一組權重與偏置在所有位置及影格共用，形成一張特徵圖。四通道就是四張這樣的圖，不是四個顏色或形狀答案。小窗每次移一格；`padding=1` 在四邊各補一圈零，使 32×32 的每個位置都有輸出，大小仍是 32×32。這些零只處理邊界，不是新拍到的像素。

先用 4×4 數字表看共享小窗和兩種平均。下例的小窗只有中央權重 1、右鄰權重 2，其餘為零，偏置也為零；所以左上輸出是 `1×1+2×2=5`，右移一格仍用相同權重，變成 `2×1+3×2=8`。

```python
import torch
from torch.nn import functional as F

pixel_demo = torch.arange(1.0, 17.0).reshape(1, 1, 4, 4)
kernel_demo = torch.zeros(1, 1, 3, 3)  # 一個輸出通道、一個輸入通道、3×3 權重
kernel_demo[0, 0, 1, 1] = 1  # 中央
kernel_demo[0, 0, 1, 2] = 2  # 右鄰
response_demo = F.conv2d(pixel_demo, kernel_demo, padding=1)
local_demo = F.avg_pool2d(pixel_demo, 2)
global_demo = F.adaptive_avg_pool2d(pixel_demo, 1)
print("小窗第一列", response_demo[0, 0, 0].tolist())
print("2×2 平均", local_demo[0, 0].tolist())
print("整張平均", global_demo.item())
```

小窗第一列印 `[5,8,11,4]`：右邊界的 4 算的是 `4×1+0×2`，直接看見補零的作用。`AvgPool2d(2)` 每個通道各把不重疊的 2×2 區域加總除以 4，印 `[[3.5,5.5],[11.5,13.5]]`；例如左上是 `(1+2+5+6)/4=3.5`。它把高寬減半，仍留下四個區域，讓後面的卷積能在較小的格子圖上組合局部特徵。`AdaptiveAvgPool2d(1)` 則要求每通道最後只剩 1×1，本例把全部 16 個值平均成 `8.5`，不再保留四區的位置。兩種平均都沒有可學權重；真網路平均的是卷積與逐值 GELU 之後的特徵，這裡用整數表讓操作可手算。練習在 `local_demo` 前把 `pixel_demo[0,0,3,3]` 改成 32，先預測：只有右下的局部平均變成 `17.5`，整張平均則變成 `9.5`。

回到實際入口，第二個 `Conv2d(4,8,3,padding=1)` 每個輸出位置會讀四個輸入通道的 3×3 小窗，即 36 個值，加權成八個輸出通道；仍在所有位置共用同組參數。最後逐通道平均 16×16 的 256 個值，得到八種特徵的整張平均強弱，讓一張影格只佔一條向量。`Flatten` 只把八個 1×1 攤成八格；`Linear(8,12)` 再學十二組「八格加權和＋偏置」，接上融合所用的 12 維。令 `M=B×T`，表示先把一批的各影格當作獨立圖片計算；GELU 逐值運算，不改形狀：

| 操作 | 輸出形狀 |
| --- | --- |
| 原始影格 | `[M,1,32,32]` |
| 第一個卷積、GELU | `[M,4,32,32]` |
| 2×2 平均 | `[M,4,16,16]` |
| 第二個卷積、GELU | `[M,8,16,16]` |
| 每通道全圖平均 | `[M,8,1,1]` |
| Flatten、Linear | `[M,8]` → `[M,12]` |

以下 `TinyAV` 是完整 CPU 機制例，沒有載入舊 A 或正式新權重。為單獨檢查新計算，三筆材料的像素與局部聲音向量都由亂數製作；前兩筆只平移聲音支持區間，第三筆刪除聲音。它們沒有可靠的形狀答案，程式中的類別標籤只供檢查反向傳播。這裡不更新參數、不計答對率；正式模型的分工及訓練另列於節末。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1)
torch.manual_seed(7)


class FusionBlock(nn.Module):
    def __init__(self, width):
        super().__init__()
        self.norm_attention, self.norm_ff = nn.LayerNorm(width), nn.LayerNorm(width)
        self.q, self.k, self.v, self.out = [nn.Linear(width, width) for _ in range(4)]
        self.ff = nn.Sequential(nn.Linear(width, 2 * width), nn.GELU(), nn.Linear(2 * width, width))

    def forward(self, x, valid, positions, frequency, rotary):
        z = self.norm_attention(x)
        query, key, value = self.q(z), self.k(z), self.v(z)
        if rotary:
            angles = positions * frequency

            def rotate(vector):
                a, b = vector[..., 0::2], vector[..., 1::2]
                c, s = angles.cos(), angles.sin()
                return torch.stack([a * c - b * s, a * s + b * c], dim=-1).flatten(-2)

            query, key = rotate(query), rotate(key)
        length = x.shape[1]
        causal = torch.tril(torch.ones(length, length, dtype=torch.bool))
        allowed = causal[None] & valid[:, None, :]  # 每列只讀有效的過去 key
        scores = query @ key.transpose(-1, -2) / x.shape[-1] ** 0.5
        weights = scores.masked_fill(~allowed, -torch.inf).softmax(dim=-1)
        weights = weights * valid[:, :, None]
        x = (x + self.out(weights @ value)) * valid[..., None]
        x = (x + self.ff(self.norm_ff(x))) * valid[..., None]
        return x, weights


class TinyAV(nn.Module):
    def __init__(self, representation="time_rope"):
        super().__init__()
        if representation not in {"time_rope", "additive", "index"}:
            raise ValueError("位置表示須為 time_rope、additive 或 index")
        self.representation, self.width = representation, 12
        self.vision = nn.Sequential(
            nn.Conv2d(1, 4, 3, padding=1),
            nn.GELU(),
            nn.AvgPool2d(2),
            nn.Conv2d(4, 8, 3, padding=1),
            nn.GELU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(8, 12),
        )
        self.audio = nn.Linear(17, 12)
        self.kind = nn.Embedding(2, 12)  # 0 影格、1 聲音；不是答案類別
        self.markers = nn.Parameter(torch.randn(5, 12) * 0.02)
        self.layers = nn.ModuleList([FusionBlock(12) for _ in range(2)])  # 兩組獨立參數
        self.norm_out = nn.LayerNorm(12)
        self.head = nn.Linear(12, 3)
        self.register_buffer("frequency", 10000.0 ** (-torch.arange(0, 12, 2) / 12))

    def forward(self, images, frame_ms, audio_features, support, frame_valid, audio_valid, duration):
        if images.ndim != 5 or images.shape[2:] != (1, 32, 32):
            raise ValueError("需要 [B,T,1,32,32]")
        batch, frames = images.shape[:2]
        if audio_features.ndim != 3 or audio_features.shape[0] != batch or audio_features.shape[2] != 17:
            raise ValueError("聲音需要 [B,A,17] 局部向量")
        chunks = audio_features.shape[1]
        if not 1 <= frames <= 16 or not 1 <= chunks <= 20:
            raise ValueError("超出影格或 200 ms 區塊上限")
        if (
            frame_ms.shape != (batch, frames)
            or frame_valid.shape != frame_ms.shape
            or support.shape != (batch, chunks, 2)
            or audio_valid.shape != (batch, chunks)
            or duration.shape != (batch,)
        ):
            raise ValueError("時間、支持、mask 或片長形狀不符")
        if frame_valid.dtype != torch.bool or audio_valid.dtype != torch.bool:
            raise ValueError("mask 必須為布林值")
        if not all(torch.isfinite(t).all() for t in [images, frame_ms, audio_features, support, duration]):
            raise ValueError("拒絕非有限輸入")
        if not ((duration > 0) & (duration <= 4000)).all():
            raise ValueError("片長須在 0–4000 ms 內")
        for mask in [frame_valid, audio_valid]:
            if ((~mask[:, :-1]) & mask[:, 1:]).any():
                raise ValueError("有效內容在前，padding 在後")
        bad_frame = (frame_ms < 0) | (frame_ms >= duration[:, None])
        bad_order = (frame_ms[:, 1:] <= frame_ms[:, :-1]) & frame_valid[:, 1:]
        if (bad_frame & frame_valid).any() or bad_order.any() or (frame_valid[:, 0] & (frame_ms[:, 0] != 0)).any():
            raise ValueError("影格須從 0 開始、嚴格遞增且在片內")
        start, end = support[..., 0], support[..., 1]
        bad_audio = (start < 0) | (end > duration[:, None]) | (end <= start) | (end - start > 200.0001)
        overlap = (start[:, 1:] < end[:, :-1]) & audio_valid[:, 1:]
        if (bad_audio & audio_valid).any() or overlap.any():
            raise ValueError("聲音支持須在片內、非重疊且最多 200 ms")

        image_x = self.vision(images.reshape(-1, 1, 32, 32)).reshape(batch, frames, 12)
        image_x = image_x + self.kind.weight[0]
        audio_x = self.audio(audio_features) + self.kind.weight[1]
        markers = self.markers[None].expand(batch, -1, -1)
        x = torch.cat([markers[:, 0:1], image_x, markers[:, 1:3], audio_x, markers[:, 3:5]], dim=1)
        ones = torch.ones(batch, 1, dtype=torch.bool)
        valid = torch.cat([ones, frame_valid, ones, ones, audio_valid, ones, ones], dim=1)
        zero = torch.zeros(batch, 1)
        anchor = support.mean(dim=-1)  # 用真實支持中點，不用 padding 後的長度
        physical_ms = torch.cat([zero, frame_ms, zero, zero, anchor, zero, zero], dim=1)
        length = x.shape[1]
        if self.representation != "index":
            # 六對分配 t,h,w,t,h,w；本例 h=w=0，只測時間部分。
            time_pairs = (torch.arange(6) % 3 == 0).float()
            positions = physical_ms[..., None] / 250.0 * time_pairs
        else:
            positions = torch.arange(length).float()[None, :, None].expand(batch, -1, 6)
        if self.representation == "additive":
            angles = positions * self.frequency
            # 同樣 12 格；cos-1 讓座標 0 的特徵為零，不另加固定偏移。
            x = x + torch.stack([angles.cos() - 1, angles.sin()], dim=-1).flatten(-2)
        layer_weights = []
        for layer in self.layers:
            x, weights = layer(x, valid, positions, self.frequency, rotary=self.representation != "additive")
            layer_weights.append(weights)  # 第二層讀的是第一層更新後的 x
        return self.head(self.norm_out(x[:, -1])), torch.stack(layer_weights, dim=1)


batch, frames, chunks = 3, 16, 4
images = torch.rand(1, frames, 1, 32, 32).expand(batch, -1, -1, -1, -1).clone()
audio_features = torch.randn(1, chunks, 17).expand(batch, -1, -1).clone()
frame_ms = (torch.arange(frames).float() * 250)[None].expand(batch, -1)
audio_start_ms = torch.tensor([1000.0, 2000.0, 1000.0])
starts = audio_start_ms[:, None] + torch.arange(chunks)[None] * 200
support = torch.stack([starts, starts + 200], dim=-1)
frame_valid = torch.ones(batch, frames, dtype=torch.bool)
audio_valid = torch.ones(batch, chunks, dtype=torch.bool)
audio_valid[2] = False
duration = torch.full((batch,), 4000.0)
args = [images, frame_ms, audio_features, support, frame_valid, audio_valid, duration]

model = TinyAV("time_rope").eval()
with torch.no_grad():
    visual_trace = images.reshape(-1, 1, 32, 32)
    for layer in model.vision:
        visual_trace = layer(visual_trace)
        print("影格入口", type(layer).__name__, tuple(visual_trace.shape))
logits, weights = model(*args)
print("三筆×三類分數／注意力形狀", tuple(logits.shape), tuple(weights.shape))
print("兩筆發聲塊中心", support.mean(-1)[:2, 1].tolist())
print(
    "第一層音訊讀影格／第二層讀出讀音訊",
    bool(weights[0, 0, 20, 1:17].sum() > 0),
    bool(weights[0, 1, 24, 19:23].sum() > 0),
)
additive_model = TinyAV("additive").eval()
additive_model.load_state_dict(model.state_dict())  # 同寬度、同權重，只換時間進入方式
additive_logits, _ = additive_model(*args)
print("additive 分數形狀", tuple(additive_logits.shape))
index_model = TinyAV("index").eval()
index_model.load_state_dict(model.state_dict())  # CPU 缺少物理時間的控制
index_logits, _ = index_model(*args)
print("序號版移時前後相同", torch.equal(index_logits[0], index_logits[1]))

# 遮住的聲音任意改值，第三筆的讀出仍應相同。
changed = audio_features.clone()
changed[2] += 1000
changed_logits, _ = model(images, frame_ms, changed, support, frame_valid, audio_valid, duration)
print("缺聲音內容被 mask 排除", torch.equal(logits[2], changed_logits[2]))
F.cross_entropy(logits, torch.tensor([0, 1, 2])).backward()  # 只檢查梯度，不做 optimizer.step()
print(
    "影格／聲音／兩層 attention／head 有梯度",
    [
        float(p.grad.norm()) > 0
        for p in [
            model.vision[0].weight,
            model.audio.weight,
            model.layers[0].q.weight,
            model.layers[1].q.weight,
            model.head.weight,
        ]
    ],
)

names = ["circle", "square", "unknown"]
display = {"circle": "圓", "square": "方", "unknown": "不可判定"}
semantic = names[int(logits[0].argmax())]
record = {"semantic": semantic, "display_text": display[semantic], "source": "random_cpu_reference", "trained": False}
dialogue = [{"role": "assistant", "semantic_result": dict(record), "content": record["display_text"]}]
talker_condition = record["semantic"] if semantic != "unknown" else None  # None 轉交
print("參考模型紀錄", record)
print("對話保留同一語義", dialogue[0]["semantic_result"]["semantic"] == record["semantic"])
```

前八行逐層列出影格入口形狀，與表中相同，只是這次 `M=3×16=48`；最後的 `(48,12)` 再排回 `(3,16,12)`，每格仍對應原來的一張影格。輸出分數形狀 `(3,3)`、注意力 `(3,2,25,25)`，第二軸是兩層；24 個觀測／界線位置後，新增索引 24 的讀出位置。發聲塊中心是 `[1300,2300]` ms。兩條跨模態讀取路徑都印 `True`，只說路徑已通，不表示注意力已對準正確影格。additive 版分數同為 `(3,3)`；它以 `[cosθ−1,sinθ]` 加入同樣 12 格，RoPE 則在各層旋轉 Q、K。序號版兩筆完全相同、遮住的聲音改值不影響第三筆，兩行都印 `True`；五組參數的梯度均非零。這些是計算檢查，不是解題成績。`record` 帶 `trained=False`，其 `semantic` 是隨機 head 輸出；對話與 Talker 仍沿用它，不能偷換老師答案。

真正訓練前，要把同一底層情境的移時、時長／間距、位置、振幅與刪線索變體歸為同一 **family**，整家族只進 train、dev、final 其中一份。移時配對固定 pixels、waveform、token 數與序列化，只改合法 `audio_start_ms`；發聲整段不跨形狀切換，中心離切換至少 125 ms。刪圖或刪聲的訓練目標是 `unknown`，不能沿用原形狀答案。正式入口還要重做窗外波形擾動檢查；本例的 feature mask 檢查不能代替波形局部性驗證。

下表是**事前驗收目標，尚非結果**：

| final 項目 | 固定分母與目標 |
| --- | --- |
| 主要移時配對 | 200 個家族各一個預指定配對；兩題都對才成功，至少 170／200＝85% |
| 四個時長×間距面板 | 各 50 家族，各至少 75%（整數計數至少 38／50） |
| 刪圖、刪聲診斷 | 各 200 題，各至少 180／200＝90% 回 `unknown` |

正式比較的 additive／time-RoPE 各用三個 seed（初始化亂數設定），共六次下游訓練；相同物理時間與容量下比較時間進入方式，只以 dev 選一個升版候選，所有六次都報告，不能看 final 換 seed。index 控制不增加正式訓練工作。同家族的其他題不增加獨立樣本數，共用同一舊 A 也不等於六次獨立預訓練。新版包裝與固定舊版還要逐舊任務比較 `correct/n`；任何主要舊任務退步超過 5 個百分點，就保留舊版預設。

練習在 `audio_valid[2] = False` 後加入 `frame_valid[2] = False`。先預測張量形狀仍相同、第三筆只剩界線與讀出位置可讀，再執行核對。它應該學到 `unknown`，但隨機 head 不保證這樣回答；指出需要什麼訓練示範與 final 診斷，才可宣稱學會缺線索時轉交。


**從機制例走到正式訓練。** 正式模型仍只接本節的灰階形狀世界，沒有借用成熟模型權重。以下差異需要逐項對上，才能解讀其成績：

| 零件 | 上面的機制例 | 正式訓練的 `AVModel` |
| --- | --- | --- |
| 融合寬度 | 12、單一 head | 64、4 heads、2 層；每 head 16 維 |
| 聲音入口 | 17 維摘要投影 | 各 200 ms 的 24×37 log-mel 圖，經兩層 CNN 變成64維 |
| 振幅與最後一塊 | 機制例接12.17的摘要 | 固定 `log1p(power)` 尺度；700 ms切成200／200／200／100 ms，最後補零但錨點是650 ms |
| 讀取方式 | 最後讀出、序列因果 | 第一個位置讀出、雙向注意力；只排除缺少內容的key |
| 時間 | 250 ms單位的示意 | 秒；每 head 共用8個頻率，additive版將同一組重複4次 |

`24×37`的第一軸是24個mel頻帶，第二軸是同一塊內的37個時間框。200 ms在16 kHz下有3200個樣本；窗長256、每次移80個樣本，不在兩端補中心窗，便有`(3200-256)//80+1=37`框。`log1p(power)`是把非負功率`p`轉成自然對數`ln(1+p)`：零仍為零，大值的差距被壓小。所有塊用同一個固定轉換，沒有再按每塊RMS或整段錄音統計除尺度，因此沒有把振幅資訊先抹平。

每 head 的頻率相同，是為了把正式對照集中在「加進特徵」與「旋轉Q/K」；沒有把不同頻率數也混成改進。正式版的前置讀出位置可先讀整段材料，因此沒有文字生成的未來答案可偷看；它也不具備即時可見性。兩個presence數字只說圖／聲是否附上，不能直接告訴模型圓或方。

<summary>正式模型的完整聲音前處理、融合與CPU形狀核對</summary>

下面直接列出正式計算所需的類別與函式，不必開外部Notebook。`local_audio`先將各塊分開，再做STFT和CNN；跨塊樣本不會進入同一個聲音特徵。時間間隔80 samples是5 ms，`(3200−256)//80+1=37`個STFT窗。`TimeAttention`的Q/K/V先分成4個head，各自讀取，再接回64維。遮罩只有有效key，沒有 `is_causal=True`；這正是和前面小例的差異。

```python
import math
from dataclasses import dataclass
import torch
from torch import nn
import torch.nn.functional as F


@dataclass(frozen=True)
class AVConfig:
    width: int = 64
    heads: int = 4
    layers: int = 2
    representation: str = "time-rope"
    local_samples: int = 3200
    n_fft: int = 256
    hop: int = 80
    mel_bins: int = 24

    def validate(self):
        if self.representation not in {"additive", "time-rope"} or self.width % (2 * self.heads):
            raise ValueError("時間表示／head 維度不合法")
        if self.local_samples != 3200 or (self.n_fft, self.hop, self.mel_bins) != (256, 80, 24):
            raise ValueError("v1 固定獨立 200ms、center=False 的局部前處理")
        return self


def mel_bank(n_fft=256, bins=24, sample_rate=16000):
    def mel(hz):
        return 2595 * math.log10(1 + hz / 700)

    points = torch.linspace(mel(0), mel(sample_rate / 2), bins + 2)
    hz = 700 * (10 ** (points / 2595) - 1)
    frequencies = torch.linspace(0, sample_rate / 2, n_fft // 2 + 1)
    up = (frequencies[None] - hz[:-2, None]) / (hz[1:-1, None] - hz[:-2, None])
    down = (hz[2:, None] - frequencies[None]) / (hz[2:, None] - hz[1:-1, None])
    return torch.minimum(up, down).clamp_min(0)


def local_audio(waveform, config=AVConfig()):
    """每塊 STFT 只讀該塊；不使用全錄音統計，也不跨塊卷積。"""
    config.validate()
    if waveform.ndim != 1 or not len(waveform) or not torch.isfinite(waveform).all():
        raise ValueError("waveform 必須是一維有限且非空")
    count = math.ceil(len(waveform) / config.local_samples)
    padded = F.pad(waveform, (0, count * config.local_samples - len(waveform)))
    blocks = padded.reshape(count, config.local_samples)
    spectrum = torch.stft(
        blocks,
        n_fft=config.n_fft,
        hop_length=config.hop,
        window=torch.hann_window(config.n_fft, device=waveform.device),
        center=False,
        return_complex=True,
    )
    power = spectrum.abs().square() / config.n_fft
    mel = mel_bank(config.n_fft, config.mel_bins).to(waveform.device) @ power
    # 固定物理振幅尺度；padding 和窗外樣本不參與全局正規化。
    features = torch.log1p(mel).unsqueeze(1)
    starts = torch.arange(count, device=waveform.device) * 200.0
    ends = torch.minimum(starts + 200, torch.tensor(len(waveform) / 16, device=waveform.device))
    return features, starts, ends, (starts + ends) / 2


class TimeAttention(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.config = config
        self.qkv = nn.Linear(config.width, config.width * 3)
        self.out = nn.Linear(config.width, config.width)
        frequencies = 2 ** torch.linspace(-1, 6, config.width // config.heads // 2)
        self.register_buffer("frequencies", frequencies)

    def rotate(self, x, times):
        angle = times[:, None, :, None] * self.frequencies[None, None, None, :]
        left, right = x[..., 0::2], x[..., 1::2]
        return torch.stack(
            (left * angle.cos() - right * angle.sin(), left * angle.sin() + right * angle.cos()), dim=-1
        ).flatten(-2)

    def forward(self, tokens, times, valid):
        b, length, width = tokens.shape
        q, k, v = (
            self.qkv(tokens)
            .reshape(b, length, 3, self.config.heads, width // self.config.heads)
            .permute(2, 0, 3, 1, 4)
            .unbind(0)
        )
        if self.config.representation == "time-rope":
            q, k = self.rotate(q, times), self.rotate(k, times)
        attended = F.scaled_dot_product_attention(q, k, v, attn_mask=valid[:, None, None, :])
        return self.out(attended.transpose(1, 2).reshape(b, length, width))


class AVModel(nn.Module):
    def __init__(self, config=AVConfig()):
        super().__init__()
        self.config = config.validate()
        width = config.width
        self.image = nn.Sequential(
            nn.Conv2d(1, 16, 5, stride=2, padding=2),
            nn.GELU(),
            nn.Conv2d(16, width, 3, stride=2, padding=1),
            nn.GELU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
        )
        self.audio = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1),
            nn.GELU(),
            nn.Conv2d(16, width, 3, stride=2, padding=1),
            nn.GELU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
        )
        self.modality = nn.Embedding(3, width)
        self.readout = nn.Parameter(torch.randn(1, 1, width) * 0.02)
        self.blocks = nn.ModuleList(
            nn.ModuleList(
                (
                    nn.LayerNorm(width),
                    TimeAttention(config),
                    nn.LayerNorm(width),
                    nn.Sequential(nn.Linear(width, 4 * width), nn.GELU(), nn.Linear(4 * width, width)),
                )
            )
            for _ in range(config.layers)
        )
        self.head = nn.Sequential(nn.LayerNorm(width + 2), nn.Linear(width + 2, 3))

    def forward(self, batch):
        frames, audio = batch["frames"], batch["audio"]
        b, ni, na = len(frames), frames.shape[1], audio.shape[1]
        image = self.image(frames.flatten(0, 1)).reshape(b, ni, -1) + self.modality.weight[0]
        sound = self.audio(audio.flatten(0, 1)).reshape(b, na, -1) + self.modality.weight[1]
        tokens = torch.cat((self.readout.expand(b, -1, -1) + self.modality.weight[2], image, sound), dim=1)
        times = F.pad(batch["time_s"], (1, 0))
        valid = F.pad(batch["mask"], (1, 0), value=True)
        if self.config.representation == "additive":
            # 兩種表示使用同一個 per-head 頻率集合；加法版只跨 heads 重複，
            # 不額外給它 width/2 個獨特頻率當作另一個變因。
            frequencies = self.blocks[0][1].frequencies.repeat(self.config.heads)
            angle = times[..., None] * frequencies
            tokens = tokens + torch.stack((angle.sin(), angle.cos()), dim=-1).flatten(-2)
        for norm1, attention, norm2, ffn in self.blocks:
            tokens = tokens + attention(norm1(tokens), times, valid)
            tokens = tokens + ffn(norm2(tokens))
        return self.head(torch.cat((tokens[:, 0], batch["presence"]), dim=-1))


# 只用隨機初始化檢查正式架構；不是已訓練模型的答案。
torch.set_num_threads(1)
torch.manual_seed(20261029)
formal_model = AVModel(AVConfig(representation="time-rope")).eval()
y, x = torch.meshgrid(torch.arange(32), torch.arange(32), indexing="ij")
formal_frames = torch.stack(
    [
        ((x - 16) ** 2 + (y - 16) ** 2 <= 64).float(),
        ((x - 16).abs().le(7) & (y - 16).abs().le(7)).float(),
    ]
)[:, None]
fixed_wave = torch.zeros(11200)  # 700 ms，兩筆共用同一條波形
pulse_t = torch.arange(1280) / 16000
fixed_wave[720:2000] = 0.6 * torch.sin(2 * torch.pi * 440 * pulse_t)
features, starts, ends, anchors = local_audio(fixed_wave)
starts_ms = torch.tensor([1215.0, 2215.0])  # pulse內部中心85ms → 1300／2300ms
formal_batch = {
    "frames": formal_frames[None].repeat(2, 1, 1, 1, 1),
    "audio": features[None].repeat(2, 1, 1, 1, 1),
    "time_s": torch.cat(
        [
            torch.tensor([[0.0, 2000.0], [0.0, 2000.0]]),
            starts_ms[:, None] + anchors[None],
        ],
        dim=1,
    )
    / 1000,
    "mask": torch.ones(2, 6, dtype=torch.bool),
    "presence": torch.ones(2, 2),
}
with torch.no_grad():
    formal_logits = formal_model(formal_batch)
print("局部圖", tuple(features.shape))
print("支持區間", list(zip(starts.tolist(), ends.tolist())))
print("原始局部錨點", anchors.tolist())
print("正式架構分數形狀", tuple(formal_logits.shape))
```

這段應印出局部圖 `(4,1,24,37)`、支持區間 `[(0,200),(200,400),(400,600),(600,700)]`、錨點 `[100,300,500,650]`，以及分數形狀 `(2,3)`。發聲中心1300／2300 ms是波形內部85 ms加起點；第一個聲音塊的錨點則是100 ms加起點，兩者不必相同。CNN讀整張局部聲圖來保留事件在塊內的位置。這裡只初始化權重，任何 `argmax` 都不能當作已學會時間對齊。

正式資料將254種非全同的八段形狀模式按family分成38 train、16 dev、200 final；同family的四種片長／間距面板和變體不跨份。主要配對的聲音長度一律700 ms，80 ms脈衝的中心可在錄音內部85或585 ms；同一配對只改音訊起點。另把相同起點下的波形互換，檢查模型是否真的讀聲音內容，不能只從起點猜答案。每個表示用seed 11／29／47各跑6000次更新；一個seed訓練不佳仍須報告。dev只依配對正確率、刪線索診斷、較早checkpoint與既定工作順序選候選；final不能反過來選種子。

| 時間表示／seed | 主要移時配對 | 面板0／1／2／3的正確數，各50 | 固定起點、互換波形的配對 |

| 加法／11 | 130／200 | 30／35／37／28 | 92／200 |
| 加法／29 | 192／200 | 48／49／46／49 | 139／200 |

六支的刪圖、刪聲診斷各為200／200。選定seed29通過事前的主要配對、四面板及刪線索門檻，但事前指定的波形互換診斷並非全對：逐題是348／400，同家族兩題全對只有148／200。起點相同、波形內容改變時仍會失敗，表示不能把主要面板的滿分擴張成所有影音對齊情境都可靠。這項限制保留在新版說明；沒有看到這個結果後改選互換控制較高的seed11或47。

主要配對的三seed平均為加法72.17%、時間RoPE100%，差27.83個百分點。把同200家族共同重抽1000次，差值的95%區間為24.17–31.67個百分點；同一seed的差值分別是35、4、44.5個百分點。這是在這三次下游初始化及這個形狀世界下的比較，不是600個獨立情境，也不能外推為成熟影音模型的一般架構優勢。完整數字、逐題失敗與原始封包見[本輪結果](../../docs/omni-products/v1/results-summary.json)，可操作權重見[新版模型操作](../../docs/omni-products/README.md)。

這裡的共同重抽以家族為單位：先把同一家族在六支模型上的對錯綁在一起，每次從200家族中**有放回地抽200個**，所以同一家族可能出現多次。沿用同一份抽樣索引，先算各seed的「時間RoPE正確率−加法正確率」，再對三seed取平均；重做1000次，取這1000個均差的2.5%與97.5%分位數作上述95%區間。它描述以已測家族重抽時，這組固定seed比較的均差有多大變動；整段在零以上，表示此條件下的差值方向穩定。95%不是模型正確率，也沒有涵蓋重訓新seed或換世界的變動。
