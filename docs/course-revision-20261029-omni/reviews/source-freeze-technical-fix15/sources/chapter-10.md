# 第 10 章：圖片如何進入文字模型

從一張黑底紅方塊開始，先把像素、圖塊與位置變成數字，再接進文字序列。這一章的零件都很短，所以每一步都直接讀本課函式庫 `tiny_perceptron/multimodal.py` 裡的實作：畫合成圖的 `scene`（[10.1](10.md#10.1)）、切塊的 `patchify`（[10.2](10.md#10.2)）、圖片入口 `VisionEncoder`（[10.5](10.md#10.5)）、展開圖片位置的 `expand_modalities`（[10.7](10.md#10.7)），最後在 [10.8](10.md#10.8) 把它們和文字模型接成 `MultiModalLM`。程式接得通，不等於模型學會看圖，兩件事要用不同證據確認。[10.9–10.11](10.md#10.9)改問圖文配對：從現成的候選說明裡選出相配的一段，這和自己生成句子是不同的工作。最後在[10.12](10.md#10.12)為影格加上時間戳，分清「第幾張圖」和「那個時刻看到什麼」。忘了前面章節的名詞，可以查[名詞頁](../glossary.md)。
