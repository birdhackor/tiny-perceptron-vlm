## 12.5 怎麼找出一段單音的主要頻率？

仍用 440 Hz 單音，這次長 0.2 秒。希望每個短時間框都能指出「哪些頻率較強」，並核對最強的格子是否對應 440 Hz。把時間框分解成各頻率的計算叫**短時傅立葉轉換**（Short-Time Fourier Transform，STFT）。

怎麼從一排振幅算出頻率強弱？可以把每個候選頻率想成一組規則起伏的波形樣板：與聲音逐點相乘，再把乘積加起來。起伏互相配合時，乘積較能累積；不配合時，正負乘積會互相抵消。每個頻率還用兩份錯開四分之一週期的樣板，分別計分，再把兩份分數的平方相加，一起衡量這種起伏的強弱。

先看另一組只有四點、未加窗的人工波形 `[1,0,-1,0]`。對每四點一週期的樣板 `[1,0,-1,0]`，乘積和為2；錯相樣板 `[0,1,0,-1]` 得0。兩份合起來是 `2²+0²=4`。每四點兩週期的樣板 `[1,-1,1,-1]` 則得0；在這組取樣點上，它的錯相樣板也全為0，所以本例能分開這兩種頻率。若把原波形錯開一個取樣點，成為 `[0,1,0,-1]`，一週期的兩份樣板分別得0與2，平方相加仍為4：同一種起伏，可以由兩份樣板共同描述。

![四個人工振幅分別與兩種頻率樣板逐點相乘相加；一週期的兩份分數為2與0，兩週期為0](../figures/p7-12-frequency-match.svg)

正式STFT對每個短時間框重複這種比對，先乘[上一節的窗權重](12.md#12.4)，再計算每個頻率格的兩份分數。工具用複數保存這兩個方向的結果；下面的 `abs().square()` 便把兩份分數合成強弱。樣板只由頻率與取樣位置決定，不是模型向答案學出的權重。整理成頻率×時間表後，各格的強弱就能用亮度表示。

![頻率沿縱軸、時間框沿橫軸；亮度代表各格能量的示意](../figures/multimodal_audio_axes.svg)

```python
import torch
from tiny_perceptron.multimodal import tone

wave = tone(440.0, seconds=0.2)
spectrum = torch.stft(wave, 400, 160, window=torch.hann_window(400), return_complex=True)
power = spectrum.abs().square()
peak = power.mean(-1).argmax().item()
print("頻率格、時間框", tuple(power.shape))
print("最高格編號", peak, "對應Hz", peak * 16000 / 400)
```

400 點一框、每次移 160 點，輸出功率 `(201,21)`：201 個非負頻率格、21 個時間框。函式預設在邊界補資料，使框中心落在相應時間點；所以它與直接 `unfold` 的完整框數不同。這裡 3200 點得到 21 框，不是沒有補齊的 18 框。

STFT 結果是複數，含頻率成分的大小與相位。`abs()` 取大小，再平方得到功率；例如 `3+4j` 的大小是 5，功率是 25。圖用功率亮度表達，不直接顯示相位。

頻率格間隔為 `16000／400＝40 Hz`，第 11 格對應 440 Hz。把各框功率平均後找最大，程式印出 11 與 440.0，符合這個單音的來源。真人語音含多種變化，最強一格只能描述當下能量，不能當成某個字的編號。

頻譜也不是音高列表：圖上不同頻率可能同時亮起。練習改成 480 Hz 單音，預期最大格約 12；若用 450 Hz，則不能要求它剛好落在整格，附近格會一起分到能量。
