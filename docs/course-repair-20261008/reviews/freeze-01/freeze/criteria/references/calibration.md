# 跨領域校準：理由成立，還要核對它完成什麼

以下校準審閱理由。先承認來源已完成的部分，再按原承諾判剩餘缺口；不得由已知問題倒推必須缺什麼。充分版與欠缺版的差別是必要關係，不是例子數量。

## 一項有效理由不能包辦另一項承諾

原文：「共用印表機要避免工作交錯，也要先申請者先印。每次只允許一人取得使用權；印完整份後才釋放，等候者之一再取得。」示例中的兩份文件沒有交錯。

錯誤放行：「互斥已完整解釋，例子也正確，所以這套安排的理由都已教清楚。」錯誤拒絕：「沒有再跑多人案例，所以整段都不夠。」

有效判斷：原文已說清如何避免交錯；尚未交代如何選下一位，不能從互斥推出申請順序。必要缺口只在原文另承諾的先後次序，不否定互斥理由，也不要求完整排程理論。

最小修正：「申請按到達順序排隊，釋放時交給隊首。」已有此規則就通過，無須再跑多人案例；若原問題只要求避免交錯，原版亦可通過。

## 完整操作規則不自動交代選擇需要

原文：「甲一越過設定溫度就切換。乙低於下限才開、高於上限才關，中間維持原狀。乙較適合加熱器。」

錯誤放行：「我另想出小幅反覆波動的情境，算出乙較少切換，所以原文已解釋。」有效判斷：兩種規則可懂；但以減少切換為選擇判準，是審閱者另加的需要。

最小修正是指出需求與條件：「要避免設定溫度附近的小幅波動反覆切換；波動未越過上下限時，乙保留狀態，代價是容許較大的溫差。」已有此需求及完整規則，即可正常推得，不要求新增兩筆讀值或證明所有設備都更好。

## 真實補充依新增關係判斷

換算行動電源標示能量時，來源說容量乘電壓，又補充USB端口有不同輸出電壓。只說「補充是真的」不能回答容量應配哪端電壓；缺少配對且影響當下選值，才是必要缺口。補一句電芯容量須配同組電芯額定電壓即可。

若前文或表格已教配對，這句便可通過，不需要電路原理。若只是重複已知關係，沒有新增必要理解負擔，可保留或列可選編輯；不能因刪去仍懂、換了主詞或自己想不出用途，就直接判必要。

## 任意約定與正常推論

偽 API `make_date(4, 4, 2026)` 不能據此判前兩項是月／日或日／月；兩規則都相容，非對稱日期會影響操作，約定需交代。若來源已有其他不對稱例及明確結果，則先查是否已能唯一推得，不能只看首個對稱例。

已教每頁最多十筆、不足也佔一頁，三十七筆需四頁，是正常推論；留下三滿頁加一不足頁即可，不因沒另寫公式報缺。

路線導覽只需指定任務、基本角色、可靠來源及後續方向，不必在入口證明全部工程成因；當下推算已使用的性質才需教清。
