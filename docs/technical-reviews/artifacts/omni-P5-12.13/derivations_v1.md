# 12.13 independent derivations

Reviewer: `/root/omni_p5_technical_12_13`. These are hand derivations and artificial counterexamples, not measurements of a trained model.

1. Signal and dimensions: a sample interval is 1/16000 seconds. `arange(1600)` gives indices 0 through 1599, so each block occupies 1600/16000 = 0.1 seconds, with its final sample at 0.0999375 seconds. Concatenating two blocks gives 3200 samples and 0.2 seconds. Frequencies are explicitly 440 then 880 Hz; the amplitude multiplier is 0.5. A 400-sample window covers 25 ms, a 160-sample hop is 10 ms, and Nyquist is 8000 Hz. Real one-sided STFT has 400//2+1 = 201 frequency bins. Centering adds 200 samples on each side: 1 + floor((3200+400-400)/160) = 21 frames. Eighteen HTK-mel edge locations define sixteen triangles. Thus bank [16,201] times power [201,21] gives [16,21], and transpose gives [21,16]. These are explicit demonstration settings, not optimized choices.

2. Mean invariance: write the extracted feature array as X[t,b], t=0,...,20 and b=0,...,15. Reversal is Y[t,b]=X[20-t,b]. For every band b, sum_t Y[t,b] = sum_t X[20-t,b] = sum_u X[u,b], by the substitution u=20-t. Dividing both by the same 21 gives the same arithmetic mean in real arithmetic. This argument needs only a permutation of the same rows, not anything about waveforms or speech. In float32, addition is not associative; different reduction order need not give bitwise equality. The executed artifact therefore checks the documented allclose criterion abs(a-b) <= 1e-8 + 1e-5*abs(b), as well as reporting exact equality separately.

3. Task identifiability: artificial frames L=[1,0] and H=[0,1] give mean([L,H])=mean([H,L])=[0.5,0.5]. The correct first-segment labels are respectively “低先” and “高先”. Any deterministic rule given only the common mean must return the same answer on both, so cannot be correct for both. A randomized rule sees the same conditional input and cannot reliably identify which ordering occurred. Retaining an order-sensitive representation removes this collision, but does not prove that training learns to use it. Supervised examples must expose the intended order answer (or a defined equivalent target); no learning success is asserted. This argument does not rule out upstream encoders already encoding order into each row before averaging.

4. Occurrence versus order exercise: the predicate “an H frame occurred” is true for both [L,H] and [H,L], and the second coordinate of the common mean is positive for both. A mean can therefore help for such a predicate under these artificial assumptions. It is not an assertion that arbitrary log-mel means uniquely identify every tone in real mixtures. The predicate “H came first” changes under reversal and needs distinguishing temporal information. The exercise appropriately asks “可能足以幫忙”.

5. Speech and response objectives: the syllable/token sequences “你愛我” and “我愛你” use the same three items in different orders but have different transcripts. A transcript target therefore cannot generally discard order. A downstream requirement can be coarser: an artificial keyword rule maps both “請更新地址謝謝” and a one-character-deletion transcript “請更新地址謝” to “地址更新”. This establishes only that a transcription error does not logically imply a wrong task answer; it says nothing about an ASR error rate or this course model's abilities.

6. Ordinal versus physical time: indices [0,1] alone could describe frames at [0,10] ms or [0,20] ms. Both have identical relative order and different physical separation. An origin, time step, sample rate or explicit time coordinates are needed to recover milliseconds. The 12.17 cross-reference uses start_ms plus sample indices/rate and records raw support before any cross-block fusion; the current 12.13 example itself is centered whole-wave STFT and is not a strict block-local feature proof.

7. Existing product A: source inspection shows Conv1d, bidirectional GRU, adaptive pooling to 16 time-axis outputs, and a 16-entry time-position embedding. This supports sixteen ordered temporal interval vectors. Because GRU contextualization precedes pooling and a shared logits term is added, these vectors are not claimed to depend only on isolated raw intervals. The audit only parses that implementation and applies the pure pooling API to [0,...,63], giving interval means [1.5,5.5,...,61.5]; no neural forward, weights, training or final-family inference is performed.
