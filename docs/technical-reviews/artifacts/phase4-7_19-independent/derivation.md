# 7.19 independent count and boundary derivation

The stipulated token rows have lengths 3, 3, 5, 1. P = 3+3+5+1 = 12 includes the final assistant marker; the displayed slash separators are not tokens. C = 16 leaves C-P = 4 positions. A reservation of G=4 satisfies P+G <= C exactly. G=5 asks for a possible total of 17 and cannot be promised inside this explicitly fixed 16-slot full-history contract. It does not imply that an implementation must reject: explicit clipping is one way to handle the incompatibility. The repo generator clips at its configured length; the original HF length-preparation method instead sets its max_length to P+G, so an HF generation max_length field alone is not an independent C.

The stipulated f,g,E candidate has 3 newly selected tokens: f and g are visible content, E is a selected EOS token. Total = 12+3 = 15, leaving one unused slot. The slot is not PAD. G=2 produces only f,g: 2 new tokens, total 14, the full visible store name, no generated EOS. An initial E produces 1 new token, total 13, but no name. The exercise f,E produces 2 new tokens, total 14, fits G=4 but misses g. All counts are exact integers, in toy-token units; no rounding, ratio, percentage, empirical denominator, or numerical tolerance is needed beyond equality.

The ByteTokenizer counterexample serializes the same messages with its own BOS, roles, UTF-8 byte tokens, EOS delimiters and final assistant marker. It has 59 tokens, not 12. This is a concrete different tokenizer contract; it does not estimate the count for any downloaded model.

For real TinyLM the token tensor has axes [batch, sequence]. Cached K/V shape is [batch, heads, sequence, head_dimension]. The short seeded CPU comparison moves cached length from 8 to 12 and then verifies an exact length-16 cache; 17-token full input or length-16 cache plus one new token raises ValueError. Cached and uncached output IDs at the total limit are identical. Logits use atol=1e-6 and rtol=1e-5; observed max absolute difference is 1.7881393432617188e-7. These are numerical and boundary checks, not training or quality measurements.
