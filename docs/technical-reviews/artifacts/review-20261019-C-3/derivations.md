# 機率與估計的核對

令固定題目在固定隨機抽樣策略下，一份回答是否答對的指標為 X_i。若每個 X_i 都有 P(X_i=1)=p，且相互獨立，則 P(X_1=0,...,X_k=0)=(1-p)^k。取補事件得到集合命中機率 1-(1-p)^k。對 0<p<1，增加一次抽樣的增量是 p(1-p)^k>0；p=0 或 p=1 時恆定。

## 相同輸出與獨立性

獨立性是聯合機率等於邊際機率乘積的條件，不是兩次觀察到的值必須不同。每次獨立以 0.8 機率輸出 7，八次至少六個 7 的機率是 sum_{j=6}^8 C(8,j)0.8^j0.2^(8-j)=0.79691776。因此六個重複錯答案本身不否定獨立性，也不識別模型真正的機率。

固定模型、固定題目與確定性 greedy 解碼時，可把回答分布寫成集中在單一字串 y* 的點質量。所有回答 Y_i=y* 幾乎必然成立。對任意集合 A_i，P(Y_1∈A_1,...,Y_k∈A_k) 與 product_i P(Y_i∈A_i) 都是 product_i 1[y*∈A_i]，故符合相互獨立的定義。同一題的正確性機率 p_g 只有 0 或 1，公式 1-(1-p_g)^k 仍然成立，只是增加 k 沒有收益。從有溫度的抽樣改成 greedy，也改變了解碼分布，不能保留原來的 p=0.3。

所以原文的 greedy 行為描述成立，但把它列成「破壞三個前提」的例子不成立。適當的最小修正是將 greedy 說明移出破壞獨立性案例，明說它對固定題目沒有重抽多樣性、正確率為 0 或 1，因此重試沒有增益。

若下一次生成的分布隨先前答案改變，就不能直接把聯合失敗機率寫成固定的 (1-p)^k。例如 X_1~Bernoulli(0.3)，讓第二份回答複製第一份，則 P(X_1=0,X_2=0)=0.7，而非 0.49。把先前答案加進 prompt 是這類適應性流程；需要另行證明分布保持不變且獨立，才能沿用公式。這不是說任何加入 prompt 的程式都在邏輯上保證相依；模型可能忽略新增內容。

## 題目差異、估計與選擇

對兩題 p_1=0.9、p_2=0.1，平均單次正確率為 0.5。兩次抽樣的平均命中率是 ((1-0.1^2)+(1-0.9^2))/2=(0.99+0.19)/2=0.59。先平均 p 再代入會得到 1-0.5^2=0.75，不能代表這兩題的平均集合命中率，更不能預測每一道題。

對固定題目做 m 次獨立同分布抽樣，樣本比例 p_hat=sum_i X_i/m 的期望是 p、變異數是 p(1-p)/m≤1/(4m)。抽樣估計仍有不確定性；增加 m 可以縮小此不確定性，不能因某一份手工候選清單含正解，就回頭把假設參數 p 改掉。

集合命中是 max_i X_i=1；特定選法的成功是 X_J=1。後者蘊涵前者，反過來不成立。例如候選 [3,4,3,5] 對答案 4 命中，但 J=1 會交出錯誤的 3。用已知答案對候選評分可量集合命中，不能據此推出未知答案下的可部署選擇器成績。

## 非巢狀實測與 pass@k

理論上對同一分布的期望集合命中隨 k 不減；同一條已抽樣序列的前 k 項也有不減的命中指標。重新抽一組 k=8 與重新抽一組 k=4 則不是包含關係，後者可能命中而前者失敗。有限題數的單次比例因此可下降，不反駁期望公式。實驗程式對每個 candidate_count 重新呼叫 _sample，不重用較小 k 的候選。

原論文的每題估計量是 1-C(n-c,k)/C(n,k)，總體數字再跨題平均。n=k 時分母 C(k,k)=1；c=0 時分子也是 1，估計量為 0；c>0 時 C(k-c,k)=0，估計量為 1。故每題只生成 k 份並以是否有成功記 0/1，再跨題平均，確為 n=k 的特例；它的變異可比大候選池的估計高。

兩支線各自只有 24 道不同測試題，每種候選數都用同一批題目。每支保存的候選數是 24×(1+2+4+8)=360；重複生成的份數不能算成不同題目數。原始紀錄的逐份 ID、文字與 final_correct 已由驗證程式重新解碼及重算。
