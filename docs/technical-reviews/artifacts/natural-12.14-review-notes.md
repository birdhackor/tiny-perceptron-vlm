The plain transcript channel omits acoustic attributes unless they are represented in its text. The original Whisper API also exposes segments and optional timestamps, so the claim is limited to attributes not written into the transcript and the text-only channel used here; it is not a claim that every possible ASR output lacks metadata. Distinct pitch or emotion can coexist with the same lexical text, so their identity is not recoverable from those equal strings alone. Direct audio-feature input is a different learnable route, not a quality claim established by this experiment. The practical interface outputs text and contains no TTS stage.
