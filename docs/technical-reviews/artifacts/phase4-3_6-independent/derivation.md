# 3.6 本審閱者的短推導

query 列 i 與 key/value 候選欄 j 對齊。這裡 B=H=1，Tq=Tk=4，Dk=Dv=2。
Q/K/V 是 [1,1,4,2]；QKᵀ、allowed、weights 則是 [1,1,4,4]。
`ones(4,4,bool).tril()[None,None]` 的最後兩軸都是位置，不是特徵。

Q/K 全零，縮放後每個合法分數也是 0；第 i 列合法 j=0,…,i，分母是
Σexp(0)=i+1，不合法分數 -∞ 的 exp 為 0。每个合法候選比例是 1/(i+1)：

|query i|比例分母|V 第一格平均|V 第二格平均|
|---|---|---|---|
|0|1|1/1=1|10/1=10|
|1|2|(1+2)/2=1.5|(10+20)/2=15|
|2|3|(1+2+3)/3=2|(10+20+30)/3=20|
|3|4|(1+2+3+4)/4=2.5|(10+20+30+40)/4=25|

這是人工 V 特徵數字，沒有字元機率、物理單位、訓練資料樣本或模型品質分數。
第 3 張 V 的兩格各加 100，因果前 3 列比例為 0，因此差異精確為 [0,0]。
最後一列比例 1/4，因此差異兩格各 25，結果 [27.5,50]。
刪除 `.tril()` 後每列都合法四候選；每列第 3 張比例都是 1/4，故每列差異 [25,25]。
分數填普通 0 時 exp(0)=1，本例全部候選仍各 1/4，禁讀的六格也非零。

原稿 allclose 的預設為 atol=1e-8、rtol=1e-5；本次均值/比例以 float64 理論值核對
CPU float32 結果，使用 atol=rtol=1e-6，最大誤差 9.934107481068821e-9（來自1/3）。
未來介入的前3列、禁讀權重、clone保留原V、移除tril的差異都另外核精確相等。
非零 Q/K 與官方 SDPA 的對照採元素wise atol+rtol×|expected|容忍式，最大絕對差
1.9073486328125e-6；該最大誤差處數值尺度使之通過，不能將1e-6誤稱固定絕對上限。

「貓看狗。」有三個提供位置/右移目標對：[貓→看, 看→狗, 狗→。]。句號後沒有目標。
低答案代價不保證防偷看：人工把三個右邊目標的類別直接複製到四類 logits（正確类20，
其他0），float32平均cross entropy為0；double理論每個為log(1+3 exp(-20))≈6.18e-9。
這只是刻意洩漏的代數反例，分母三個位置、四類、mean reduction、零訓練步，
不是本書模型成績，也不宣稱重新訓練或完整系統已驗收。
