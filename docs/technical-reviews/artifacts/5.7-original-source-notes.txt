Adam：Kingma、Ba；arXiv 1412.6980v9，2017-01-30，ICLR 2015。
原 PDF URL https://arxiv.org/pdf/1412.6980v9
PDF SHA-256 eab9c73ae2ceda884b94830bda99312254bac4806f6c9f045cbab90721ecda31。
親讀第 2 頁 Algorithm 1、§2；另外以 pdftotext 親讀原 PDF 第 2 頁。
m_t=β1*m_(t-1)+(1-β1)*g_t；v_t=β2*v_(t-1)+(1-β2)*g_t²；m_hat=m_t/(1-β1^t)，v_hat=v_t/(1-β2^t)。
更新為 θ_t=θ_(t-1)-α*m_hat/(sqrt(v_hat)+ε)。因此下次更新不只依賴權重與本輪梯度，亦依賴 m、v、t。論文不保證續訓品質、CPU/GPU逐位一致或所有任務較好。

AdamW：Loshchilov、Hutter；arXiv 1711.05101v3，2019-01-04，ICLR 2019。
原 PDF URL https://arxiv.org/pdf/1711.05101v3
PDF SHA-256 9d5af48931e773d6983d167e15c06ef594475b751c1f263827f5ed3c7a00d0d8。
親讀第 2 頁 §2、第 3 頁 Algorithm 2；實際渲染原 PDF 第 3 頁並以 view_image 查看。
Algorithm 2 有顏色區分：粉色是把L2項加進梯度的舊法，綠色是AdamW額外衰減。AdamW保留m、v、t並將衰減放在梯度估計之外。論文使用 schedule multiplier η_t 與衰減 λ 的參數慣例；PyTorch 的 weight_decay 乘當步lr，須以其目前原始碼核對，不能把兩種符號直接當同一參數。
