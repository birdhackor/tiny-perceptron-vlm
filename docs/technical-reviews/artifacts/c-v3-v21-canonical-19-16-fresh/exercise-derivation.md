# 19.16 手工資訊充分性標籤核對

審閱者：`/root/c_v3_technical_coord/canonical_19_16_fresh`。

這是依本節練習所明定必要欄位作出的透明推導，不是模型執行或能力量測。

1. 初始材料已知「案件編號42」及規則「查進度需本人授權」，案件42的授權狀態未知。
2. 問「文件說查進度需要什麼條件？」時，本題明定必要欄位集合 R1={規則文字}。已知必要欄位集合 K1={規則文字}，所以 |R1∩K1|/|R1|=1/1，全滿足，充分性為 yes。
3. 問「案件42目前是否符合查進度的授權條件？」時，必要欄位集合 R2={案件編號, 該案件的授權狀態}。材料僅給其中案件編號，故已知必要欄位數為1/2，充分性為 no。單看「有編號」會產生錯誤的 yes。
4. 補上「授權狀態：否」後，兩個必要欄位都有明確值，已知必要欄位數為2/2，充分性為 yes；由規則判定授權條件未滿足。欄位的已知假值與欄位未知有不同作用。

結論只涵蓋練習自行明定的兩組必要欄位。它不聲稱舊 C 的公開語法、字表或權重支援案件授權這個新世界，也不把充分性與執行許可混為一談。
