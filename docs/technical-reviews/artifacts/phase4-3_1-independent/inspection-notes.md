## Original papers read

* Vaswani et al., *Attention Is All You Need*, arXiv `1706.03762v7`, original PDF pp. 3–4, §3.2 and §3.2.1, Eq. (1); newly extracted layout text lines 145–190. The original says “The output is computed as a weighted sum ... of the values” and each value's weight is computed from compatibility of the query with the key. It applies softmax to obtain the weights, with output `softmax(QK^T/sqrt(d_k))V`. This supports the lesson's weighted read operation as the value aggregation part of ordinary softmax attention, with each output feature receiving a sum over source positions. It does not claim the manual weights are a complete query/key attention computation. The lesson explicitly defers computing those weights to the next section. The general formula does not require choosing a single source position.

I do not infer that every attention architecture is uninterpretable or repeat their reported empirical numbers as a new experiment. ## Own calculation and scope

With nonnegative coefficients summing to 1, each output coordinate is a convex combination `o_j = sum_i w_i v_ij`. The denominator of the normalized weighted mean is `sum_i w_i = 1`; there is no additional division by the two positions. For the unitless toy data, `[0.9,0.1] @ [[2,0],[0,4]]` yields exact decimal `[1.8,0.4]`; the feature axis stays length 2. Two two-feature cards concatenated would retain four numbers, whereas this mixing outputs two. The swapped exercise yields exact decimal `[0.2,3.6]` and leaves both source rows unchanged. For a single feature, `0.9*1=0.9` and `0.1*100=10`; a greater coefficient need not yield a greater contribution when source magnitudes differ.
