1.1 確定性對照與可逆性推導（本節 UTF-8 原稿；2026-10-03）

本文 text = 貓看狗，狗看貓。 是八個 Python str 碼點，並含五種碼點。
五種碼點的 Unicode 值依序：
。 U+3002 = 12290
狗 U+72D7 = 29399
看 U+770B = 30475
貓 U+8C93 = 35987
， U+FF0C = 65292
有 12290 < 29399 < 30475 < 35987 < 65292。
set 去重，sorted 以單碼點字串的 Unicode 碼點總序排列，故
C = [。, 狗, 看, 貓, ，]。
E(C[i]) = i 由 enumerate 從 0 定義，所以
E(。)=0, E(狗)=1, E(看)=2, E(貓)=3, E(，)=4。
逐個原句字元代入 E：
貓→3，看→2，狗→1，逗號→4，狗→1，看→2，貓→3，句號→0。
得到 [3,2,1,4,1,2,3,0]，保留原順序與全部標點。

定義 D(i)=C[i]。因為 C 由不同碼點組成，所以對所有 c∈C，D(E(c))=c。
str.join 的空分隔字串把各 D(E(c)) 依序串回原文，故得到完全相同的 str。
成立條件：編碼字元均在 C，解碼使用同一 C；不假定對字元做 Unicode 正規化，
也不宣稱一個碼點等於任意語言中一個可見字形／grapheme cluster。

反向排序 C' = [，, 貓, 看, 狗, 。]，令 π(i)=4-i。
E'=π∘E，而 D'=D∘π⁻¹；π⁻¹=π。
因此 D'(E'(c))=D(π⁻¹(π(E(c))))=D(E(c))=c。
新 ID 逐個為 [1,2,3,0,3,2,1,4]，其中文仍是貓看狗，狗看貓。
原先貓/狗的整數比為3/1，重編後為1/3，但指涉的字完全沒變。
故 ID 的數值大小或鄰近本身不提供語義倍數、大小或相似度。
中間字「看」的新 ID 仍是2，所以「編號改變」是整份清單改變，並非每種字都改。

鳥不在 C，沒有定義 E(鳥)；教材的普通 dict（沒有 __missing__）以 d['鳥']
取值時依 Python 契約拋 KeyError。此結果不可推論到所有 tokenizer：具有 UNK、
byte fallback 或其他規則者的處理方式不同。

本節執行只建立清單／dict／ID 並逆查，沒有模型參數、loss、梯度或 optimizer。
這證明本例沒有訓練步驟；不宣稱真實模型永遠不用可訓練 tokenizer。
數學是精確整數與字串等式，容忍差為0；實際CPU核對另見1.1-cpu-check-result.json。
