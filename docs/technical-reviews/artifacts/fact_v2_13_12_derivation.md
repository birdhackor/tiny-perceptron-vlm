# 13.12 手算與成立範圍

對同一個已採樣的情境 s 與回答 a，令 p_old = π_old(a|s) > 0，p_new = π_new(a|s) > 0。

自然對數恆等式：log(p_new) − log(p_old) = log(p_new/p_old)，所以 exp(log(p_new) − log(p_old)) = p_new/p_old。在實數中是恆等式，float32 計算只有有限精度。

原例第一筆：p_old = 0.2，p_new = 0.4，直接除得到 0.4/0.2 = 2；log(0.4) ≈ −0.9162907319，log(0.2) ≈ −1.6094379124，差 ≈ 0.6931471806，exp 後為 2。

原例第二筆：p_old = 0.2，p_new = 0.1，直接除得到 0.1/0.2 = 0.5；log(0.1) ≈ −2.3025850930，減去 log(0.2) 得 −0.6931471806，exp 後為 0.5。

兩格是兩筆已採樣回答的條件機率，不能要求它們跨題相加為 1。可以各自補成完整二選一分布：第一題 old=[0.2,0.8]、new=[0.4,0.6]；第二題 old=[0.2,0.8]、new=[0.1,0.9]。程式只保留每題所選第一個回答的機率。

乘固定正優勢：ratio×A = 2×0.6 = 1.2，這是 PPO 論文式 (6) 逐筆 surrogate 的一項，不能視為兩倍品質。原論文另在式 (7) 取 clipped/unclipped 較小者；本節尚未裁切，正文已指向下一節。

練習第一筆改為 0.3/0.2 = 1.5；log(0.3) − log(0.2) ≈ 0.4054651081；第二筆保持 0.5。錯把新機率本身作分母時，p_new/p_new = 1，兩格都為 1。這個前向值反例沒有聲稱某種錯誤實作的梯度必定為零。

ratio=1 只表示該題該個已採樣回答的條件機率相同，不證明整個策略分布相同，也不保證正確率。ratio>1/<1 分別表示這個回答的條件機率提高/降低；不是跨所有新情境的實測頻率。

實務要保存有限的 log probability，通常由 log_softmax/log_prob 直接計算，避免先 softmax 成極小機率後下溢成零。這不保證任意 log ratio 的 exp 永遠有限；float32 exp(1000) 會溢位。正文的 0.1–0.4 人工數值沒有這個問題。

detach() 停止反向與前向 AD，但與來源共享儲存；它本身不保證歷史快照。此正文先計算新 tensor 的 log，並沒有再原地修改該份 old log，故有效。正式程式在 no_grad 收集、gather 後 clone，三個 epoch 重用同一份 old log/advantage。固定 reference 來自 SFT 起點，與每輪採樣策略的 old log 承擔不同角色。

手算容忍差：上述十位小數的展示與恆等式採實數解釋；真 CPU float32 輸出使用絕對誤差 ≤1e−6，無相對誤差。列印採 round(...,4)，因此正文和練習字串需精確相等。
