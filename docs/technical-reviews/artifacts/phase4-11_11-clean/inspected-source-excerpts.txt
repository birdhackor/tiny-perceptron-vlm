555: From binary to multiclass and multilabel
556: ----------------------------------------
557: 
558: Some metrics are essentially defined for binary classification tasks (e.g.
559: :func:`f1_score`, :func:`roc_auc_score`). In these cases, by default
560: only the positive label is evaluated, assuming by default that the positive
561: class is labelled ``1`` (though this may be configurable through the
562: ``pos_label`` parameter).
563: 
564: In extending a binary metric to multiclass or multilabel problems, the data
565: is treated as a collection of binary problems, one for each class.
566: There are then a number of ways to average binary metric calculations across
567: the set of classes, each of which may be useful in some scenario.
568: Where available, you should select among these using the ``average`` parameter.
569: 
570: * ``"macro"`` simply calculates the mean of the binary metrics,
571:   giving equal weight to each class.  In problems where infrequent classes
572:   are nonetheless important, macro-averaging may be a means of highlighting
573:   their performance. On the other hand, the assumption that all classes are
574:   equally important is often untrue, such that macro-averaging will
575:   over-emphasize the typically low performance on an infrequent class.
576: * ``"weighted"`` accounts for class imbalance by computing the average of
577:   binary metrics in which each class's score is weighted by its presence in the
578:   true data sample.
579: * ``"micro"`` gives each sample-class pair an equal contribution to the overall
580:   metric (except as a result of sample-weight). Rather than summing the
581:   metric per class, this sums the dividends and divisors that make up the
582:   per-class metrics to calculate an overall quotient.
583:   Micro-averaging may be preferred in multilabel settings, including
584:   multiclass classification where a majority class is to be ignored.
585: * ``"samples"`` applies only to multilabel problems. It does not calculate a
586:   per-class measure, instead calculating the metric over the true and predicted
587:   classes for each sample in the evaluation data, and returning their
588:   (``sample_weight``-weighted) average.
589: * Selecting ``average=None`` will return an array with the score for each
590:   class.
