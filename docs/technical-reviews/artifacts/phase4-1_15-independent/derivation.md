# 1.15 獨立代入及範圍

候選軸依序 ID 0=貓、1=看、2=狗。分數、T 與機率均無物理單位；softmax 的分母是同一步三個候選的 exp(z_i/T) 總和，不是樣本數或句長。

對有限實數 z 與 T>0，p_i(T)=exp(z_i/T)/Σ_j exp(z_j/T)。因為 p_i/p_j=exp((z_i-z_j)/T)，正溫度保持排序，argmax 相同；降低 T 擴大較高與較低分數的機率比。以熵衡量整體分配尖銳程度，H=log Z-E[z]/T，dH/dT=Var(z)/T³≥0。因此「機率更平均」是整體分配的性質，不表示每個非最高候選在任意 T 區間均逐一遞增。

原題 [3,1,0]，T=.5 的 exp 分母 411.8178495916658，最高機率 .9796292071670795；T=1 分母 23.803818751646713，最高機率 .8437947344813395；T=2 分母 7.130410341038193，最高機率 .6285317192117624。

練習 [3,1,2]，T=.5/1/2 的最高機率分別 .8668133321973348/.6652409557748219/.5064803910556540。第三個機率分別由 .002428258029591337/.04201006613406605/.14024438316608848 增至 .11731042782619835/.24472847105479764/.30719588571849843。另 dp_3/dz_3=p_3(1-p_3)/T>0，給固定其他分數與正 T 時提高第三個分數的機制。

教材三位小數按最近值四捨五入，絕對誤差容忍 .0005。獨立 Python math.exp 的雙精度計算和原 torch float32 最大單元素誤差 <1e-7；三個 float32 元素加總容忍 <3e-7。初稿 probe 曾誤將加總誤差限設成單元素的 1e-7，練習 T=1 的加總誤差 1.043081283569336e-7 觸發自己的斷言；保留 attempt1 原碼／stderr，修正三項累計容忍後通過，教材數值無問題。

數學 T→0+ 是極限，唯一最高者取得全部質量；T=0 不定義這個除法。torch 直接除零產生無效 softmax；generate API 的 temperature<=0 是獨立 argmax 分支，並沒有用 T=0 去除分數。並列最大時 torch.argmax 取最先的最大索引，本節明確把並列交給實際最大值規則。

原 fence 只有既定分數→機率與 argmax，未呼叫模型、未抽樣、未求梯度或更新參數。probe 的固定 Parameter adapter 只為實際執行 generate 的循環；3 組各新增 8 token，共 24 forward，exact torch.equal 核对參數不動、grad=None、training 模式恢復。它不是訓練或語言品質評测。

改 T 與改 z 是兩個因子，公式已顯示兩者都影響 p；比較溫度時固定 z，比較訓練得到的模型時固定解碼規則，才能隔離這兩個因素。本節未宣稱只控制這兩項就能完成完整模型評測。題目、資料、種子等其他控制仍應在實際實驗中固定。4096 次抽樣僅展示非最高候選可出現，不用其比例驗收模型或測量品質。高低溫度的文字多樣性／通順風險由原論文支持，不由三候選玩具結果外推。
