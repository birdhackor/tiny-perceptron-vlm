# chapter-16 首讀實質主張清單

此清單於核對候選來源前按完整 before-first-section snapshot 列出。審查範圍是章導讀，不是逐 16.x 重審。

1. 模型慢、對話 KV 快取太大、訓練批次放不下可能是不同成本問題。
2. 章內分別處理可辨認的運算耗時、生成快取、文件裝填、梯度累積與精度。

4. 長文計算的分塊與限制注意力連結是不同方法。
5. 草擬多個 token 後由原模型一起驗證可減少序列等待回合；此處是章末方法問題，未聲稱既得加速。

7. 16.3 指出 CausalAttention 接續 cache 的行。
8. 16.4 指出 CausalAttention 共用 KV 頭的行。
9. 16.8 指出 CausalAttention 改用 SDPA 的行；主體於 3.7。
10. 14.11 的循環深度可增加每題計算。
11. 7.23 的 thinking effort 是資源偏好，不等於實際秒數。
