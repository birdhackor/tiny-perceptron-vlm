Q(t)、D(t) 是 lexical_terms 輸出的非負整數計數。
score(q,d)=Σ_{t∈Q} min(Q(t),D(t))。
查詢書店地址的 Q(書)=Q(店)=Q(地)=Q(址)=1，共四個片段。
d1 貓喜歡曬太陽的這四個 D(t) 均為0，因此 score=0+0+0+0=0。
d2 書店地址是青街8號的這四個 D(t) 均為1，因此 score=1+1+1+1=4。
只查書、文件書重複10次時 min(1,10)=1；重複不增加此單片段查詢的分數。
文件書店地址尚未公布仍有四個 Q(t)，因此 score=4，但沒有肯定地址值。
原規則可以給分4而且未正規化為[0,1]，不是回答正確機率；甚至高分與資訊存在亦不同。
改問法營業處在哪的五個片段均不在d1/d2的字元集合，所以各項min為0，零分由 if score 排除。
相同分數排序 key=(-score,document.id)，因此字串 id 按 Python 升冪；這只排序分數與 id，沒有語意、日期、真值欄位。
