## 依你想理解的問題選路 {#R.2}

第一次接觸語言模型，先沿第 1–4 章閱讀：從出現次數猜字，改成可調數字，再學會查看前文，最後組成第一個 Transformer。這個名稱表示一種零件組合，等你看過它的做法，再記名字就很自然。

各主題也可以分開學。有時一張小數字表就能說明機制；討論圖片時，可以換成簡單圖卡。局部範例各自成立，最終整合專題才追蹤同一個模型如何接續學習。

| 想理解的問題 | 建議起點 |
| --- | --- |
| 模型如何從猜字學起？ | [第 1 章](chapter-01.md)，依序讀到第 4 章 |
| 為什麼先讀文章，再練習回答？ | [7.11 的對話示範](7.11.md)，再看[7.17 的兩階段理由](7.17.md) |
| 答案對了，為什麼仍沒完成指令？ | [8.14 的書店告示](8.14.md)，沿同一材料讀到 8.16 |
| 回答上限與長上下文有什麼不同？ | [7.19 的十六格例子](7.19.md)，再看[14.7 的位置範圍](14.7.md)與[A.8 的線索位置](A.8.md) |
| 圖片與聲音怎麼成為輸入？ | [10.1 的圖片](10.1.md)、[12.1 的聲音](12.1.md)，可分別開始 |
| 如何教文風、誠實、安全與偏好？ | [第 8 章](chapter-08.md)、[第 9 章](chapter-09.md)；後訓練方法由[7.18](7.18.md)連到第 13 章 |
| Dense、MoE、加速與壓縮各改善什麼？ | [第 15 章](chapter-15.md)、[第 16 章](chapter-16.md)；儲存與較小模型分別看[第 17 章](chapter-17.md)、[第 18 章](chapter-18.md) |
| 模型何時查資料或使用計算器？ | [A.2 的外部資料](A.2.md)、[B.1 的工具請求](B.1.md) |
| 零件如何組成我們自己訓練的小助理？ | [第 19 章](chapter-19.md)，從有限任務與輸入開始 |
| 如何接手成熟模型做應用？ | 延伸閱讀[第 20 章](chapter-20.md)，查看沿用哪些上游能力 |

跳讀遇到陌生概念時，使用小節末尾的回讀連結補一個必要步驟，再回到原問題。前置連結是找路工具；理解眼前例子需要的說明仍留在正文裡。
