## R.4 理解零件，再驗收整合

一個只有幾個數字的小例子，能讓你追蹤每一步。例如查表得到向量，再把向量混合成下一字的分數。它的價值是把機制看清楚；真正訓練時，再用許多例子反覆更新，並留下不參與更新的題目檢查能力。

譬喻幫我們找到起點，實際數字讓譬喻落地。「查筆記」對應的是比對位置、算比例、混合內容，不代表模型像人一樣讀書。每節會指出眼前結果能支持哪件事，讓你逐步學會判讀。

主線整合專題規劃讓文字核心、圖片入口、語音入口與接頭都從隨機權重開始訓練。接頭把圖片或聲音入口的特徵轉成文字核心能接收的向量，放在問題文字前面的序列位置，連接方式見[19.6](chapters/19.md#19.6)。任務限定為少量教過類型的文字請求、商品與位置圖、已知中文字卡、真人語音需求與計算工具，目標是驗收同一個模型能否真的把這些零件用起來。目前公開的舊合成示範與尚待完成的新成品範圍，分別列在[19.12](chapters/19.md#19.12)。成熟 Qwen／Whisper 的路線另放第 20 章，讓你練習接手已有能力的模型。

MoE、PPO、DPO、量化、蒸餾各自回答不同問題，也有互為替代的安排。第一次完成小助理，不必把每個方法都套一次。先看任務需要什麼，再選架構、訓練訊號與交付方式；成品的能力與限制集中在[19.12](chapters/19.md#19.12)；已公開合成示範的下載與重做步驟見[19.11](chapters/19.md#19.11)，各局部實驗的操作見[操作頁](training.md)。
