1. Hoffmann 等，Training Compute-Optimal Large Language Models。
URL：https://arxiv.org/pdf/2203.15556v1
版本：PDF 本身標示 arXiv:2203.15556v1，2022-03-29；原始快取來自 https://arxiv.org/pdf/2203.15556。
親讀原 PDF 文字抽取：outputs/technical-sources/text-behavior/chinchilla2022.txt；原 PDF SHA-256：3fd3632a8ef48171bd25282990221d49535d75356192f068b3b2ebe08f2aedd4。
定位：p.2 §1 Eq.(1)，p.4 §3，p.5 §3.1–3.2，p.6 §3.3 Eq.(2)，pp.27–28 Appendix F。
核對：論文將最終代價當作參數數 N 與訓練 token 數 D 的函數，在指定 FLOP 預算下比較配置。§3 明說規律由多個模型與訓練長度的實驗擬合而來；不是任意四個小設定就證明通用定律。其原始實驗多達數百個模型、參數與訓練 token 範圍很大，不能把本文小語料重複訓練套上它的係數。
必要公式：argmin L(N,D) subject to FLOPs(N,D)=C；經驗擬合 L̂(N,D)=E+A/N^α+B/D^β。
Appendix F 將一組乘加算兩個 FLOP；投影與密集層按矩陣兩邊尺寸計算成本。這支持本節的一位置 Linear 前向近似 2DH，不支持將該數當整個模型訓練 FLOPs、牆鐘速度或實際執行的硬體指令數。

2. Cawley、Talbot，On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation。
URL：https://jmlr.org/papers/volume11/cawley10a/cawley10a.pdf
版本：JMLR 11 (2010), 2079–2107，2010-07 發表。下載 PDF SHA-256：db01ac8fabef3064a0297bfcf64fb9791bf35c4d03be7a51f5862260adfca206。
親讀原文定位：摘要與 §1 pp.2079–2080；§5、§5.1 pp.2094–2095；§6 結論。
核對：有限樣本上的模型選擇也會過度貼合評分資料；選擇流程須納入模型擬合與獨立評估，不能只報挑出的最好數字。本文是核分類器與重複切分的研究，其選擇偏差機制支持教材警告，但不提供本 TinyLM 四格的置信區間，也沒有證明只共用 test 就足以建立嚴格因果推論。

3. Radford 等，Language Models are Unsupervised Multitask Learners。
URL：https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf
版本：OpenAI 2019 技術報告。親讀快取 outputs/technical-sources/text-behavior/gpt2_2019.txt；原 PDF SHA-256：d9d852e2894556e73f53cb22b7c605a9643d6f0b19bf604b429ed6192fa24f4e。
定位：p.2 §2 Eq.(1)，p.4 §2.2 Input Representation。
核對：語言模型可按前文預測下一符號，整串機率是條件機率的乘積；符號可以採字、詞或以 byte 為基礎的切分。這支持本節以字作概念簡化，不表示實際 ByteTokenizer 將中文一字編成一 token。正式四格全為 ASCII，每個字母與標點一 byte，另有 EOS 目標。
必要公式：p(s₁,…,sₙ)=∏ᵢ p(sᵢ|s₁,…,sᵢ₋₁)。

5. PyTorch 官方原碼，CrossEntropyLoss。
URL：https://raw.githubusercontent.com/pytorch/pytorch/5c4886908584029761b579af026dcfb627c84070/torch/nn/modules/loss.py
版本：同上述 CPU PyTorch commit。
下載全檔 SHA-256：415e4ccbbab63b9cc2b79f09a338cca6fa191c07138a4fb419e3c841c4748ae0。
親讀定位：class CrossEntropyLoss 行 1200–1242。
核對：類別索引目標模式的未縮減負對數代價乘上非 ignore_index 的指示值；sum 合計，mean 依未忽略的權重分母平均。本專案不設類別權重，因此分母是有效位置數。這是答案代價遮罩，並不等於 attention 輸入遮罩。
必要公式：lₙ=−log softmax(xₙ)[yₙ] × 1[yₙ≠ignore_index]；mean=Σlₙ/Σ1[yₙ≠ignore_index]。
