Scaling is alpha/r: 1 for the lesson and exercise; also tested 0.5 with a nonzero synthetic correction, max row/column error 2.384185791015625e-7 against rtol=atol=1e-6.

For L=sum of outputs, with s=alpha/r, dL/dA = s sum_i B.T 1 x_i.T, while dL/dB = s sum_i 1 (A x_i).T. At B=0 the A gradient is zero. A random nonzero A and the seeded inputs give nonzero B gradients. This does not assert nonzero B gradients for every possible input/loss. Backward alone changes no parameter values. A single synthetic SGD step changes B while preserving the original W/bias and leaves A unchanged on that first step; a second backward produces a nonzero A gradient. This bounded variant is not style training.
