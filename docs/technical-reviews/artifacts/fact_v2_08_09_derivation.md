# 8.9 independent derivations

For a fixed frozen base weight W (out,in), A has shape (r,in), B has shape (out,r), and s=alpha/r. With row-vector x, unmerged y=x W^T+bias+s(x A^T) B^T. In exact arithmetic this equals x (W+sBA)^T+bias. The original bias is unchanged. This equality describes a linear LoRA branch; it does not prove any trained style quality.

1. Base binding: if a different model has W_new=W+E, applying the same adapter produces W+E+sBA, differing from the trained effective matrix by E. Matching tensor shapes only establishes conformability, not identical features or weights. This is the equation-level reason for retaining a base identity as well as module names and scaling metadata.
2. Alpha: fixing A, B and rank r=2, s(alpha=4)=2 and s(alpha=2)=1. Their correction ratio is 2. For the filled A=0.2 and B=-0.1, each BA entry is two products: (-0.1)(0.2)+(-0.1)(0.2)=-0.04; the respective ideal correction entries are -0.08 and -0.04. CPU FP32 execution gives -0.08000000566244125 and -0.04000000283122063; this is representational rounding, while torch.equal(delta4,2*delta2) is True.
3. Double apply: merging once gives W_merged=W+sBA. Adding the same nonzero correction again gives W+2sBA, not W+sBA. This algebra does not assert every possible input produces different logits; a zero correction or a correction nullspace can produce identical outputs.
4. Toy averages: B has shape (3,2), six entries initially filled 0.1. The real-number mean is 6*0.1/6=0.1; torch.float32 returns 0.10000000149011612, which round(...,2) displays as 0.1. A clone has independent data storage. Copying both saved matrices restores exact stored tensor values. Omitting A leaves filled 0.2 instead of the original Gaussian draw, so the A-and-B comparison is False while the B mean still prints 0.1.
5. Formal denominators: the probe has 1 batch, 9 positions, vocabulary 264, so the maximum is over 1*9*264=2376 logits. It is not a maximum over the held-out datasets. The archived CUDA merge maximum 6.67572021484375e-06 is 0.00000668 to eight decimal places; it is less than 0.0001. CPU fresh merge and saved GPU merge need not share this value because finite arithmetic, operation order and backends differ.
