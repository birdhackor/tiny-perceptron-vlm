2.4 獨立數學核對，2026-10-03

D1 純量合成：第一層 u=2x，第二層 y=3u，因此 y=3(2x)=6x。

D2 含偏移的多特徵合成：以每筆輸入為列向量，第一層
h=xAᵀ+c，第二層 y=hBᵀ+d，其中 A∈R^(m×n)、B∈R^(p×m)。
代入得 y=xAᵀBᵀ+cBᵀ+d=x(BA)ᵀ+(cBᵀ+d)。
故合成層的權重為 BA∈R^(p×n)，偏移為 cBᵀ+d；多層依此歸納。
這是實數算術中的仿射恆等式，不保證不同浮點計算路徑逐位相同。
PyTorch 類名 Linear 接受 bias，數學上有非零 bias 時稱仿射；正文以 API 類名使用。

D3 三點不可由單一仿射直線同時表示：y(0)=0 迫使 b=0；
y(2)=2 迫使 k=1。此時 y(-2)=-2，而目標為2，矛盾。
等價地，左右兩段斜率為 (0-2)/(0-(-2))=-1 與 (2-0)/(2-0)=1。
仿射函數 y=kx+b 在所有區段只有固定斜率 k。

D4 原例 A=[[1],[-1]]，B=[[1,1]]，BA=[[1-1]]=[[0]]。
每筆 x 的隱藏列為 [x,-x]，直接加總 x+(-x)=0。
ReLU 後為 [max(0,x),max(0,-x)]，加總為 |x|：
x<0 時第一項0、第二項-x；x>=0 時第一項x、第二項0。
x=-2,0,2 對應 hidden=[[-2,2],[0,0],[2,-2]]，
ReLU hidden=[[0,2],[0,0],[2,0]]，linear=[0,0,0]，curved=[2,0,2]。
零點左右斜率不同，零點本身不可微；本節不計算該點的導數。

D5 練習：將最後 x=2 改為3，hidden 最後列=[3,-3]，
直接相加仍0，ReLU後=[3,0]，相加3；全列 curved=[2,0,3]。
再移除 ReLU，所有列回到 x+(-x)=0，即 [0,0,0]。

D6 表達能力與學習：D3-D4 展示這個架構加入非線性後能表示 |x|，
不表示任意非線性與任意寬度必然改善所有架構，也沒有訓練品質／速度實測。
較大隱藏層和平滑激活是可用設計；ReLU本身不是全域平滑，亦無所有模型都使用平滑激活的結論。
梯度表示局部敏感度；輸出記錄 grad_fn 並不表示已呼叫 backward 或更新參數。
