定位與核對：
1. §1，印刷頁 8424–8425：研究對象是文字語料中的重複、近重複及跨訓練／驗證集合的內容重疊。我的核對結論是：這種重疊會讓擅長記住已見內容的模型在評估與設定選擇時佔優勢；不能據此推論新材料能力。支持 1.2 的 c6、c10、c12。
2. §4.1，印刷頁 8426：方法比較兩筆文字的連續子序列，處理文件只有局部內容重複的情形。可用自己的索引符號表示必要關係：對某個長度 L，x_i[a:a+L] = x_j[b:b+L]。作者在其工程方法採 50 個 token 的最低匹配長度；這不是本課三字玩具例的評估規則，也不是所有語言或文件的普遍閾值。支持 c8 的局部內容重疊機制及 c12 的限制。
3. §4.2，印刷頁 8427：另一方法將文件轉成 n-gram 集合並估計相似度，用來辨識未必逐字完全相同的文件。我記下其所用集合比值：J(A,B) = |A∩B| / |A∪B|。這個公式以集合交集與聯集的大小量化近似重疊；它不是模型語義理解的量測。支持 c23 對近重複家族的處理需求。
4. §5.3，印刷頁 8429：作者檢查訓練與驗證文字間的重疊，說明重複內容可能讓偏向記憶的模型得到較樂觀的評估。我的報告只引用此污染機制，沒有把論文中的資料比例或模型分數移植到教材小例子。支持 c8、c10、c12、c23。
5. §8，印刷頁 8431–8432：結論尤其要求避免訓練與測試集合間的重複內容，因為重疊會影響模型選擇。支持 c12。
