1. Chaudhry et al., On Tiny Episodic Memories in Continual Learning
原文：https://arxiv.org/pdf/1902.10486v4
版本：arXiv:1902.10486v4，2019-06-04。
下載 PDF SHA-256：49fd308f26477c8a2861befc0b0fed727a6f745b6d0a0c11434a50a3b5255c6d
原 PDF 只留於 ignored outputs/technical-sources/7.16-fresh/chaudhry-v4.pdf；公開證據為本筆記。
親讀定位：§1（pp.1–2）、§3.1–3.2（pp.2–3）、§4/Algorithm 1（pp.3–4）、§5.1–5.5（pp.5–8）、Appendix D/Table 8（p.15）。
§4、Algorithm 1 lines 5–8：抽取當前任務及記憶中的原始樣本，以當前 θ 聯合計算一次梯度更新；記憶儲存樣本，並非預錄梯度。相同大小兩批時可寫 g_ER=(g_new+g_memory)/2。正文使用固定四筆配方，是此機制的一種有界混合例，沒有宣稱與論文所有配置一致。
§3.2 Eq.(1)：A_T=(1/T)Σ_j a_(T,j)，a_(i,j) 是完成任務 i 後，於任務 j 留出集的成績；Eq.(2)–(3) 記錄舊任務之前最佳成績與現在成績的差。這支持前後測量各任務，不能只看新任務或混合總分。
§4 明定原論文將當前 batch 與同樣大小的記憶 batch 合併，故總 batch 翻倍；§5.2 的兩個 batch 都為 10；§5.3 為比較 SGD 更新數另調整 MER；Table 2（p.7）另報時間。原論文不支持「相同步數即可等成本」；教材額外要求記錄有效 token 與計算，是合理的控制變量要求。
§4 記憶寫入策略：ring buffer 保證各類別數量；k-means 追蹤特徵空間代表；MoF 追蹤均值代表。§5.4（pp.6–7）指出極小 reservoir 可能淘汰整個舊類別，增加遺忘；對很小的記憶，保證類別覆蓋的策略較佳。這只支持「有覆蓋且代表性佳的樣本可能更有效」，沒有建立每一份 LLM 語料的品質排序。
§5.5（pp.7–8）：只把記憶題 loss 降低可強烈記憶並在留出題表現差；應檢查舊任務留出題。也不能反過來斷言反覆練極小記憶必然傷害泛化，因該研究的聯合訓練確實可改善泛化。教材說重複單例不增加覆蓋，沒有宣稱重複必然無效。
§5.5（p.8）顯示任務關係與新任務資料量影響 replay；旋轉後近乎對抗的任務可能傷害舊任務，沒有 universal retention 保證。Appendix D/Table 8 親讀列出各基準及方法的 learning-rate 選擇，與 §5.1 的交叉驗證程序一致；Figure 1 的結果另平均五次、Figure 3 平均三次，支持保留配方和種子資訊。§5.1–5.2 是小型監督影像分類、task-specific heads，不能把其準確率或時間直接套成本課 byte SFT 或一般語言模型品質。

原文：https://arxiv.org/pdf/1706.08840v6
版本：arXiv:1706.08840v6，2022-09-13；NeurIPS 2017 論文的該修訂版本。
下載 PDF SHA-256：ddbc9c87d310b092b8621d47aeae1f97f4f664fd061e2406e944d0f9921cbb37
原 PDF 只留於 ignored outputs/technical-sources/7.16-fresh/gem-v6.pdf；公開證據為本筆記。
親讀定位：§1（pp.1–2）、§2（pp.2–3）、§3/Eq.(5)–(8)/Algorithm 1（pp.3–5）。
§1：對同一可調模型逐任務更新可能降低舊任務成績，並非一定降低。§2 用整個前後任務測試矩陣 R：R_(i,j) 是學完 i 後於任務 j 的測試成績。Eq.(3) 的 BWT=(1/(T−1))Σ_(i<T)(R_(T,i)−R_(i,i)) 區分舊任務變化；新任務成績另見 R_(T,T)。
§2 task descriptors：相同輸入可在兩任務要求不同標籤；缺少可辨識的任務線索時目標本來就會衝突。§3 Eq.(7) 的 g·g_old<0 表示當前參數方向在小步、局部線性條件下增加舊任務代價，支持需要平衡共享參數信號。GEM 是梯度投影方法，與本文一般 replay 不能混為同一演算法。
§3 Eq.(5) 的記憶題平均代價與留出任務成績不同；以訓練記憶的平均 loss 不足以宣稱全任務保留。該文對 direct memory 訓練過度擬合的看法，由上一來源實證修正，本文以實際留出驗證為準。
