## Independent arithmetic and annotation reasoning

1. `2+2 = 4`. A pair of chopsticks contains two sticks; two such pairs contain `2×2 = 4` sticks. Thus both fixed answers contain the right sum. Under “only a number”, A is exactly `4` while B adds a comma, prose and punctuation. The stated rubric therefore picks A. Removing the restriction does not logically mandate B: a new rubric and human decision are required.
2. The Cartesian product `{0,…,7}²` has `8×8 = 64` ordered questions. There are 8 diagonal families with one question each and `8×7/2 = 28` off-diagonal families with two questions each: `8 + 28 = 36` families and `8 + 2×28 = 64` records. A family is `(min(a,b),max(a,b))`, so `2+3` and `3+2` share it.
3. Independently sort the 36 family keys, shuffle with Python `random.Random(42)`, take first 28, next 4, last 4 families. The first group has 7 diagonal and 21 off-diagonal families: `7+2×21=49` records. Validation has four off-diagonal families: `2×4=8`. Test has diagonal `2+2` and off-diagonal `2+4`, `0+1`, `0+7`: `1+2×3=7`. This is a seed-specific outcome, not an invariant of the 80/10/10 family fractions.
4. For a genuine tie with target probability 1/2, binary cross-entropy's derivative with respect to the comparison logit z is `sigmoid(z)-1/2`. At z=0 it is zero. If a random forced winner replaces the tie, the derivative at z=0 is +1/2 or -1/2, each with probability 1/2: mean 0, variance 1/4. This proves the precise label-noise point; arbitrary systematic ranking could instead create bias. Conflicting length/fun rubrics similarly supply incompatible labels for the same conditional pair; no universal human agreement or measured noise rate is claimed.
5. Relative ranking does not imply absolute acceptability. A counterexample is two safety labels `(False,False)` with a chosen index of either 0 or 1; the selected absolute label remains False. Saving explicit rubric/reason permits a reviewer to distinguish formatting and content criteria, but does not itself prove the annotation correct.
