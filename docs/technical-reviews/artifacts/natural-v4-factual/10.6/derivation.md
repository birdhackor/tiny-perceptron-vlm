# 10.6 independent derivation

For X of shape [B,P,H_in], an nn.Linear with W of shape [H_out,H_in] and b of shape [H_out] returns Y[b,p,j] = sum_i X[b,p,i] W[j,i] + b[j]. The same W and b are used for every b,p. Thus B=1, P=16, H_in=8, H_out=12 gives [1,16,12] and W=[12,8]; changing H_out to 10 gives [1,16,10] and W=[10,8]. Feature width neither denotes nor changes image count or patch count. Default bias is present, already explained by the explicitly linked W.5.

A downstream fixed input width 12 cannot contract its 12-element axis with a 10- or 16-element axis; a [1,16,12] tensor also cannot broadcast-add to [1,16,10] or [1,16,16]. These concrete operations are exercised and their real exceptions saved. Changing image spatial size alone does not fix a feature-width mismatch with an unchanged encoder/projector interface.

For column x=[1,2]^T choose W=[[1,0],[0,1],[1,1]], a 3x2 matrix. W x=[1*1+0*2, 0*1+1*2, 1*1+1*2]^T=[1,2,3]^T. In PyTorch row convention, x @ W.T gives the same vector. This particular W has two independent columns; output coordinate 3 is coordinate 1 plus coordinate 2. Three displayed numbers are not three independent observations. For any 12x8 W the image of the affine map lies in b+col(W), dimension rank(W)<=8, not twelve independent input degrees of freedom.

If a visual encoder maps a red image and a blue image to the same z, then fixed projection gives Wz+b in both cases; subtraction yields (Wz+b)-(Wz+b)=0 for every output width. A fixed downstream model with identical text and other context then receives the same visual evidence and produces the same conditional output distribution. Sampling can differ, but no reliable association with the hidden red/blue label follows. This is an information limit on the provided evidence, not a denial of the language model's previously learned priors.

Matching width alone also does not imply semantic correspondence. With hypothetical red=[1,0], blue=[0,1] and a downstream coordinate convention [red-score,blue-score], identity preserves the intended meanings but W=[[0,1],[1,0]] swaps them. Both have the correct width. A random initialized projector need not coincide with the required meaning-preserving map. In the specific caption-supervised alignment route described, paired image/caption losses constrain what mappings improve language behavior; LLaVA §4.1-4.2 supplies an original research implementation. Its training setup is not universal proof of successful grounding.

Independent prerequisite arithmetic: [[2,1,0],[1,2,1]] @ [[10,0],[20,1],[30,4]] = [[40,1],[80,6]]. Bias [5,0] gives [[45,1],[85,6]]; changing it to [8,0] increases only each cost by 3, giving [[48,1],[88,6]]. For scene RGB 16x16 with 4x4 patches, patchify produces (16/4)^2=16 positions and 3*4*4=48 values per position. Linear(48,8) gives [1,16,8], W=[8,48]; Linear(48,16) gives [1,16,16], W=[16,48]. These prerequisites were actually executed on CPU as a supporting interface/arithmetic check, not reported as newly trained visual representations.
