# 1.12 本輪獨立推導

L(w)=(w−3)^2，dL/dw=2(w−3)。w=1時L=4、g=−4。
一步更新w'=1−η(−4)=1+4η；L(w')=(−2+4η)^2=4(1−2η)^2。
η=.1→w'=1.4,L'=2.56；η=.6→w'=3.4,L'=.16；η=2→w'=9,L'=36。
同一個正確導數g=−4在三例保持不變；過大的η能使有限步結果變差。
本平方例要嚴格下降需0<η<1（此推導只對本例，沒有宣稱所有模型都有同一閾值）。

軸與單位：w、before、after、w.grad皆是零維純量，無batch或feature軸。
w是無物理單位的教學參數，L是其平方距離；梯度為代價／參數，η把梯度換成參數位移。
本平方例沒有平均或除法分母，不能與接字實驗的平均cross-entropy相當。
PyTorch預設float32，w與L相對上述實數算術使用abs<=1e−6；before=4與g=−4精確相等。

查表有界替代只更新一次：weight[3,3]的列=目前字、欄=下一字候選；
inputs[2,1]的軸=兩個位置×一字前文，logits[2,3]的軸=位置×候選。
cross_entropy預設mean，分母為2個有效目標；自然對數代價為nats／目標。
