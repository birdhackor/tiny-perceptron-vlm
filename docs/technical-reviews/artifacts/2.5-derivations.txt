2.5 透明推導與成立範圍（2026-10-03）

資訊未交給模型：令兩筆真實前文不同，但可見輸入均為x，答案分別圓、方。固定參數且無其他可辨識狀態時，同一函數p(.|x)只定義同一候選分配。若用獨立於顏色的抽樣，兩題各一半出現時正確率=(q(圓|x)+q(方|x))/2≤1/2；擴模型或更久訓練都不能從完全相同x穩定分辨這兩題。此結論不排除偶然兩次都猜中，不涵蓋額外輸入、隱藏狀態、題號、不同模型參數等側資訊。

原例字位：紅/藍(1)、色(2)、物(3)、體(4)、是(5)。取最近1字是「是」，最近3字是「物體是」，最近4字是「色物體是」，最近5字才保留紅／藍。看到不同輸入只是排除這種資訊不可區分，並非保證優化、資料充分或泛化成功。
練習字位：紅/藍(1)、色(2)、的(3)、小(4)、小(5)、物(6)、體(7)、是(8)。C=8起點0可見紅／藍；C=7起點1均為「色的小小物體是」。Python切片按Unicode code points計，本例無多code point字素。

拼接：C排各D項，共CD項，位置順序保留。dense Linear 接H輸出，每個輸出對每個輸入有一個權重，共HCD；若開啟bias另H項。固定D、H，直接矩陣乘加的項數亦隨C增加；不將這個算術外推為任何GPU實測速度。
D=2，C=3時輸入6、權重6H；C=6時輸入12、權重12H，權重比2。加入H偏置後的總參數比一般不正好2，教材已限定是輸入層權重。
本實驗V=17、D=16、hidden輸出H=16。總參數=VD+(HCD+H)+(VH+V)=272+(256C+16)+289=577+256C。
C=1：833；C=3：1345；C=5：1857。每加兩字多512個hidden權重；窗口與容量同時改變，不能據此隔離單一原因。
