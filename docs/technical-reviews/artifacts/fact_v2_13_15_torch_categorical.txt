   13: class Categorical(Distribution):
   14:     r"""
   15:     Creates a categorical distribution parameterized by either :attr:`probs` or
   16:     :attr:`logits` (but not both).
   17: 
   18:     .. note::
   19:         It is equivalent to the distribution that :func:`torch.multinomial`
   20:         samples from.
   21: 
   22:     Samples are integers from :math:`\{0, \ldots, K-1\}` where `K` is ``probs.size(-1)``.
   23: 
   24:     If `probs` is 1-dimensional with length-`K`, each element is the relative probability
   25:     of sampling the class at that index.
   26: 
   27:     If `probs` is N-dimensional, the first N-1 dimensions are treated as a batch of
   28:     relative probability vectors.
   29: 
   30:     .. note:: The `probs` argument must be non-negative, finite and have a non-zero sum,
   31:               and it will be normalized to sum to 1 along the last dimension. :attr:`probs`
   32:               will return this normalized value.
   33:               The `logits` argument will be interpreted as unnormalized log probabilities
   34:               and can therefore be any real number. It will likewise be normalized so that
   35:               the resulting probabilities sum to 1 along the last dimension. :attr:`logits`
   36:               will return this normalized value.
   37: 
   38:     See also: :func:`torch.multinomial`
   39: 
   40:     Example::
   41: 
   42:         >>> # xdoctest: +IGNORE_WANT("non-deterministic")
   43:         >>> m = Categorical(torch.tensor([ 0.25, 0.25, 0.25, 0.25 ]))
   44:         >>> m.sample()  # equal probability of 0, 1, 2, 3
   45:         tensor(3)
   46: 
   47:     Args:
   48:         probs (Tensor): event probabilities
   49:         logits (Tensor): event log probabilities (unnormalized)
   50:     """
