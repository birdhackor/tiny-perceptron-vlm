# tiny-perceptron-vlm 的背景與核對

本文件保存本課背景、操作與專案約定，供作者、協調者及技術審閱者按需要查核。通用教學判準以 [SKILL.md](../SKILL.md) 為準；這裡不保存特定課文的改寫答案，也不代表本輪已驗收。

首次閱讀者不提前取得下方技術與操作參考。協調者依實際入口設定讀者背景，只提供已讀的必要前文，不能把本文件中的資訊算作讀者已經理解。

## 讀者與閱讀路線

- 未另指定時，面向數學不錯的高中生，或有基本數學能力但不熟的大學生。依[閱讀路線](../../../../course/README.md)及[暖身](../../../../course/first-steps.md)設定本次必要背景；Python、tensor、機率、矩陣與梯度可按需回查，不假定讀者熟悉機器學習術語或開發歷史。
- 順序閱讀可用實際已教的必要前文；跳讀另記提供的先備。前置連結供找路，不能取代當前推理需要的正文說明。
- 文字、圖片、聲音與工具各有局部教學例子，不要求每節追蹤同一個模型。第 19 章才驗收自行訓練的整合，第 20 章是成熟模型的延伸應用。

## 工作階段與成品分工

完整改版沿用[六階段原規約](../../../../docs/course-revision-20261005/README.md)的先後關係：大綱、新增教材、既有教材改寫、三輪審閱、必要的成品工程與訓練、事實回填及發布。同一階段可分工；本輪的實際階段與範圍依使用者指示及對應工作計畫，不把較早批次當成新任務自動重做。保留的 [MTP／蒸餾批次計畫](../../../../docs/course-revision-20261007-phase7/PLAN.md)屬其指定修訂範圍。

只分析、審閱、改 skill、修文句或局部維護時，完成已授權範圍及相應核對，不因此啟動全書改寫或成品訓練。只審凍結稿可依通用流程保存三類證據；完整改版已指定的三輪先後及修正門檻仍依本輪約定。

- 主線整合的文字、視覺、語音與接頭神經權重由本課自行訓練；固定的前處理與計算工具是程式，不把成熟模型藏成主線零件。已有的 Qwen／Whisper 路線明確放在延伸，上游能力不代替主線驗收。
- 成熟方法的機制、用途與條件核對原論文、官方文件與可靠教學，不要求本課小模型重證論文收益。短例子建立直覺或驗證實作，正式能力宣稱查對應資料與評測；小實驗不理想時核對條件，不據此否定成熟知識。
- 只保留對理解或結論範圍有用的數字與失敗，完整配方另存。skill、排版與文字更新不觸發 GPU 重訓；模型、資料、實作或能力主張改動才做相應驗證。

- 首讀紀錄在 `docs/reader-reviews/`，技術在 `docs/technical-reviews/`，銜接在 `docs/continuity-reviews/`；凍結與分組證據依[目前 active 批次](../../../../docs/course-reviews-active.json)及其引用的 manifest。歷史問題由協調者在獨立初判與交叉覆核後比對，不提前放入閱讀包。

- 修改教材時按範圍重建 Notebook、核對正文與圖的版本，完成受影響的讀者、技術、銜接、程式與閱讀時間檢查；操作依[發布說明](../../../../docs/publishing.md)。只改本 skill 時查文件、來源與連結，不宣稱既有教材已依新標準通過。

- 網站、資料包與權重是不同發布材料。發布後按本課規約核對公開 commit、下載入口與配套版本；固定 HF revision、資料 manifest 及歷史結果不隨文字改版覆寫。存放與授權依[資產管理](../../../../docs/asset-storage.md)。

## 技術與證據核對的位置

以下只定位本課常見核對方向，不是每節必教清單，也不提供待審段落的答案。具體主張仍查當前實作及原始來源：

- 張量的軸、順序、dtype、mask、位置與答案編號依當前例子、API 和資料約定核對，圖、公式與程式須對應；陌生約定不能靠相同數值猜出。
- [預設訓練入口](../../../../scripts/train.py)可只做 forward／backward 的 dry run；正常結束或梯度存在不代表權重已更新。依當次模式與紀錄判斷，另查訓練後成果及留出資料。
- 文字回答的內容、指定範圍、格式、停止與工具行為分開查；多模態輸入通路能運作，不單獨證明模型真的利用該模態。成熟模型與自訓練模型的證據各對應自己的版本和材料。
- 局部實驗查[固定實驗](../../../../docs/course-experiments/README.md)及[驗證範圍](../../../../docs/validation.md)；整合成果查[第 19 章 v2 最後測試](../../../../docs/selftrained/results/v2-final-public-results.json)，成熟模型延伸查其[學生指引](../../../../docs/natural-assistant/v4/STUDENT.md)。不把舊合成結果當成新成品能力。
- 下載指紋吻合只證明檔案相同；公開推論權重與完整續訓 checkpoint 用途不同。配套、設定、tokenizer、資料及狀態依[資產管理](../../../../docs/asset-storage.md)與相應訓練指引查核，不從模型檔存在推斷可精確續訓。
- CPU、MPS、GPU、kernel 與 Colab 的實際驗證範圍分開，設備與計時邊界依當次證據，不把一種環境跑通當全部平台通過。安裝與套件版本查[環境說明](../../../../docs/environment.md)及[目前 README](../../../../README.md)，不在 skill 複製易過期的版本表。
