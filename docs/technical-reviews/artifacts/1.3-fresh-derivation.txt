一、配對與長度
令原序列 s=(s_0,…,s_{n-1})，n≥2。x=s[:-1]=(s_0,…,s_{n-2})，y=s[1:]=(s_1,…,s_{n-1})。
所以 len(x)=len(y)=n-1，且每一題 (x_i,y_i)=(s_i,s_{i+1})，0≤i≤n-2。
本節「右移一格」指答案取自原序列右鄰 i+1，並不是把 y 整個 list 往右做 in-place 移動。
貓看狗。的 n=4 → 3 題：(貓,看),(看,狗),(狗,。)；s_3 的句號無 s_4，所以未作問題。
鳥飛。的 n=3 → 2 題：(鳥,飛),(飛,。)。
若 y=x，則每題變成 (s_i,s_i)，兩邊仍長 n-1；只核對長度無法偵測此任務錯配。
在以配對答案為正確目標的損失中，恆等函式 g(s_i)=s_i 恰好符合這份錯標資料。
這是目標設定的邏輯結果，沒有聲稱某次訓練必然收斂，也沒有用短執行外推品質。

二、ID 保留位置
固定字到 ID 的對應 f，令 t_i=f(s_i)。則 t[:-1]_i=f(x_i)，t[1:]_i=f(y_i)。
因此編碼後的第 i 題仍是 (f(s_i),f(s_{i+1}))；字的數值 ID 改變不會改變原序列的相鄰關係。
本次小句字表 {。:0,狗:1,看:2,貓:3} 產生 (3,2),(2,1),(1,0)，CPU 執行也核對完全相等。
前置1.1圖使用較長原句的五字表，逗號加入後 ID 是 {。:0,狗:1,看:2,貓:3,，:4}。
