# 有限樣本修正文句的核對

新版僅將有限樣本「不會恰好等於理論值」改為「通常有抽樣誤差，所以不必恰好等於理論值」。
其餘頁面內容與 Python fence 均未變。改寫前後的逐位元組比對、凍結與現行來源雜湊，
以及本次原始小節與補充程式的執行收據見 recheck-evidence-current-01.json 與
section-run-current-01.json；舊證據全部維持原檔與原 SHA-256。

設 S 為 D 個獨立等機率 ±1 乘積的加總。E[S]=0、Var(S)=D，故
Y=S/√D 的母體標準差為 1。有限樣本的 std() 計算的是
s=√(Σ(Y_i-Ȳ)²/(n-1))，本例 n=1000，分母為 999。公式中每個 Y_i 都依抽樣而變，
沒有代數等式要求 s 必定等於母體標準差。

本次再次執行原始 fence，D=4 時 s=0.979770839214325，
D=64 時 s=0.9736785888671875；各自與 1 的差約為 -0.02023、-0.02632。
這些是當次抽樣得到的估計差，既不是母體方差推算錯誤，也不是全體樣本的誤差界。
未縮放值則分別為 1.95954167842865 與 7.7894287109375，仍靠近 2 與 8。

反過來，有限樣本也可能精確相等：在 n=1000、D=64 下，取分數 +8、-8 各 497 個，
+12、-12、+4、-4 各一個，以及兩個零。總和為零，平方和為
994×64+2×144+2×16=63936=999×64，因此未縮放的樣本標準差精確為 8，
縮放後精確為 1。所有分數都能由 64 維 ±1 向量的點積得到；指定完整陣列在獨立
公平符號模型下的機率非零。這是存在性反例，並非聲稱 seed=42 會抽出該陣列。
本次重跑原有 verify_claims.py 再次逐格驗證該反例，輸出與舊證據完全相同。

因此新文句的「通常有抽樣誤差」表達有限樣本估計會隨抽樣起伏，「不必恰好等於」
同時容許當次有誤差及偶然精確相等；沒有把有限樣本寫成絕不可能相等。
這個判斷依母體與樣本標準差的定義、指定抽樣模型、當次執行與存在性推導，
不把少量執行外推為所有種子、裝置或版本的誤差機率保證。
