# 本人算式與軸核對

令 R=[[2,1,0],[1,2,1]]，W=[[10,0],[20,1],[30,4]]。
C[i,j]=sum(R[i,k]*W[k,j] for k in range(3))。
第一列成本 2*10+1*20+0*30=40 分；甜度 2*0+1*1+0*4=1 假想單位。
第二列成本 1*10+2*20+1*30=80 分；甜度 1*0+2*1+1*4=6 假想單位。
收縮的是材料軸 k 長度 3，留下店／杯軸 i 長度 2 與指標軸 j 長度 2。
每個值三項加總，不除以 3、不做 batch 平均。

Linear weight 儲存 A=W.T，shape=(2,3)，因此 R @ A.T + b = R @ W + b。
b=[5,0]：[[40+5,1+0],[80+5,6+0]]=[[45,1],[85,6]]。
b=[8,0]：[[40+8,1+0],[80+8,6+0]]=[[48,1],[88,6]]。
兩次 bias 差值 [3,0]，對每杯相同。

只把 R[0,2] 由 0 改為 2：第一杯增加 [2*30,2*4]=[60,8]，成為 [100,9]；第二杯 [80,6] 不变。
本次 exact integer sums 與 torch float32 均精確相等；容忍差 0。
