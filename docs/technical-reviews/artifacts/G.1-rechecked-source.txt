## G.1 文字與數字怎麼對上

拿「貓看狗」作例子。先把可用字排成一份清單，約定「狗」是 0、「看」是 1、「貓」是 2；原句便寫成 `[2, 1, 0]`。這些編號叫 ID，只負責指出位置，不表示貓比狗大。如果再拿 ID 2 去查一張數字表，取出 `[0.2, -0.1]`，這一排可調整的數字才是 embedding，中文常說嵌入向量。編號與向量是兩個步驟，不能混為一談。

| 名詞 | 在例子裡做什麼 | 完整講解 |
| --- | --- | --- |
| ID、編碼與解碼 | 字轉編號，再按同一約定換回字 | [1.1](chapters/01.md#1.1) |
| token、tokenizer | 把文字切成模型處理的小單位；小單位未必是一整個字 | [6.1](chapters/06.md#6.1)、[6.7](chapters/06.md#6.7) |
| embedding | 用 ID 查出一排可學習的數字 | [2.1](chapters/02.md#2.1) |
| tensor、shape | 數字的集合，以及每個方向有幾格；兩列三欄就是 shape `[2,3]` | [W.3](first-steps.md#W.3) |
| Linear、activation | 用加權配方混合數字，再加入不能只靠直線表達的變化 | [2.3](chapters/02.md#2.3)、[2.4](chapters/02.md#2.4) |

「一張字卡」只是 token 的第一個譬喻。當切法換成位元組，同一個中文字可能拆成幾張卡；當切法合併常見片段，一張卡也可能放好幾個字。閱讀時要問「這裡採哪種切法」，不能看到 token 就一律算中文字數。

試著回答：`2` 與 `[0.2, -0.1]` 哪個是 ID、哪個是向量？前者指出要查的位置，後者才是查回的數字。若仍分不清，建議先讀 1.1，看看文字如何換成編號；再讀 2.1，看看如何用編號查出一排向量。
