## G.3 模型如何混合線索

看到「那隻狗追著球，它跑得很快」，先暫把每個字看成一格，「目前位置」就是正在處理的「它」那一格。實際模型每格放一個token，也就是切分後的文字小單位；一個字可能拆成多格。每格文字先換成編號，再查表取得一排數字，這排數字就是文字特徵，讓模型能用數字處理文字。

模型把每格的特徵交給三套可學習的加權配方，分別產生Q、K、V。「它」那格的Q與可讀各格的K比較，例如前面「狗」與「球」所在格的K，得到每格的讀取比例，再按比例混合各格的V。attention，也就是注意力，是這套比較、計算比例、再混合數字的方法。「查筆記」可以幫你記住流程；哪些格真能提供正確線索，仍要用模型的實際結果檢驗。

| 名詞 | 在流程裡的角色 | 完整講解 |
| --- | --- | --- |
| Q、K、V | 查詢用的數字、供比較的數字，以及要取回的內容數字 | [3.3](chapters/03.md#3.3)、[3.4](chapters/03.md#3.4) |
| causal mask | 擋住目前位置之後的答案，避免訓練時偷看 | [3.6](chapters/03.md#3.6) |
| padding、loss mask | 補齊長度的空位，以及哪些位置計入猜錯代價 | [7.6](chapters/07.md#7.6)、[7.3](chapters/07.md#7.3) |
| residual | 留住原數字，再加上這次處理的修正 | [4.2](chapters/04.md#4.2) |
| normalization | 調整數字尺度，使後續處理更穩定 | [4.3](chapters/04.md#4.3) |
| FFN | 對每個位置各自做特徵轉換的網路；本課先用兩個線性層和中間的非線性 | [4.4](chapters/04.md#4.4) |
| patch、projector | 圖片小方塊，以及把圖片特徵接到文字模型的轉接頭 | [10.2](chapters/10.md#10.2)、[10.6](chapters/10.md#10.6) |
| spectrogram、mel | 按時間看各頻率的強弱，以及把鄰近頻率分段彙整 | [12.5](chapters/12.md#12.5)、[12.6](chapters/12.md#12.6) |

頻率是聲音起伏每秒重複的次數，440Hz就是每秒440次；像單音這樣規律的聲音，頻率較高通常聽起來較高。spectrogram（頻譜圖）按時間顯示各頻率成分的強弱；mel則用一組有重疊的區段，將鄰近頻率加權彙整，得到每個時間段中各區段的強弱。前者讓你看各個頻率位置，後者把附近位置合成較少的區段。

幾種「遮罩」也要分開：不讓模型看未來，與不把某些位置列入考題，是不同工作。提示文字可能不算 loss，卻仍提供回答線索。試著用一句話說出「看得到」和「需要作答」的不同，再到[7.5](chapters/07.md#7.5)核對。
