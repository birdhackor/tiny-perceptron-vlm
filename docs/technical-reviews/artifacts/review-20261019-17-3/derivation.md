# 權重誤差的精確推導

令 W 的兩列為 (7/10, 1/5)、(-7/10, 6/5)。刻度 s=1/2，逐項 round(W/s) 得到整數值 (1, 0)、(-1, 2)；乘回 s 得 R=(1/2, 0)、(-1/2, 1)。本例沒有半整數的捨入平手問題，且沒有 int8 範圍截斷或整數儲存。

E=W-R 的兩列為 (1/5, 1/5)、(-1/5, 1/5)，四個絕對值均為 1/5。因此 MAE=(1/5+1/5+1/5+1/5)/4=1/5。先取絕對值可以防止正負抵消；這不表示帶符號的四格均值一定為零，本例其值為 1/10。

對以列向量儲存的一筆輸入 x，無 bias 的線性層給 y=xW^T。兩個模型若 bias 相同也會在差分時消掉。逐輸出座標有 y_j=Σ_k x_k W_jk，故 y_j-y'_j=Σ_k x_k(W_jk-R_jk)，合寫為 ΔY=X(W-R)^T。這是實數代數等式；分別計算再相減與先相減再相乘，在浮點實作中可能有末位差異。

輸入 (1,1) 時，原輸出 (9/10,1/2)，還原輸出 (1/2,1/2)，差為 (2/5,0)。輸入 (1,-1) 時，原輸出 (1/2,-19/10)，還原輸出 (1/2,-3/2)，差為 (0,-2/5)。所以單格權重絕對差 1/5 不是一般的輸出絕對差上限。

一般有 |Δy_j| ≤ Σ_k |x_k||E_jk| ≤ ||x||_1 max_k|E_jk|。輸入方向決定帶符號項如何相加；輸入乘常數 α，精確差分亦乘 α。把兩筆輸入乘 10，不改 W 或 R，因此 MAE 仍為 1/5，差變成 (4,0)、(0,-4)。FP32 中的十進位常數通常不能精確表示，數值核對用小於 10^-6 的容忍差；不把浮點尾數當作實數等式失敗。

MAE 不足以保證最後答案：固定下游映射 g(y)=ReLU(y)_0-7/10，再用 g(y)>0 作二元答案。第一筆輸入用 W 得 1/5，用 R 得 -1/5，答案改變；第二筆輸入兩者均得 -1/5，答案不變。這是包含啟用函式與固定讀出的反例，只證明權重 MAE 本身不能決定最終答案或任務品質，沒有聲稱任何實際模型的準確率變化。
