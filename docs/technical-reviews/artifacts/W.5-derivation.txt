W.5 自有數學核對筆記；日期：2026-10-03。

定義 R 的列索引 i 是店／飲料，材料索引 j 是紅茶、牛奶、糖；W 的列索引 j 是材料，欄索引 k 是成本、假想甜度。二維矩陣乘法定義 C[i,k] = Σ(j=0..2) R[i,j] W[j,k]。相同 j 的材料相乘後加總，i 和 k 留在輸出，因此沒有把不同飲料的材料相加。

R = [[2,1,0],[1,2,1]]，形狀 (2,3)。
W = [[10,0],[20,1],[30,4]]，形狀 (3,2)。
W[:,0] = [10,20,30]；W[:,1] = [0,1,4]。
C[0,0] = 2×10 + 1×20 + 0×30 = 20+20+0 = 40。
C[0,1] = 2×0 + 1×1 + 0×4 = 0+1+0 = 1。
C[1,0] = 1×10 + 2×20 + 1×30 = 10+40+30 = 80。
C[1,1] = 1×0 + 2×1 + 1×4 = 0+2+4 = 6。
結果 C = [[40,1],[80,6]]，形狀 (2,2)。一般二維形狀 (m,n) @ (n,p) 得到 (m,p)，內側 n 必須相同；這裡不用較高維的 batch 廣播規則。

nn.Linear 的儲存矩陣 A = W.T = [[10,20,30],[0,1,4]]，形狀 (2,3)。對本例而言 Y = R A.T + b，b 是長度 2 的向量，每列分別加同一個 b。
b = [5,0] 時 Y[0,0] = 40+5 = 45；Y[1,0] = 80+5 = 85；Y[:,1] = [1+0,6+0] = [1,6]。
練習 b = [8,0] 時 Y[0,0] = 40+8 = 48；Y[1,0] = 80+8 = 88；甜度仍為 [1,6]。
成本差分 [48-45,88-85] = [3,3]。沒有改動第二個 bias 分量，因此甜度沒有增加。

W.3 已讀必要前置圖的六格：[[60,70,80],[80,90,100]]。
每列三格平均：(60+70+80)/3 = 70；(80+90+100)/3 = 90。
每欄兩格平均：(60+80)/2 = 70；(70+90)/2 = 80；(80+100)/2 = 90。
圖的橫箭頭是 dim=1（沿每列跨三次小考），直箭頭是 dim=0（沿每欄跨兩位同學）。

以上為透明算例；假想甜度權重不代表飲料科學，兩間店也不是品質實驗樣本。CPU 執行只核對這組 float32 小矩陣及此 PyTorch 版本，不支持 GPU 速度、訓練品質或所有數值配置完全精確。
