SciPy signal tutorial Eq(3) has sinc(tau*(f-fx)); its first zeros around fx are separated from fx by1/tau. Smaller tau widens that main lobe, making nearby frequencies harder to separate for comparable window shape. Longer windows include a longer interval in the per-window transform (Eq8–9), reducing temporal localization. This is a qualitative time/frequency trade-off; neither a claimed universal frequency threshold nor an equivalence of FFT bin spacing and resolution.
For this fixed-length per-frame processing, overlapping slicing has8 frames versus4 disjoint frames. Downstream per-frame FFT/feature work generally increases; unfold itself returns a view and does not alter amplitude. No runtime/memory benchmark is claimed.
Overlapping frames reuse original recording points; they are not independent recordings. If the intended target is generalization to unseen recordings, recording IDs must not occur on both train and test sides, following grouped-data validation. This does not prove unseen-speaker generalization or impose this grouping on a different within-recording prediction task.
