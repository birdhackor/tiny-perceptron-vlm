# 6.5 可追蹤推導

對固定有效目標集合 I，令 p_i 是給正確 token 的條件機率，L = Σ_i −ln(p_i)，N = |I|，μ = L/N。因此 L = μN；只知道 μ 而不知道 N 無法恢復 L。

機率鏈式法則給 P(t_1,...,t_N | prefix) = Π_i P(t_i | prefix,t_<i)，無需各位置獨立。由 log 乘積法則，−ln P = Σ_i −ln p_i。本課的程式沿 tokenizer 選定的一條 ID 路徑計分，不做多條能解碼成相同原文路徑的機率邊際化。

換底 −log_2 P = (−ln P)/ln 2。令 B 是相同原文的 UTF-8 byte 數，BPB = L/(B ln 2)，計入 EOS 時 L 含其邊界代價、B 不含特殊標記。若改了文字、前文、EOS 或有效目標規則，應重新計算 L。

手算：10×0.6=6、5×1.0=5；0.5×0.25=0.125，−ln0.5−ln0.25=−ln0.125≈2.07944154。貓為 U+8C93（3 bytes），🙂為 U+1F642（4 bytes），合計 B=7；5/(7ln2)≈1.03049646、4/(7ln2)≈0.82439717。數字加倍時 BPB 加倍；同一手寫分子而 B 由7變14時 BPB 減半。這最後一步僅為公式算例，不能推論真模型對較長文字的總 NLL。

長文例中 A 是已知前文。第一窗計 B、C，第二窗只計 D；C 在第二窗只供條件，不能再加其 −ln p_C。有限視窗改變可讀前文，故須匹配比較政策；本次 256-byte 片段的實際輸入長度 byte 最大257、BPE最大198，均小於384。

限制：兩種字表的原文曝光與更新排程相同，不使參數數量、有效目標或運算量相同。這組資料上較低 BPB、更多生成字元或不同的隨機初始分數，均不推出普遍 tokenizer 優劣、最優字表大小或回答正確率。
