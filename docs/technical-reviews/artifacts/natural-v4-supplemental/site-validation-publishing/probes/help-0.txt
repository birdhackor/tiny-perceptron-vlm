usage: export_course.py [-h] [--output OUTPUT] [--executed EXECUTED]
                        [--revision REVISION] [--reading-times READING_TIMES]
                        [--reading-routes READING_ROUTES]
                        [--require-reading-times]

將教材與核對過的 Notebook 輸出整理成 Markdown，再由 Zensical 建置全站。

options:
  -h, --help            show this help message and exit
  --output OUTPUT
  --executed EXECUTED   獨立 kernel 執行副本；提供時嚴格核對每份教材與執行結果
  --revision REVISION   網站原始碼與 Colab 連結的 Git ref
  --reading-times READING_TIMES
                        外部 AI 估時 JSON；已提供資料會嚴格核對來源 SHA
  --reading-routes READING_ROUTES
                        以 canonical page IDs 定義的閱讀路線 JSON
  --require-reading-times
                        正式估時驗收：全部發布頁必須有目前來源與圖檔的估時
