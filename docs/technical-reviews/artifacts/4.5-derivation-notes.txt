4.5 獨立推導與範圍核對（2026-10-03）

令 A、F 分別表示本節 attention、FFN，N1、N2 表示各分支自己的 LayerNorm。
u = x + A(N1(x)); y = u + F(N2(u))。
主路的 x 沒有先被 N1(x) 替換；第二段保留的是已第一次更新的 u。
N1、A、N2、F 對本節 [B,T,D] 均輸出可相加的 [B,T,D]。
兩次加法只修正數值，不改 B、T、D，因此相同寬度的 block 可串接。

假設所考慮點存在導數，第一段 Jacobian = I + J_A(N1(x)) J_N1(x)。
post-norm 第一段若為 v=N1(x+A(x))，Jacobian = J_N1(x+A(x)) (I+J_A(x))。
第二段也有同樣的排列差異。這些公式只顯示圖與梯度路徑不同，
沒有推出所有權重下輸出必不相等，亦沒有推出 pre-norm 必定訓練更好。

已讀 4.2 的殘差图：x=[1,2]，f(x)=2x=[2,4]，
y=x+f(x)=[1+2,2+4]=[3,6]；對 y.sum() 每格梯度 =1+2=3。
標量計算為精確整數；實際 float32 CPU 原例也印 [3,6]、[3,3]。
這裡直接路不表示經過所有後續操作後仍能還原原文。

Q/K/V 各 [1,4,8]；重排為 [1,4,2,4] 再換軸成 [1,2,4,4]。
每頭 query/key 的 4×4 比例表兩軸都是位置；每頭輸出的 4×4 為位置×特徵。
拼兩頭最後特徵軸：4+4=8，輸出 Linear 後仍 [1,4,8]。
