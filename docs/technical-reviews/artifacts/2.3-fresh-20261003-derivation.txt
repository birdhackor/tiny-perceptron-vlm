2.3 獨立技術核對：手算與成立範圍（2026-10-03）

固定一次前向計算的權重 W 與偏移 b，輸出第 o 格為
y[n,o] = Σ_i x[n,i] W[o,i] + b[o]。
每個輸出使用 W 的一列；bias 對輸入 x 是常數，但本身仍是可訓練參數。
這是仿射運算；PyTorch 的介面名稱為 Linear。

原例 x=[1,2,4]，W=[[1,0,2],[0,-1,1]]，b=[1,0]：
y[0,0]=1×1+2×0+4×2+1=1+0+8+1=10。
y[0,1]=1×0+2×(-1)+4×1+0=0-2+4=2。
W 形狀 [2,3]，W.T 形狀 [3,2]；[1,3] @ [3,2] 為 [1,2]。
若使用未轉置的 [1,3] @ [2,3]，相接維度 3 與 2 不同。
上述乘加只有小整數，當次 CPU float32 可精確表示；實際核對差值為 0。
教材的 torch.allclose 仍是容許浮點誤差的比較，不是一般浮點恆等性證明。

練習只改 W[0,2]：2→3，ΔW[0,2]=1，故 Δy[0,0]=x[0,2]×1=4。
第一輸出為 1+0+12+1=14；第二列 W 與其 b 未變，第二輸出仍為 2。
結果為 [[14,2]]，與原例的差值為 [[4,0]]。

任意保留的前置索引 α：y[α,o]=Σ_i x[α,i] W[o,i]+b[o]。
式中沒有對 α 求和，所以每筆／每位置各自計算，共用 W、b。
因此 [2,4,3] 用 Linear(3,2) 得 [2,4,2]。
這裡的「位置」是保留索引；未展平時不會混合不同位置。
若每筆 C 個位置、每位置 D 個特徵，先依固定順序拼接為 C×D 格，
Linear 的 in_features 必須匹配 C×D，才能在一筆內對所有位置的格子加權。
已核對 2.2 的 B=2,C=3,D=2：每筆為 6 格，Linear(6,2) 得 [2,2]。

方陣沒有形狀保護的反例：
W=[[1,0,2],[0,-1,1],[2,3,1]]，x=[1,2,4]。
x W.T=[1+0+8,0-2+4,2+6+4]=[9,2,12]。
x W=[1+0+8,0-2+12,2+2+4]=[9,10,8]。
兩者形狀同為 [1,3]，數值不同；W 對稱時可以相同，教材只說「有時」。

有界求導核對（沒有參數更新）：L=10²+2²=104。
∂L/∂W[0,:]=2×10×[1,2,4]=[20,40,80]。
∂L/∂W[1,:]=2×2×[1,2,4]=[4,8,16]。
∂L/∂b=[20,4]，實跑 backward() 與此相同，W、b 原值未變。
求導與實際更新是不同動作；這只能驗證可學參數與梯度路徑。

額外的仿射層增加一套可調參數與一次計算，本身不保證泛化品質。
若中間沒有非線性：(x A1.T+b1) A2.T+b2
= x (A2 A1).T + b1 A2.T + b2，仍是仿射映射。
所讀 Bengio 2003 §2、式(1) 支持固定窗口拼接後加權與偏移；
§2 和 §4 以未參與訓練的資料評估泛化。這裡不移植其測得品質數字。
教材說「有機會把線索放進同一計算」，不能解讀為已學會詞義或語法。
