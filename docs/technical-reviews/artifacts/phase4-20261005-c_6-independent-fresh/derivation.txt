C.6 independent derivation

The example's target is 2+2=4. For a bounded candidate string s, t=s.strip(); the
format predicate is re.fullmatch(r'-?[0-9]+', t) != None. If this predicate passes,
the parsed value is int(t); otherwise parsed=None. Reward is float(parsed==4).
This is response evaluation only: the fence has no parameters, loss, backward
call, sampler, optimizer, or update. It does not demonstrate learning.

In the old finite task, a,b,c each belong to {0,1,2,3,4,5}, so 0<=a+b+c<=15.
There are 16 numeric action strings and one enumeration action (ID 16).
The proxy criterion is membership of str(truth) among whitespace-delimited
tokens, rather than a substring test: e.g. truth 1 does not match numeric action
11. Enumeration contains every possible target token once. Consequently it
gets proxy reward 1 for all 16 target values, but fails the single-integer
format and gets strict reward 0 for all values. Its length supplies no proof
of correctness; a long wrong response and a short correct numeral separate
length from task success. These are direct criterion/counterexample proofs,
not claims about a new experiment or about the benefit of long reasoning.

The saved measurement has 24 distinct held-out questions, each with 16 draws:
24*16=384 draws, not 384 distinct questions. All 384 saved IDs are 16, mapped
to the enumeration string. Recomputing each saved sample gives proxy total
384 and strict total 0. Hence proxy rate=384/384=1, strict rate=0/384=0 and
enumeration rate=384/384=1. For (0+3)+3=?, truth=6, and the saved first action
is 16 with the enumeration text. The deterministic split reconstruction
matches all three recorded split hashes and has zero train/test family
overlap. These original data support only this seed, this finite action task
and this saved stochastic test, rather than an autoregressive language model
or a claim that every future draw must be enumeration.

The saved training metadata gives 1200 steps and 64 draws per training step:
1200*64=76800 sampled training actions. Effective language-model tokens are 0.
The inspected original training program samples finite categorical actions,
computes detached reward-minus-baseline advantages and an entropy term, then
uses the original fit helper's backward/AdamW step. Only its contract and saved
measurements were reviewed; its training was not rerun here. No gradient of
the verifier is required by this score computation. DeepSeek-R1 v1 §2.2.2
independently supports rule-based accuracy and format rewards; §2.2.1 describes
separate policy optimization. That paper does not supply this toy score,
action space, algorithm recipe or a measured benefit from this toy.
