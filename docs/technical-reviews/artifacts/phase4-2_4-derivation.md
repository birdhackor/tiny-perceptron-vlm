# 2.4 reviewer-owned arithmetic and algebra

Reviewer: /root/phase4_factual_coordinator/factual_2_4. Access date: 2026-10-05.
This document is my own derivation, written after reading the current section and pinned official PyTorch originals. It does not reuse earlier review conclusions.

1. A scalar affine function y=k*x+b cannot pass through (-2,2), (0,0), (2,2). The middle point forces b=0. The left point then forces k=-1, while the right point forces k=1: a contradiction. The numerical example “multiply by 2, then by 3” has coefficient 3*2=6.
2. Let first-layer weight W1 have shape [H,D], second-layer W2 have shape [O,H], and row-major sample matrix X have shape [B,D]. With bias vectors c1=[H], c2=[O], Y=(X*W1^T+c1)*W2^T+c2 = X*(W2*W1)^T + c1*W2^T+c2. Equivalently the stored collapsed bias vector is W2*c1+c2. Thus two such affine layers remain affine. Repeating the substitution covers any finite compatible stack. This does not assert identical parameter counts, training dynamics, or constraints on a particular factorization. PyTorch calls this operation an affine linear transformation; the textbook explicitly includes the additive offsets.
3. In the section, W1=[[1],[-1]] ([2,1]), W2=[[1,1]] ([1,2]), so W2*W1=[[1-1]]=[[0]] ([1,1]). X=[[-2],[0],[2]] ([3,1]) gives hidden=[[-2,2],[0,0],[2,-2]] ([3,2]), followed by [[0],[0],[0]] ([3,1]). Transposing a [1,1] matrix leaves its shape and zero coefficient unchanged. The sign bit of floating point -0.0 in the observed middle row has no effect on this numerical equality.
4. ReLU(t)=max(0,t) applied to each hidden element gives [[0,2],[0,0],[2,0]], then W2 adds the two columns and gives [[2],[0],[2]]. For every real x, max(0,x)+max(0,-x)=|x|: for x<0 the result is -x; for x>=0 it is x. Hence the negative-side slope is -1 and positive-side slope is +1. From x=-2 to x=0, delta y/delta x=(0-2)/(0-(-2))=-1. From x=0 to x=2 it is (2-0)/(2-0)=+1. No derivative at zero is claimed. Inputs/outputs are dimensionless example values; the slope denominator is an input difference, not a sample average.
5. Changing only the final scalar input from 2 to 3 changes hidden's final row to [3,-3], linear's final output remains 0, and ReLU's final output is 3. Replacing b(F.relu(hidden)) with b(hidden) removes the sole nonlinearity and makes that path all zero again.
6. The independent biased/non-square control uses W1=[[1,2],[-1,0],[0,3]], c1=[1,-2,0.5], W2=[[2,1,0],[0,-1,1]], c2=[3,-4]. Thus W=W2*W1=[[1,4],[1,3]], and c=W2*c1+c2=[3,-1.5]. X=[[1,2],[-2,3],[0,0]] should give Y=[[12,5.5],[13,5.5],[3,-1.5]] through either computation. The bounded probe confirms these values. Deliberately omitting c is detected as unequal, so this control exercises the offset rather than repeating the zero-weight cancellation case.
7. Numeric comparisons in the independent probe use rtol=0, atol=1e-6 on CPU float32; the observed maximum absolute error is exactly 0. The original fence's torch.allclose default is rtol=1e-5, atol=1e-8, and it also passes; the zero reference reduces its applicable allowance to atol=1e-8. All dimensions and the three independent sample rows are checked explicitly. No ratio, accuracy metric, token denominator, or learned-model statistic is present.

Scope: algebra and forward-function representation only. There is no backward call, optimizer step, training dataset, loss, or held-out evaluation in this section. The hand-specified absolute-value function demonstrates that adding the nonlinearity admits a function impossible for a scalar affine output; it does not establish successful learning or generalization.
