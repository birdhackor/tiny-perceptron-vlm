# 文字距離與圖文核對

本紀錄只核對凍結文字所示的確定性算例、演算法與圖，不據此推論 OCR 模型的品質。

## 編輯距離的狀態與邊界

令 R 為正確答案、P 為預測，D(i,j) 表示把 P[:j] 改成 R[:i] 的最少單位編輯次數。允許插入、刪除、替換；相同字的保留成本為零，不把移位或整行交換當作單一步驟。

D(0,j)=j：目標是空字串，只能刪去預測的 j 個字。D(i,0)=i：預測為空，必須補入正確答案的 i 個字。長度差也是下界，因此兩個邊界不只是可行成本，確實為最小值。

一般格的三個候選是：

- D(i,j−1)+1：刪除預測末字。
- D(i−1,j)+1：補入正確答案末字。
- D(i−1,j−1)+[R[i−1]≠P[j−1]]：保留相同字或替換不同字。

把插入、刪除與替換寫成單調的前綴對齊路徑，終點的最後一條邊必屬於這三類。反過來，每一類都能把一條較短前綴的可行路徑延伸成當前路徑。依 i+j 歸納，各前驅已取最短成本，因此三者的最小值同時是可達上界與所有路徑的下界。這證明遞推會得到編輯距離；不需要列舉所有完整編輯序列。

程式的 previous[j] 是上一列，current[-1] 是本列左格，previous[j−1] 是左上格。每列開始只有 current[0]=i，向右計算後替換 previous；兩列之外的狀態不再被後面的格子讀取。迴圈結束時 previous[-1]=D(len(R),len(P))。即使 R 為空，初始化那一列也已含正確答案。

獨立驗證程式以 Dijkstra 搜尋前綴圖，而非呼叫教材的遞推來製造預期答案。檢查教材各例及空字串、反序例，另比較長度零到四的所有二進位字串配對，共 31²=961 組。它核對教材節錄的 AST 與實作一致，也核對移除 docstring 前後的距離相同。docstring 的中繼資料用途不在「不影響計算」的敘述之外被否定。

## 各算例與正規化

「今天去臺北」長度為 5；「今天去台北」只差第四個碼點。替換一次可達，兩串不相等又排除零次，故距離為 1，CER=1/5=0.2。

「10100」改成「1010」可刪去末尾 0；「010」改成「1010」可補入開頭 1。兩例的長度差都是 1，故最小成本恰為 1。

「今天去臺」缺「北」，長度差為 1，補一次即可；「今天去台」除了長度差，剩餘的「台」也不是參考的「臺」。一次插入無法同時改掉「台」，所以後者至少兩次；一次替換再一次插入可達。兩者分母均為參考的 5，CER 分別為 0.2 與 0.4。

「今日休館明日開放」與「明日開放今日休館」各長 8，字的集合與重數皆相同，故只問字有沒有出現無法辨別順序。逐位相同的位置是 2 與 6，六次替換給出距離上界 6。獨立最短路徑的結果也為 6，提供最小成本的核對；不可只靠六個位置不同就斷言所有字串的編輯距離都等於逐位錯字數。CER=6/8=0.75。

臺是 U+81FA、台是 U+53F0，均為一個 Python 字串元素，UTF-8 均需三個 byte。NFC 不會把它們合併。教育部原始字條支持把台作為臺的異體的本例語境；不支持所有讀音與文脈都能任意互換。顯式把兩邊的臺映射成台後，本例 CER 從 0.2 變成 0。這是換了比較的等價規則；預先定義並並列前後分數是評量程序建議，不是 Unicode 自動保證或模型品質改善的測得結果。

CER 以非空 reference 長度為分母，本節全部教材算例均非空。實作對空 reference 回傳 cer=None；不能把教材的除法描述外推為空字串也有有限 CER。碼點不是所有文字的視覺字元，本節的中文算例沒有結合符號或變體選擇符，才可直接用碼點數作字數。

文字評分只比較給定的兩串字，不會自行證明圖上是否有字、字是否出於該圖，或該圖應採哪種閱讀方向；這些輸入與標註規則必須另核對。沒有圖像內容支持時，不應以常見句子補成答案，這是忠於參考內容的評量要求，沒有宣稱任何模型已通過這項測試。
