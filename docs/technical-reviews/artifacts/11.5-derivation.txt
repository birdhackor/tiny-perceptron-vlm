11.5 本人透明推導，2026-10-03

限定 ModelConfig 預設 vocab_size=264、max_length=128、單頭、
LayerNorm、DenseFFN hidden=4w、GELU、無權重綁定、無 RoPE。
語言寬度 w、區塊數 L；兩種模態的特徵寬度皆 16。

圖片接頭的權重形狀 [w,16]，偏置 [w]：
P_projector=16w+w=17w。
w=8 得 136；w=64 得 1088。L 不出現在式子裡。

一個語言區塊：
q/k/v/out 為四個無偏置 w×w 矩陣，合計 4w²。
FFN up 為 [4w,w] 加 4w 偏置；down 為 [w,4w] 加 w 偏置，
合計 8w²+5w。
兩個 LayerNorm 各有 w 個權重與 w 個偏置，合計 4w。
所以 P_block=12w²+9w。
w=8：12×64+72=840。
w=64：12×4096+576=49728。
partial=圖片接頭+一個最後區塊，故 136+840=976；
正式較大模型為 1088+49728=50816。
976−136=840 是參數元素數，沒有訓練資料行數的單位。

語言模型：詞嵌入 264w、位置表 128w、L 個 block、
最後 LayerNorm 2w、無偏置輸出 264w：
P_language=658w+L(12w²+9w)。
w=8,L=1 得 5264+840=6104；L=2 得 6944；L=4 得 8624。
w=64,L=2 得 42112+99456=141568。

視覺編碼器：48×16+16 + 16×16 + 2×16 + 16×16+16 = 1344。
各項為 patch 線性層、位置表、LayerNorm、特徵線性層。
聲音編碼器：16×16+16 + 2×16 + 16×16+16 = 576。
再加圖片與聲音接頭兩份 17w：
P_all=P_language+1344+576+34w=692w+L(12w²+9w)+1920。
w=8,L=1：6104+1344+576+136+136=8296。
w=8,L=2：6944+1344+576+136+136=9136。
w=8,L=4：8624+1344+576+136+136=10816。
w=64,L=2：141568+1344+576+1088+1088=145664。
all 的聲音編碼器和聲音接頭有開關，不代表純圖片路徑使用它們。

浮點數條件與狀態：32 bits / 8 bits per byte = 4 bytes per scalar。
這只算參數的 float32 數據，另需梯度、優化器狀態與中間運算等。
Adam 的 m、v 各和參數同形；當前 AdamW 沿用此兩組歷史向量，
另有步數 scalar；AMSGrad 可多一組歷史最大值。
PyTorch 的狀態延遲到 p.grad 非 None 才建立，不能以所有名義
requires_grad=True 的數量機械乘固定倍數當作實際記憶體。

有效監督曝光量：若三個目標標籤均未被忽略，同一資料用十次，
提供 3×10=30 個有效目標項；沒有因此增加三十個獨立樣本。
正式抽樣四題×160次=640個抽樣題次，答案長短不同。
重建 random.Random(42+step)，每題先消耗 ratio=0 的回放抽籤，
再 choice 同一36行訓練資料；答案 UTF-8 bytes 數加 EOS，
逐步目標與每個版本的 history 完全相同，加總3830。
這是相同監督目標曝光量，不是相同 FLOPs、時間或必然相同品質。

驗證／測試各六個圖片家族，每個問 shape? 和 color?，所以12個問題。
形狀答案 circle 或 square 每個有6個 bytes，加EOS是7，六題42。
red、green、blue 加EOS分別4、6、5，各兩題，所以顏色目標30。
每份評估合計有效目標42+30=72，exact-match分母則是12個問題。
各版本驗證與測試的答對數，以及原始生成ID逐項比對，另見
11.5-audit-execution.json，這裡不把題目数改成獨立圖片數。
