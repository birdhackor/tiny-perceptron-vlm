usage: fetch_natural_data.py [-h] [--manifest MANIFEST] [--revision REVISION]
                             [--manifest-sha256 MANIFEST_SHA256]
                             [--output OUTPUT] [--list | --verify]

匿名取得固定版本的自然照片、中文讀字與語音資料，逐檔核對後解包。

options:
  -h, --help            show this help message and exit
  --manifest MANIFEST
  --revision REVISION   固定的 40 位 Git commit；預設為已公開的三包資料版本
  --manifest-sha256 MANIFEST_SHA256
                        本機與該 Git 版本的資料清單都必須符合此固定 SHA-256
  --output OUTPUT
  --list
  --verify              只核對既有資料，不下載
