L338: A dictionary display is a possibly empty series of dict items (key/value pairs)
L339: enclosed in curly braces:
L340: 
L341: .. productionlist:: python-grammar

L344:    dict_item: `expression` ":" `expression` | "**" `or_expr`
L345:    dict_comprehension: `expression` ":" `expression` `comp_for`

L347: A dictionary display yields a new dictionary object.
L348: 
L349: If a comma-separated sequence of dict items is given, they are evaluated
L350: from left to right to define the entries of the dictionary: each key object is
L351: used as a key into the dictionary to store the corresponding value.  This means
L352: that you can specify the same key multiple times in the dict item list, and the
L353: final dictionary's value for that key will be the last one given.
