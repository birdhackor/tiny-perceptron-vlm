L1603: .. function:: print(*objects, sep=' ', end='\n', file=None, flush=False)
L1604: 
L1605:    Print *objects* to the text stream *file*, separated by *sep* and followed
L1606:    by *end*.  *sep*, *end*, *file*, and *flush*, if present, must be given as keyword
L1607:    arguments.
L1608: 
L1609:    All non-keyword arguments are converted to strings like :func:`str` does and
L1610:    written to the stream, separated by *sep* and followed by *end*.  Both *sep*
L1611:    and *end* must be strings; they can also be ``None``, which means to use the
L1612:    default values.  If no *objects* are given, :func:`print` will just write
L1613:    *end*.
L1614: 
L1615:    The *file* argument must be an object with a ``write(string)`` method; if it
L1616:    is not present or ``None``, :data:`sys.stdout` will be used.  Since printed
L1617:    arguments are converted to text strings, :func:`print` cannot be used with
L1618:    binary mode file objects.  For these, use ``file.write(...)`` instead.
L1619: 
L1620:    Output buffering is usually determined by *file*.
