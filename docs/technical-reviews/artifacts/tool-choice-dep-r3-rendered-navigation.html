全部章節各自回答什麼¶

章號提供一條由小到大的路徑，也讓你知道自己目前在哪裡。第 1–4 章建立最初的文字模型；第 5–7 章處理資料與訓練中的實際問題；之後各章是可以各自展開的主題。Flash Attention 這類加速方法放到第 16 章，因為先知道原本算了什麼、哪裡花空間，才容易理解它省掉什麼。

章 這一章的問題
1．從猜下一個字開始 文字如何編號？猜法如何從出現次數變成可學習的數字？
2．多看幾個字 前文怎麼變成特徵，固定長度的窗口有什麼限制？
3．從前文挑線索 注意力如何比較、挑選與混合不同位置的資訊？
4．拼成初始 Transformer 如何保留順序與原訊息，把零件組成一個文字模型？
5．訓練與評估 如何更新、存檔、留出新題，判斷進步是否可靠？
6．文字切成哪些小單位 一個字、一個位元組與常見片段，各付出什麼代價？
7．從文字接續到對話 哪段是問題、哪段是回答，哪些位置該計算猜錯代價？
8．個性與指令遵循 如何把生動、洞察、簡潔和格式可靠分開教、分開看？
9．誠實與安全 資訊不足、需要拒絕與無害請求，各應如何回應？
10．圖片進入模型 圖片如何拆成小方塊，再變成可與文字一起處理的向量？
11．檢查圖片是否真的有用 如何訓練轉接頭，又如何排除只靠問題猜答案？
12．聲音進入模型 波形、取樣與頻譜如何表示，如何檢查模型有沒有聽？
13．從答案比較學偏好 如何用同題的兩份回答，教模型傾向較合適的一份？
14．現代架構的零件 相對位置、正規化與門控，各解決哪個問題？
15．Dense 與 MoE 每次全部計算，和只選幾組專家計算，有什麼不同？
16．量測與加速 生成時能省哪些重算，速度與記憶體要怎麼量？
17．量化 用較少刻度記錄數字，省多少儲存，又改變多少結果？
18．蒸餾 較小模型如何從教師學習，如何確認沒有一起學走錯誤？
A．檢索與外部資料 如何找到資料、用對資料，並讓答案能回到來源？
B．工具呼叫 模型提出的文字要求，如何變成可檢查的實際操作？
C．推理與額外計算 中間步驟、多試幾次與答案驗證，各能幫到什麼？

全部小節目錄可以用來找一個具體問題。可以試著找到「回答第一個 token 在哪個位置被預測？」；token 是模型處理的一個文字單位，這個問題在 7.4。若只是想先知道 token 的意思，先讀第 6 章或名詞對照，不必直接跳進位置對齊的計算。

7.4 回答第一個 token 在哪個位置被預測？ B.5 同樣有數字，何時需要計算器？ B.6 模型如何學會選擇下一個動作？ B.7 工具選擇怎樣才算可靠？ B.8 依能力與成本，何時值得借助工具？
