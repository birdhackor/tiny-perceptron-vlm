# 原始技術判斷與支持範圍

審閱對象是 `course/chapters/08.md` 在第一個小節前的章首，實際核對指定凍結快照。未讀其他角色報告、舊技術審閱或禁止的實驗輸出。判斷只涵蓋這兩段，導覽目的頁用於確認內容位置，不代替那些頁面的正式技術審閱。

## 指令決定合格回答

這是合格條件的敘述，不是宣稱任何模型必然服從。保持題目為「2+2」，若要求只給數字，`4` 符合；若要求用物件分組的例子解釋，只有 `4` 缺少所需解釋，而「兩雙各兩根筷子合起來是四根」提供例子。若反過來要求只給數字，這句解釋又含多餘文字。因此合格回答的集合隨要求改變。

IFEval 原文的 Introduction、Verifiable instructions 與 IFEval metrics 明確把回答對特定指令的符合程度當成判斷對象；各條件需具體定義。這不表示任何開放式品質都能由簡單程式精確判定。

## 提示、示範與少量參數修正

Training language models to follow instructions with human feedback 的 Introduction 說明模型可由輸入提示與例子指定任務；High-level methodology 與 Models 分開介紹提示基線、人工示範和 supervised fine-tuning。Results on the API distribution 分開比較提示、SFT 與後續強化學習。這支持提示及示範微調可以改變輸出行為；不能把後續強化學習結果全歸給 SFT，也不能保證任何提示或資料都能得到所需寫法。這裡的「示範」對照教材的「示範回答如何把寫法教進權重？」理解為訓練目標，不誤當成只有推論時加例子。

LoRA 原文的 Low-Rank-Parametrized Update Matrices 固定原矩陣 W，訓練 A、B，讓有效映射包含 BA；若 W 為 d×k，修正參數是 r(d+k)，在所選 r 足夠小而 r(d+k)<dk 時，比更新原矩陣的參數少。GPT-2 medium/large 的文字生成任務支持此方法可用於生成輸出的調整。這是「少量可訓練參數」的解釋，不是「數值改動幅度小」、全部模型儲存量縮小，或必然學到某種風格的保證。章首沒有對收斂、品質、速度或泛化作量化承諾，因此無須用本課短訓練重證研究效益。

## 活潑不能取代三個條件

這裡核對的是不蘊含關係，不主張三個評分在統計上互相獨立。

- 數字正確：對「2+2」回答「5，數字如星光流動」，即使把語氣標為活潑，5 仍不等於 4。語氣標籤不改變算術真值。
- 範圍合適：材料有「今日休館」與「明日開放」，要求只交第一句時，把兩句都交出便超出範圍。加上活潑語氣不能移除多交的句子。這是明定要求下的反例，不是某模型的實測。
- 格式可用：要求整份回答為裸 JSON 時，`答案來囉！{"answer":4}` 在物件前多了文字，即不符合整份為 JSON 的要求。正確數字和活潑語氣都不能取代交付格式。

IFEval 原文的指令類型包含排除指定詞語與整份輸出使用 JSON，提供將範圍限制與格式限制分開檢查的原始研究背景；本文件的反例才是上述不蘊含關係的直接推導。未拿 IFEval 當作算術正確性評測，也未主張它有通用語意範圍裁判。

## 選讀與導覽

明確寫出要求與人工核對目標，本身不需要先訓練 LoRA 或部署自動裁判。提示是輸入文字的一部分；IFEval 也展示明定條件可用規則核對，而非必須使用另一個語言模型評分。這支持章首的閱讀路線安排，不表示小模型一定已具備服從新要求的能力。

`evidence.json` 保存凍結檔與章首的指紋、各導覽目的頁標題及開頭、名詞頁連結存在性。少量參數修正相關頁面談 LoRA、adapter 與縮放；裁判相關頁面談判準、位置與長度偏差；章末確實以打成文字的告示作指定範圍與格式的任務。因此章首預告與實際內容一致。「可讀告示」沒有宣稱執行 OCR。這些是導覽核對，不另算成模型的軟體或實測主張。

## 原始來源的取得與限制

實際用 curl 讀取 arXiv HTML 的指定版本：2311.07911v1、2203.02155v1、2106.09685v2。閱讀位置如上，原始 HTTPS URL、當次原檔 SHA-256、讀取時間、命令與短摘錄保存在 `evidence.json`；第三方全文只在記憶體處理，未落入 repo。原檔 SHA 指當次 HTML 位元組，網站外框改動後未必重現同一 SHA，論文修訂版則由 URL 明定。
