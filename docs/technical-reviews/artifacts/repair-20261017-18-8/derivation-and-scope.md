## 數學關係

設 p、q 是同一有限候選集合上的正機率分布，總和各為 1；本節以自然對數計算。

1. `KL(p||q)=Σ p_i log(p_i/q_i)`，權重是 p；反過來的 `KL(q||p)` 改用 q 加權。`p=[0.8,0.2]`、`q=[0.5,0.5]` 時，兩者分別是 `0.19274475702175747` 與 `0.2231435513142097`，不可交換。第一名若以先出現者處理平手，兩者都可選第 0 候選，不能由此判分布相同。
2. 由 `log x <= x-1`，有 `-Σ p_i log(q_i/p_i) >= Σ p_i(1-q_i/p_i)=0`。所有 p_i 正時，等號需逐項 q_i/p_i=1，即 p=q。若允許零機率，以 `0 log 0=0` 及在 p_i>0、q_i=0 時 KL=+∞ 延伸；本節 softmax 算例的數學分布為正。這是精確數學性質，不是宣稱浮點程式必定回傳非負數。
3. `H(p)=-Σ p_i log p_i`、`CE(p,q)=-Σ p_i log q_i`，所以 `KL(p||q)=CE(p,q)-H(p)`。本例 H=`0.5004024235381879`、CE=`0.6931471805599453`；KL≈0.1927。教師 p、溫度與條件前文固定時 H 不依賴學生參數，兩者的學生梯度相等；教師若也改動，不能把 H 當成對所有參數皆為常數。
4. 對學生 logits z，`q=softmax(z)`，有 `∂KL/∂z_j=q_j-p_j`。平均 N 個有效位置後，每個有效位置再除 N；N=2 時 `[0.5-0.8,0.5-0.2]/2=[-0.15,0.15]`；N=3 時為 `[-0.1,0.1]`。被排除的 logits 列沒有直接 KL 梯度。
5. helper 在教師、學生 logits 各除 T 後才形成 p_T、q_T，再做 `T² × mean_valid Σ_i p_T,i(log p_T,i-log q_T,i)`。這是本 helper 的明定尺度，外層再乘 T² 就會重複。Hinton 的高溫尺度論證不是宣稱任意 T 下的梯度剛好都是原梯度的 T^-2 倍；本節沒有提出這種等式。
6. normalized p 下 `softmax(log p)_i=exp(log p_i)/Σ_j p_j=p_i`；零學生 logits 則形成均勻分布。`labels != -100` 是位置選擇，不是候選索引選擇。

## 梯度與前文的範圍

labels 遮罩在 helper 中的 per-token KL 計算之後選取列；它沒有修改模型的輸入。若有效位置 t 的模型特徵依賴較早的真實前文位置 s，鏈式法則可使該前文的 embedding／共同參數得到間接梯度。這不表示被 attention valid 遮住的 PAD key 也成了前文。
