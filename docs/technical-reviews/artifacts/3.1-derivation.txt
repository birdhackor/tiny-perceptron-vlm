3.1 審閱者自行推導（2026-10-03）
令兩張 value 向量為 v1=(2,0)、v2=(0,4)，a>=0、1-a>=0。
y(a)=a*v1+(1-a)*v2=(2a,4(1-a))；權重和為一時是凸組合。
a=0.5: y=(1,2)；a=0.9: y=(1.8,0.4)；a=1: y=(2,0)；a=0.1: y=(0.2,3.6)。
這裡逐特徵欄位加總位置，輸出第 j 欄為 sum_i w_i V_ij；沒有先平均單張卡內特徵。
任意範數皆有 ||y-v1||=(1-a)||v2-v1||、||y-v2||=a||v2-v1||。
因此 a=0.9 較靠近第一張，a=0.1 較靠近第二張，a=0.5 是中點。
float32 為近似表示；CPU 輸出分別 1.7999999523162842、0.4000000059604645 和 0.20000000298023224、3.5999999046325684；與 float32 預期 tensor 在 allclose 預設容差內。十進位理想值誤差分別約 4.77e-8、5.96e-9、2.98e-9、9.54e-8。
固定對所有位置用 1/N 的權重，比例本身不依 query 改變；這只描述讀取比例，不宣稱模型其他運算不能依問題改變。
混合不是可逆的識別操作：權重 (0.5,0.5) 時，[(2,0),(0,4)] 與 [(3,1),(-1,3)] 都給 (1,2)。未給特徵語意映射時，輸出數字不能告訴我們哪張卡的語意。
需要修訂的比較：加權項為 t_i=w_i*v_i，所以 ||t_i||=w_i||v_i||（w_i>=0）。僅 w1>w2 並不保證 ||t1||>||t2||；還需要 value 大小條件。
反例：w=(0.9,0.1)，v1=(0.001,0)，v2=(0,100)，兩權重非負且和一。
t1=(0.0009,0)，t2=(0,10)，範數 0.0009 < 10；較大的權重反而對應較小加權向量。
因此可說「乘在該 value 前的係數較大」，不宜無條件說「對這次混合貢獻較大」。若只指係數，應明確定義，避免被理解為向量貢獻大小或最終預測影響。
前置 W.3 圖算式：(60+70+80)/3=70，(80+90+100)/3=90；列平均為 [70,90]。
(60+80)/2=70，(70+90)/2=80，(80+100)/2=90；欄平均為 [70,80,90]。
