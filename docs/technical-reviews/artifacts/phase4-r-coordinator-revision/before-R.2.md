## R.2 依你想理解的問題選路

第一次接觸語言模型，先沿第 1–4 章閱讀：從出現次數猜字，改成可調數字，再學會查看前文，最後組成第一個 Transformer。這個名稱表示一種零件組合，等你看過它的做法，再記名字就很自然。

各主題也可以分開學。有時一張小數字表就能說明機制；討論圖片時，可以換成簡單圖卡。局部範例各自成立，最終整合專題才追蹤同一個模型如何接續學習。

| 想理解的問題 | 建議起點 |
| --- | --- |
| 模型如何從猜字學起？ | [第 1 章](chapters/01.md)，依序讀到第 4 章 |
| 為什麼先讀文章，再練習回答？ | [7.11 的對話示範](chapters/07.md#7.11)，再看[7.17 的兩階段理由](chapters/07.md#7.17) |
| 答案對了，為什麼仍沒完成指令？ | [8.14 的書店告示](chapters/08.md#8.14)，沿同一材料讀到 8.16 |
| 回答上限與長上下文有什麼不同？ | [7.19 的十六格例子](chapters/07.md#7.19)，再看[14.7 的位置範圍](chapters/14.md#14.7)與[A.8 的線索位置](chapters/0A.md#A.8) |
| 圖片與聲音怎麼成為輸入？ | [10.1 的圖片](chapters/10.md#10.1)、[12.1 的聲音](chapters/12.md#12.1)，可分別開始 |
| 如何教文風、誠實、安全與偏好？ | [第 8 章](chapters/08.md)、[第 9 章](chapters/09.md)；後訓練方法由[7.18](chapters/07.md#7.18)連到第 13 章 |
| Dense、MoE、加速與壓縮各改善什麼？ | [第 15 章](chapters/15.md)、[第 16 章](chapters/16.md)；儲存與較小模型分別看[第 17 章](chapters/17.md)、[第 18 章](chapters/18.md) |
