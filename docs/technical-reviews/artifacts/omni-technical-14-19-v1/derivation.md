# 14.19 獨立推導核對

這是手算／代數推導，不冒稱模型實測。實際執行另見 execution.json。

對每一對向量，R(θ) = [[cosθ, −sinθ], [sinθ, cosθ]]，所以 R(a)ᵀR(b)=R(b−a)。固定各對內容為 [1,0]，則兩個旋轉後向量的點積是 cos(b−a)。此處 angle_j = coordinate[pair_axis[j]] × π/4。

1. 時間座標直接除以 250 ms：1250/250=5，1300/250=5.2，2300/250=9.2；不取整數。
2. 原時時間差是 (1300−1250)/250=0.2，時間對點積 cos(0.2π/4)=cos(π/20)≈0.9876883405951378。高度及寬度兩對都從 [1,0] 轉 0，分別貢獻 1。總分≈2.987688340595138，四位小數為 2.9877。
3. 移時時間差是 (2300−1250)/250=4.2，角差=1.05π=π+π/20；cos(π+π/20)=−cos(π/20)≈−0.9876883405951378。總分≈1.012311659404862，四位小數為 1.0123。這是未經 softmax 或 head 維度縮放的原始點積。
4. q_a 的時間角是 5.2π/4=1.3π，時間對≈[−0.587785252292473,−0.809016994374947]。h=1 只讓高度對轉 π/4，得到 [√(1/2),√(1/2)]；w=1 則只讓寬度對得到同一值。兩種操作都不改其他軸的座標、轉速及配對。
5. 同樣的內容、同樣的因果 index 與轉速必定產生相同的 index-only 旋轉；這不代表時間座標也相同。原始序列有 1+16+2+4+1=24 項：frame Fk 在 1+k，故 F5 在6、F15在16；audio Ak 在19+k，故 A1在20、下一塊在21。第20列遮罩 j≤20，因此可讀6與16，但不能讀21。
6. 前置 12.17 的 A1 是錄音內 [200,400) ms 的發聲塊，中心300 ms；共同起點1000/2000 ms加300，得到1300/2300 ms。移時不重排模態區塊，A1仍在20。影格 F15 的物理時間15×250=3750 ms，序號16卻小於20，故本示例的序號因果性不保證物理時間的過去性。
7. 改 unit_ms=500 時，座標為[2.5,2.6,4.6]；θ/time_ms=(π/4)/unit_ms，所以同樣每毫秒的角速度減半，不能沿用舊點積。原時總分為2+cos(0.1π/4)≈2.996917333733128；移時總分為2+cos(2.1π/4)≈1.921540904272155。
8. 旋轉是週期函數。此單一時間對的週期是8個座標單位（2000 ms）；距離增加一整個週期又得到相同旋轉，所以本例不支持「越近必然越相關」。一般 RoPE 的點積還依賴實際 Q、K 內容與各對轉速；這裡的固定相同內容未測訓練品質、空間增益或影音對齊能力。

原始數學依據：RoFormer arXiv:2104.09864v5 §3.2.1 式12–13、§3.2.2 式14–16。三軸方法依據：Qwen2.5-Omni v1 §2.2 及 Qwen3-Omni v1 §2.3；兩者上游時間尺度分別為40與80 ms，均不是本例自選的250 ms。
