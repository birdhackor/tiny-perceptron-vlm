## G.2 猜法、學習與保存

假設模型替三個候選字打分 `[2, 1, 0]`。這些分數叫 logits，還不是機率。softmax 把分數換成加總為 1 的比例，這個例子約為 `[0.665, 0.245, 0.090]`。若正確答案是第三個字，模型只分給它 0.090，猜錯代價就偏高。訓練用這個代價告訴模型：內部哪些數字應往哪個方向改。

| 名詞 | 可以怎麼理解 | 完整講解 |
| --- | --- | --- |
| logits、softmax | 候選分數，以及由分數換出的比例 | [1.6](chapters/01.md#1.6)、[1.7](chapters/01.md#1.7) |
| loss | 猜錯的代價；不是「這個模型的一切品質」 | [1.8](chapters/01.md#1.8) |
| gradient | 每個可調數字微動時，代價如何變化 | [W.6](first-steps.md#W.6)、[1.9](chapters/01.md#1.9) |
| batch | 一次拿來計算的一組例子 | [5.2](chapters/05.md#5.2) |
| checkpoint | 把模型數字保存成檔案；要接續訓練，還需保存更新工具與進度 | [5.7](chapters/05.md#5.7) |
| SFT | 用理想回答作示範，教模型在對話中回答 | [7.11](chapters/07.md#7.11) |
| DPO | 比較同題兩個回答，讓模型更偏向較合適的回答 | [13.1](chapters/13.md#13.1)、[13.5](chapters/13.md#13.5) |
| LoRA | 保留原本數字，只學一組較小的修正零件 | [8.8](chapters/08.md#8.8) |

比例高與回答可靠也是兩回事。模型可能很肯定地接出一個錯字；要知道它的信心是否與正確率一致，需要另外檢查，[9.9](chapters/09.md#9.9)會用具體例子說明。

看到某次 loss 下降，先找出那個 loss 算在哪些題目、哪些位置，再判斷能說什麼。可以用[5.8](chapters/05.md#5.8)的例子練習：寫一句「這個結果支持什麼」，以及還需要哪種新題檢查。這比把 loss 當成所有能力的總成績更準確。
