# 平方代價與固定學習率的獨立推導

令 f(w)=(w−3)²。平方非負，且僅 w=3 時為零，因此最低點為 3。
導數 f′(w)=2(w−3)。無動量、無衰減的梯度下降為
w_next=w−η f′(w)，所以在 w=1 時梯度為 −4、代價為 4、位移為 +4η。

每個候選各從 1 開始：

| η | 新位置 1+4η | 新代價 (1+4η−3)² |
|---|---|---|
| 0.01 | 1.04 | 3.8416 |
| 0.1 | 1.4 | 2.56 |
| 2 | 9 | 36 |

初始梯度為負，負梯度方向為正；沿該方向走得過遠仍可增大代價。
初始方向的正確性是局部性質，不是任意有限位移的下降保證。

定義誤差 e_t=w_t−3。更新給出 e_next=(1−2η)e_t，e_0=−2，
因此 e_t=−2(1−2η)^t，f(w_t)=4(1−2η)^(2t)。
因子為負代表位置交替越過最低點；代價則由因子的絕對值決定。

| η | 誤差因子 | 三步位置 | 三步到 3 的距離 | 三步代價 |
|---|---|---|---|---|
| 2 | −3 | 9, −15, 57 | 6, 18, 54 | 36, 324, 2916 |
| 1 | −1 | 5, 1, 5 | 2, 2, 2 | 4, 4, 4 |
| 0.75 | −0.5 | 4, 2.5, 3.25 | 1, 0.5, 0.25 | 1, 0.25, 0.0625 |
| 0.5 | 0 | 3, 3, 3 | 0, 0, 0 | 0, 0, 0 |

η=2 的第二步梯度為 2(9−3)=12，第三步梯度為 2(−15−3)=−36。
此處的發散有閉式解支持：距離為 2×3^t，並非僅憑三個上升數字推斷無界。
震盪指位置交替，與代價是否上升是兩件事。

算例中的合適學習率依賴曲率。若改為 f_a(w)=a(w−3)²（a>0），
誤差因子改成 1−2aη，一步抵達最低點需要 η=1/(2a)。
例如 a=1 時是 0.5，a=100 時是 0.005。因此 0.1 或 0.5 都不是跨問題的最佳值。
這也沒有量測任何語言模型的訓練品質或最優學習率。

有理數結果屬精確算術；原始 tensor 算例使用 CPU float32。
獨立執行對位置與代價採絕對誤差小於 3e−7，足以涵蓋這些小數的 float32 捨入。
第二段三步中的整數、0.75 與 0.5 路徑都可由二進位浮點精確表示，
另以 Fraction 逐步更新及閉式解交叉核對。

# 診斷與比較的支持範圍

比較學習率時，固定參數、最佳化器歷史、資料順序與更新次數，
是把比較中的自變項限制為學習率。終點參數及代價是結果，不能要求彼此相等。
SGD 的 momentum_buffer 會影響下一次更新，因此僅重設參數不足以重設歷史。
獨立程式中，相同參數和梯度恢復同一份歷史得到相同結果，
清除歷史則得到不同結果；此例只說明控制狀態的必要性，不提供模型品質結論。

1.000040054321289 顯示為四位小數時是 1.0000，故應比較實際存值及足夠精度。
這不表示任意小的更新都可用多印小數看見：小於儲存精度的更新可能已被捨入。
有效目標計數與零分母檢查是更新診斷的一部分，不保證梯度非零或學習率合適。
相同種子控制亂數起點；跨版本、裝置與非決定性運算的重現性仍有條件。
