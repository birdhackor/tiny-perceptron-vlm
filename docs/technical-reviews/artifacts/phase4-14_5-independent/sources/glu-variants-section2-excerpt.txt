81: 3     Experiments on Text-to-Text Transfer Transformer (T5)
82: We test the FFN variants we have described on the transfer-learning setup from [Raffel et al., 2019]. An
83: encoder-decoder transformer model [Vaswani et al., 2017] is trained on a denoising objective of predicting
84: missing text segments, and subsequently fine-tuned on various language understanding tasks.
85: 
86: 3.1    Model Architecture
87: We use the same code base, model architecture, and training task as the base model from [Raffel et al.,
88: 2019]. The encoder and decoder each consist of 12 layers, with dmodel = 768. For the attention layers,
89: h = 12 and dk = dv = 64. The FFN layers have hidden size df f = 3072. As we describe above, for the
90: GLU-variant-based FFN layers, which have thee weight matrices instead of two, we reduce the hidden layer
91: to df f = 2048, so as to maintain the same parameter and operation counts as the base model.
