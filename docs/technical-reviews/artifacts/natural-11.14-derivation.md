# Transparent arithmetic for 11.14

The helper's images each have three channels, 32 rows and 32 columns. The red strip occupies rows 8..15 and columns 0..3: 8x4=32 positions with RGB [1,0,0]. The blue strip occupies the same rows and columns 4..7: another 32 positions with RGB [0,0,1]. All other positions are [0,0,0]. Mirroring columns 0..7 exchanges these two strips and leaves channel sums [32,0,32] unchanged.

There are 8x8=64 changed spatial positions. Each changes two scalar channel values, red and blue; green remains zero. Thus `(first != second).sum()` is 64x2=128 changed scalar values. It is neither 128 colored positions nor 32 changed spatial positions. A strip individually has 32 colored positions. The lesson explicitly says that RGB channel numbers are counted separately.

At 32-to-4 adaptive pooling, the exact-commit native formulas give `start_index(a,4,32)=8a` and `end_index(a,4,32)=8(a+1)` for each a=0,1,2,3. Each bin is 8x8=64 positions, averaged independently per channel. Only output cell (row=1,column=0) is nonzero: [32/64,0/64,32/64]=[0.5,0,0.5]. All other cells are [0,0,0]. These are dyadic rationals, exactly representable in float32 here. Both arrays therefore yield identical 1x3x4x4 pooled tensors; the shape has 16 spatial bins and 48 scalar outputs.

At 32-to-8 pooling the bins are 4x4. The red/blue boundary lies exactly between adjacent bins. Rows 2 and 3, columns 0 and 1, preserve the colors [1,0,0] and [0,0,1] and their reversed order. Four spatial output bins each change two channels: 4x2=8 changed output scalars. The pooled tensor shape is 1x3x8x8 and equality is false. This corroborates that the particular 4x4 reduction, rather than an arbitrary use of averaging, removes this left/right distinction.

Flattening either complete 3x32x32 tensor gives 3x32x32=3072 scalars in PyTorch's contiguous channel/row/column order. This deterministic reshape is invertible when the shape is known; the arrays differ and their flattened arrays differ. It retains the distinction but provides no trained visual-language understanding.

Concrete paper exercise: move red rows 8..15, columns 0..3 to rows 8..15, columns 8..11, keeping blue at columns 4..7. The global channel sums remain [32,0,32]. In the 4x4 output, row 1's first two cells become [0,0,0.5] and [0.5,0,0]. Previously they were [0.5,0,0.5] and [0,0,0]. Therefore two output scalar values change and the summaries are unequal. The exercise does not specify the strip's precise within-cell location; the conclusion holds for an intact strip moved wholly into the second cell.

Information-loss conclusion: let P map an image to its pooled summary. Here x_A != x_B while P(x_A)=P(x_B), so P is not injective. The true relation labels are opposite, y_A != y_B. Any deterministic function g receiving only P(x) must give g(P(x_A))=g(P(x_B)), and cannot identify both opposite labels correctly from that summary alone. A probabilistic decoder likewise receives the same conditioning information. Additional visual evidence or context could change this; a plausible guess from prior knowledge does not reconstruct the lost order. Similarly, more than one before/after history can produce one still image, so that still image cannot uniquely establish unobserved history.

The instruction about training is a lack-of-guarantee statement for the course's supervised task: color-only labels give the same target to images with different relations. A color objective need not distinguish those relation answers. This does not claim that a pretrained model cannot already have learned relations, or that explicit relation questions are the only possible learning approach. GQA's relation-rich annotations and ViLT's VQA fine-tuning are primary examples of the task distinctions.
