# 拼接與固定視窗的直接推導

字表由人指定：E(1)=(1,10)、E(2)=(2,20)、E(3)=(3,30)。這只是追蹤用數字，沒有由這些值推論字義。

定義拼接 c(E(i₀),E(i₁),E(i₂)) 為依序列出三個向量的所有座標。因此 (1,2,3) 得到 (1,10,2,20,3,30)；(3,2,1) 得到 (3,30,2,20,1,10)。這個操作沒有相加。只要知道各向量的長度，就能依固定邊界切回原先三組，所以它保留的是輸入向量及其位置；若兩個字原先查出相同向量，拼接本身也不會額外區分那兩個字。

給位置 t、特徵 d 的權重記為 w[t,d]，後續一個加權輸出是 y=ΣₜΣ_d w[t,d]E(iₜ)[d]+b。不同位置可有不同權重。例如六格權重取 (1,0,0,0,2,0)，原序列輸出 1+2×3=7，反序列輸出 3+2×1=5。這證明能有不同作用；若權重剛好對稱或相同，仍可能得到相同結果，不能據此宣稱已學會使用順序。

對正整數 B、T、D，把 x[b,t,d] 放到 context[b,tD+d]，即 [B,T,D]→[B,T×D]。反向索引是 t=k//D、d=k%D，故這是已知原形狀下的重新分組，沒有增加數值資訊，也沒有把不同筆資料相加。B=2、T=3、D=2 時總格數為 2×3×2=12；固定第一軸為 2 後，剩下軸長為 12÷2=6。

若後續 Linear 的 in_features 固定為 K，直接接入拼接結果需要 T×D=K。D=2 時，T=3 是六格、T=5 是十格，不能直接送給同一個六格輸入層。這個限制針對此種直接接固定大小 Linear 的架構；先用補齊、截斷或其他長度處理，則屬於另一步操作。T 與 D 固定時，B 可以改變。

練習將第一筆改成 (2,1,3) 時，第一列變為 (2,20,1,10,3,30)，第二列仍是 (3,30,2,20,1,10)。原列總和 1+10+2+20+3+30=66，改後總和 2+20+1+10+3+30=66；總和無法辨認這次排列。

固定視窗的準備可以寫成：已見前文 p，取 left_pad(p,T,0) 的最後 T 項。前文超過 T 時丟掉較早位置；前文不足 T 時在左側放 T−len(p) 個 0。這裡 0 是專案的邊界編號，與題設為展示查表而另訂的 ID 對照分開。驗證程式分別執行學生訓練入口的 examples，以及實驗入口原始碼中的 _simple_examples；逐位置核對長度 1、3、5 的視窗，沒有執行訓練。
