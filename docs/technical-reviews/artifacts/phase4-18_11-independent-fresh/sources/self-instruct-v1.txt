A.2        Finetuning GPT3
GPT3SELF-INST and some of our baselines are finetuned from GPT3 model (“davinci” engine with 175B
parameters). We conduct this finetuning via OpenAI’s finetuning API11 . While the details of how the
model is finetuned with this API are not currently available (e.g., which parameters are updated, or what
the optimizer is), we tune all our models with the default hyper-parameters of this API so that the results
are comparable. We only set the “prompt_loss_weight” to 0 since we find this works better in our case, and
every finetuning experiment is trained for two epochs to avoid overfitting the training tasks. Finetuning
is charged based on the number of tokens in the training file. Finetuning GPT3SELF-INST from the GPT3
model took $338.
