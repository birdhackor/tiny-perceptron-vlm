# W.3 手算紀錄

此檔為 reviewer 的透明手算，不宣稱是程式輸出；實際執行另見 execution.json。

原始輸入為甲 (60, 70, 80)、乙 (80, 90, 100)。

- 甲的平均：(60 + 70 + 80) / 3 = 210 / 3 = 70。
- 乙的平均：(80 + 90 + 100) / 3 = 270 / 3 = 90。
- 小考 1 的平均：(60 + 80) / 2 = 140 / 2 = 70。
- 小考 2 的平均：(70 + 90) / 2 = 160 / 2 = 80。
- 小考 3 的平均：(80 + 100) / 2 = 180 / 2 = 90。

`dim=1` 跨每列的三格，分母為 3，保留兩位同學的兩個答案。
`dim=0` 跨每欄的兩格，分母為 2，保留三次小考的三個答案。
因此輸出分別為 [70, 90] 與 [70, 80, 90]。

練習僅把甲的第 3 次成績 80 改為 110。甲：(60 + 70 + 110) / 3 = 240 / 3 = 80；
乙仍為 90。前兩次小考仍為 70、80；第 3 次：(110 + 100) / 2 = 210 / 2 = 105。
因此答案為 [80, 90] 與 [70, 80, 105]；只有甲的每人平均與第 3 次小考平均改變。

格數核對：2 × 3 = 6；一維長度 6 的總格數也是 6；2 × 3 可以還原。
長度 8 需要 8 格，與原來 6 格不相等。三軸示例 2 × 4 × 3 = 24，
第一軸選定索引 0 後留下 4 × 3 的 12 格。

以上整數和與除法均能精確得到所列整數；手算容忍差為 0。
