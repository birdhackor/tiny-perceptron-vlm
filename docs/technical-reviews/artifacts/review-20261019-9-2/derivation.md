# 資訊充分性與評估的核對

設作者知道的真實球數為 H，助手可使用的數量欄位為 V。人工標註規則是：V 不是 None 時，目標為 str(V)；V 是 None 時，目標為「看不到球數，請提供數量或圖片。」。這是明示材料為真的玩具問題，沒有處理錯誤觀察或虛假數量的情境。

當 V = 3 時，目標由可見欄位推出「3」。當 V = None 時，助手可見的材料與 H = 3、H = 4 等不同世界都相容；因此材料無法唯一推出某個球數。猜到作者知道的 3 仍不構成有材料支持的回答。這是在檢查回答的依據，不是在禁止明確標為猜測的機率預測。

兩筆例子的 H 都是 3，V 分別是 3 與 None。原程式的 target 表達式只依賴 visible；visible 只讀 visible_count。故修改 H 不會改變 target。追加 box_color = 紅，但不更動這個表達式，也不會改變 target。執行證據另外檢查了 H 的四個替代值與新增顏色欄位；讀取隱藏欄位會立即報錯的字典也沒有觸發錯誤。

只知道盒子是紅色時，H = 3 與 H = 4 都符合材料，因此不能以紅色唯一決定球數。若材料再明示「所有紅盒都恰有 3 球」，由「這是紅盒」和該規則才可推出 H = 3。這裡是有無足夠前提的邏輯判斷，沒有聲稱真實世界中顏色和數量的統計相關必定為零。

目標的逐步代入如下。第一筆 visible = 3，3 is not None 為 True，str(3) 為字串 3，print 以空白分隔參數，得到「可見 3 → 3」。第二筆 visible = None，條件為 False，取澄清句，得到「可見 None → 看不到球數，請提供數量或圖片。」。因為條件比較的是 None 身分而非真值，visible = 0 時仍取 str(0)，得到「可見 0 → 0」。原程式只有建立字典、取欄位、條件表達式及列印，沒有模型呼叫、權重或參數更新；它展示的是標註規則。

令 K 是已給數量的留出題，U 是沒有足夠數量資訊的留出題。分別計算 K 中正確使用材料的比例，和 U 中適當指出缺項的比例，才能分辨兩種退化策略：總回答固定數字的策略可能碰巧猜中某些題，卻沒有在 U 中正確表達資訊不足；總要求補充的策略則沒有完成 K。這不表示一組有限測試足以證明所有情境的能力；兩組都應保留未參與訓練的題目，再按要測的變化準備球數與措辭。來源收據中列出的原始論文支持可答與不可答並測，官方文件支持測試與訓練分離。

保存的混合版測試中，同一個盒子與 count=? 在原問句得到正確澄清，改問法卻得到 6。兩題目標同為「資訊不足，請提供數量。」；所以這個具體改寫就是該模型未能維持此規則的反例。由一個原問句回答正確，不能推出所有等義問法都能判斷資訊充分性。這個反例也不能單獨證明模型內部只在記字串、完全不會推理，或其他模型都會失敗。
