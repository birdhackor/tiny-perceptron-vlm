# Independent arithmetic and unit check

The example uses numerical power P and natural logarithm L(P)=ln(max(P,epsilon)). epsilon=10^-8 gives max values [10^-8,10^-8,10^-4,1]. Since ln(10)=2.302585092994046, these are [-8 ln10,-8 ln10,-4 ln10,0] = [-18.420680743952367,-18.420680743952367,-9.210340371976182,0]. Two-decimal rounding has at most 0.005 absolute display error; float32 original output agrees at that precision and independent float64 checks use 1e-12 tolerance.

For P>=epsilon, 4P>=epsilon and L(4P)-L(P)=ln(4P)-ln(P)=ln4=1.3862943611198906. This follows from e^(a+b)=e^a e^b and the inverse definition of ln. For P<epsilon/4 both values are clamped and the difference is zero. For epsilon/4<P<epsilon the difference is ln(4P/epsilon), between zero and ln4. In the stated four-cell example the first two remain clamped. Our crossing value P=5e-9 gives ln2, not ln4. A negative L(P) records max(P,epsilon)<1 in the common chosen numeric power units; none of those powers is negative. At P=0 without a floor torch.log produces negative infinity rather than a finite feature.

With epsilon=10^-12 the same list becomes [-12 ln10,-10 ln10,-4 ln10,0], rounded [-27.63,-23.03,-9.21,0]. Zero still requires replacement and the 10^-10 value is now preserved. Identical P=10^-10 gives -18.42068 with epsilon=10^-8 and -23.02585 with epsilon=10^-12, so differing preprocessing alone can create a false difference of 4.60517. Common floor and normalization rules avoid this source of incomparable numbers; this does not mandate a specific universal normalization formula.

For a common linear 8-bit brightness scale spanning 0 to 1, rounding 255*P gives [0,0,0,255]. This independently supports 'may almost be invisible'. A display normalized after the floor/log transformation gives [0,0,0.5,1]. This is an illustrative mapping, not a claimed rendered empirical spectrum.

The official STFT equation is a weighted linear sum in waveform x. Holding window, padding, FFT and hop fixed, STFT(2x)=2 STFT(x). Thus |STFT(2x)|^2 = |2 STFT(x)|^2 =4 |STFT(x)|^2.
