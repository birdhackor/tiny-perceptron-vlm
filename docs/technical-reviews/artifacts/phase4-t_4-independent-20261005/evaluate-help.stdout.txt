usage: evaluate.py [-h] [--data DATA] [--mode {text,sft}]
                   [--split-label {train-diagnostic,validation,test}]
                   [--limit LIMIT] [--tokens TOKENS] [--tokenizer TOKENIZER]
                   [--device DEVICE] [--output OUTPUT]
                   checkpoint

離線評估文字 checkpoint；分開核對內容、正常結束與實際評估分母。

positional arguments:
  checkpoint

options:
  -h, --help            show this help message and exit
  --data DATA
  --mode {text,sft}
  --split-label {train-diagnostic,validation,test}
  --limit LIMIT         最多選取的資料筆數；all 選取整份資料（預設 20）
  --tokens TOKENS
  --tokenizer TOKENIZER
                        訓練時的 BPE／byte JSON；核對詞表、特殊 ID 與 checkpoint SHA 綁定
  --device DEVICE
  --output OUTPUT
