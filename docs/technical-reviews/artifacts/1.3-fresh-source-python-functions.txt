自有核對筆記：
zip逐次從各份可迭代資料取同位置元素，形成一個tuple；只建立zip物件不會立即耗盡全部資料。
預設zip在最短資料耗盡後停止，較長資料的剩餘項目不會出現在結果。strict=True則在迭代過程偵測不等長，拋ValueError；這個參數由Python 3.10加入。
教材用for消耗整個zip，故可觸發不等長的檢查。本次另外親跑一項配兩項、兩項配一項兩種反例，皆實際產生ValueError；關閉strict的相同輸入只產生一對。
支持範圍：CPython 3.13.5上的本節清單與完整迭代；不把strict描述成建立物件時就先計算所有長度。
