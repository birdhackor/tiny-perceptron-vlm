# tokenizer：教學模型

Byte (264 IDs) and trained byte-level BPE (512 IDs) TinyLM checkpoints, each bundled with its exact tokenizer JSON.

Compare segmentation and held-out bits per UTF-8 byte under the same raw-document exposure schedule.

限制：

- The pilot combines only the first 96 TinyStories stories and first 96 poetry records; its custom split is 153/19/20 documents.
- Each document is a UTF-8-safe prefix of at most 256 bytes. Prefixes are not complete-story or full-poem capability evidence.
- The two models differ in vocabulary, predicted-token counts and parameter counts (41,824 versus 57,696); equal document exposure is not equal FLOPs.
- Token NLL across different vocabularies is not directly comparable. Reported bpb uses the same held-out raw bytes and includes EOS boundary targets.
- The BPE companion must match the released checkpoint hash binding; the byte tokenizer uses the project 264-ID schema.

訓練程式版本：`a253d1262bf5f361f9ac4e19232ae752f0ecc7a3`。授權逐檔列於 export-manifest.json。

權重許可及上游來源聲明見 LICENSE 與 THIRD_PARTY_NOTICES.md；程式碼採 MIT。

下載的 checkpoint 已移除 optimizer、RNG 與內嵌的訓練參照模型；自訂模型的 architecture 保留在檔案中。清單若列有教師基準，它是可單獨載入的推論權重。

使用設定：

```json
{
  "script": "scripts/infer.py",
  "checkpoint": "bpe512.pt",
  "prompt": "Once",
  "tokens": 32,
  "chat": false,
  "temperature": 0.0,
  "device": "cpu",
  "tokenizer": "tokenizer-bpe512.json"
}
```
