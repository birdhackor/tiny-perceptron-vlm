# 第 20 章：做一位能看圖、讀字與聽問題的助理

你拿一張照片問：「門口的人在做什麼？」接著又想問：「招牌寫了哪些字？」如果手上忙著拿東西，也許你會直接把問題說出來。這三件事看似很接近，需要的線索卻不一樣：看活動要連起人物與物件，讀字要保留小筆畫，聽問題則要先分清使用者說了什麼。

[第 19 章](19.md#19.12)讓我們在小世界裡從頭組合文字、圖片、聲音與工具。這一章換一個起點：接手已經學過大量圖文的模型，再用適合用途的示範調整它。你可以先試用成品，接著學如何準備資料、只更新一小份權重，以及逐項驗收。第 19 章的小 MoE 仍是理解零件的練習；這裡用另一份底座，不需要先親手完成前一章訓練。

前兩節先看成品怎麼使用。20.3–20.8解釋模型、資料與訓練，20.9–20.12教你按用途核對回答，最後交出一張能力卡。各節的短 Python 例子都可用 CPU 執行；它們幫你理解一件事，不會偷偷下載完整模型。成品試用與 GPU 重訓另有清楚的入口。
