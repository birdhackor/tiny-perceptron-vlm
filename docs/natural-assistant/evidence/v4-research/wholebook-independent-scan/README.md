# 全書獨立掃讀的原始紀錄

六位新評閱者分別完整閱讀原有教材的279個編號小節，實際檢視圖、抽驗數值並查閱原始來源。各組的 `inspection.json` 和 `report.md` 保留評閱者身分、實讀範圍、當時原文指紋、發現與核驗限制。

這是一輪補充掃讀，並不是最終全書通過證明。它不包含新版第20章、三份操作指引或網站；掃讀之後修改的小節另由新的正式逐節評閱與連貫性檢查處理。原報告不因正文修改而換掉舊指紋。

`persistence-receipt.json` 對應原始工作目錄與此公開副本，逐檔核對相同bytes與SHA-256。完整第三方論文與網頁留在研究快取；此處保存其取得紀錄及來源指紋。正文、專案程式快照、自己產生的示意圖渲染和核對輸出則保留供查核。
