## 5.3 更新方向怎麼累積？

推車連續向前，遇到一小段反向推力時，不會立刻完全倒退。訓練參數也可以保留最近更新方向的一部分，讓反覆一致的意見累積。這種方法叫動量（momentum）。它與 [1.13](01.md#1.13) 把多次梯度加進同一個 `.grad` 桶不同：這裡每輪的新梯度先算好，再由優化器保留過去方向的狀態。

用v記錄方向，g是本輪梯度，更新規則為`新v=μ×舊v+g`，再`新w=舊w-η×新v`。μ是保留過去多少比例，η是[1.12](01.md#1.12)的學習率。若μ=0.9，就保留舊方向九成再加這次梯度；如果μ=0，過去全部忘掉，回到只用本輪梯度的基本梯度下降。本節只追蹤這兩行累計規則如何改變方向與位置。

```python
velocity = 0.0
position = 0.0
for gradient in [1.0, 1.0, -1.0]:
    velocity = 0.9 * velocity + gradient
    position -= 0.1 * velocity
    print("新梯度", gradient, "保留方向", round(velocity, 3), "位置", round(position, 3))
```

輸入是我們指定的三個梯度1、1、-1，不是從模型測出的資料。v與w最初都0。第一步v=1，位置-0.1；第二步v=0.9+1=1.9，位置-0.29；第三步雖新梯度為-1，v仍為 `0.9×1.9-1=0.71`，位置繼續下降到-0.361。打印的三列把當前意見、歷史合成與真正參數移動分開，`round` 只是方便顯示。

第三步最值得觀察：當前代價的梯度已轉向，動量卻暫時延續先前方向。這可能幫助穿過小抖動，也可能讓參數越過谷底後還前進過頭。因而動量並不保證每一步的當下代價都下降，要與學習率一起看訓練曲線。μ靠近1時記憶較長，同時反轉也較慢。

優化器通常為每個參數格保存自己的v，而不是整張表共享一個方向；這一狀態會影響下次更新，所以中斷接續訓練時只存w不夠，[5.7](#5.7) 會介紹存檔。基本梯度下降沒有這份歷史，但Adam還會保存更多資訊，下一節再拆開。

這個數值演算只說明如何合成給定梯度，不知道哪個位置纔是目標，也沒有訓練語言模型。不能從位置越來越負推斷質量越來越好；如果要說代價下降，仍需額外定義代價並真的計算。

練習只把保留係數0.9改成0，先手算三位置為-0.1、-0.2、-0.1，再執行核對。第三步立即反向，因為沒有過去推力。最後試0.5，應得到v為1、1.5、-0.25：同樣的梯度序列，保留強度決定什麼時候轉彎。
