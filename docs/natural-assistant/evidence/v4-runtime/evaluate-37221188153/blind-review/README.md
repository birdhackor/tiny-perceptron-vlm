# 已選配置的最後測試證據

這裡保存一次選定配置的實際生成、四位獨立 AI 助理的原判斷，以及固定程式產生的成績。原始回答不因錯誤而刪除，截斷仍留在分母；教材正文只使用能幫助學習的說明。這份證據不是人類學生研究，也不會重新決定本版權重。

`scored/scores.json`是正式成績；`descriptive-subsets.json`僅按原逐題結果拆出動作、關係與前文條件，不新增語義判讀。`partitions/`保存四位真實審閱者各自的完整判斷及看圖紀錄。`test-closure.json`記錄來源與範圍；`persistence-index.json`核對原始複製檔案的大小與SHA-256。索引生成後新增的本README不屬於原輸出。
