# 第 14 章：逐項理解現代文字模型的設計

「小貓追小狗」換成「小狗追小貓」，詞沒變，意思卻變了。完成[一層文字模型](04.md#4.5)後，我們從這種小差別重新檢查設計：位置怎麼進入比對、數值尺度怎麼控制、哪些特徵通過，以及字的 embedding 表能否和輸出層共用一張表。每節先用固定數字追蹤一個改動；若函式庫已有對應的設定，再打開本課函式庫的實作，看 [4.5](04.md#4.5) 的 `Block` 與 [4.6](04.md#4.6) 的 `TinyLM` 換上它時改了哪一行。接著把位置範圍拉長，理解位置插值與不同轉速的調整；能算出座標，和模型能讀懂長文，仍是需要分別回答的問題。

本章依節號順讀：[14.1–14.6](14.md#14.1)檢查區塊零件與權重共享，[14.7–14.10](14.md#14.7)討論位置範圍與延伸，最後在[14.11–14.18](14.md#14.11)學 Looped Transformer，了解共享區塊（多輪共用同一組區塊參數）如何反覆更新狀態、怎樣訓練才能在不同輪數交出答案，以及多跑一輪為何不一定更好。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
