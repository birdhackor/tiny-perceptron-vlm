## 20.3 只調整一小份權重，為什麼還要載入大模型？

LoRA 修正像貼在書頁旁的幾張便條：要讀懂便條，原書仍得攤在桌上。可更新的參數少，不等於要載入的參數少。本章的圖文底座 Qwen3-VL-2B-Instruct 實際有 2,127,532,032 個參數；它是上游另外訓練好的 Dense 模型，沒有第 15 章 MoE 的 expert 路由，也不是接續第 19 章從隨機參數訓練的 MoE。選它是為了接手成熟的圖文能力，不表示 Dense 普遍優於 MoE。

先用乘法估這份底座的參數要佔多少位元組。每個參數存成一個數字；32-bit 每個數字佔 4 bytes，16-bit 佔 2 bytes：

```python
parameters = 2_127_532_032
for label, bytes_per_number in [("32-bit", 4), ("16-bit", 2)]:
    weight_bytes = parameters * bytes_per_number
    print(label, "權重數字bytes", weight_bytes, "約GiB", round(weight_bytes / 1024**3, 2))
```

`2_127_532_032` 裡的底線只是讓長數字好讀，Python 會忽略它。`for label, bytes_per_number in [...]` 每次從清單取出一組兩個值，分別取名 `label` 與 `bytes_per_number`。`1024**3` 是 1024 的三次方（`**` 是次方），也就是 1 GiB 的 bytes 數；`round(..., 2)` 取到小數兩位。32-bit 共 2,127,532,032×4＝8,510,128,128 bytes，約 7.93 GiB；16-bit 約 3.96 GiB。這段沒有載入模型，算的只是參數本身。

這可以解釋 [20.2](20.md#20.2) 記錄的兩個數字。那裡的兩個官方模型檔案共 5,889,111,977 bytes；Whisper 另有 808,878,080 個參數，兩個模型合計 2,936,410,112 個，平均每個參數約 2 bytes。那次實測的圖文模型卻以 float32（就是 32-bit）執行，每個參數在記憶體裡占 4 bytes，光是圖文底座就要上面的 7.93 GiB。服務程式的記憶體峰值約 12.87 GiB，又比 7.93 GiB 多出許多：執行時還要放 Whisper 的參數、照片換成的特徵、對話越長就越大的 KV cache（[16.2](16.md#16.2)），以及計算用的暫存空間。乘法只回答「參數本身佔多少位元組」，不能直接當成整套助理需要的記憶體。

訓練又比推論多一層負擔。即使只更新 LoRA，反向傳播仍要從輸出往回穿過 Qwen 的文字核心，才能把梯度送到修正參數，途中要用到前向計算留下的中間特徵（activation，[17.11](17.md#17.11)）。本課的訓練程式開啟了 [16.10](16.md#16.10) 的中間特徵重算（activation checkpointing）：前向時少存一些中間特徵，反向傳播需要時再重算，用額外的計算換較少的記憶體。修正參數自己的負擔反而很小：1,605,632 個修正參數（[20.6](20.md#20.6)）各有一份梯度；這次訓練用的最佳化器（optimizer）是 AdamW，它還替每個參數另存 [5.4](05.md#5.4) 的 m、v。就算每個數都用 4 bytes 存，三份合計也只有 1,605,632×4×3＝19,267,584 bytes，約 0.02 GiB。本課在 NVIDIA L4 上以 bfloat16（每個數字 16 bits）訓練 LoRA，PyTorch 記錄的 GPU 記憶體配置峰值為 5,719,892,480 bytes，約 5.33 GiB，已比 16-bit 權重的 3.96 GiB 多。紀錄只有這個總數，沒有分項，所以不能替它拆出中間特徵或其他部分各占多少；它也不含 CUDA 執行環境等其他占用，不是最低硬體需求（[訓練指引](../../docs/natural-assistant/v4/TRAINING.md)第 1 節）。所以看見 4 GiB 的權重，不能推論 4 GiB 的顯示卡就能訓練。

Whisper 另外負責語音辨識，它的參數不在圖文底座的 21 億裡。後面比較 LoRA 時，圖文底座與 Whisper 各自固定，才能把變化歸到實際改過的地方。

練習把 `parameters` 改成 Whisper 的 `808_878_080`，先預測 32-bit 約 3.01 GiB、16-bit 約 1.51 GiB，再執行核對。
