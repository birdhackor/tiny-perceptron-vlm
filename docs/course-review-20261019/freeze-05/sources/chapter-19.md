# 第 19 章：三個自行訓練的成品與 Auto 整合

前面學過文字模型、圖片與聲音的入口、機率判斷與循環深度。本章把它們做成三個可以實際使用的成品：**MoE 助理**讀文字、商品圖、字卡與錄音後用文字回答；**Looped 解題器**讀固定語法的事件或加法題，輸出答案預測（事件的狀態追蹤已通過預先訂的門檻，加法還沒達標）；**機率判斷器**依狀態、問題與候選意義回傳機率。本章依節號順讀：19.1–19.12 完成 MoE 助理的資料、訓練與驗收；19.13 對照三個成品的用途，19.14–19.20 再讀共同資料、兩個新成品與 Auto 整合。

MoE 助理是本專案第 2 版的有限多模態助理，下文的「V2」只指這個版本。它的文字核心、三個入口及接頭都由本專案從隨機權重訓練，沒有沿用別人訓練好的神經權重；圖片、字型與錄音取自明確列出的資料來源。本章把圖片入口、讀字入口與語音入口合稱**感知入口**：它們把素材轉成特徵，再由接頭轉成文字核心讀得懂的向量。先看助理真正怎麼回答，再拆開模型、資料與訓練流程，最後在[19.12](19.md#19.12)用整份測試資料核對能力與不足。另兩個成品也已完成 GPU 訓練，並在設定凍結後做過測試；從[19.13](19.md#19.13)看用途，再到[19.20](19.md#19.20)核對成績與失敗。第 20 章再把視野擴到成熟模型的應用。
