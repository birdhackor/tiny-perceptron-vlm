# 第 16 章：先量成本，再選效率做法

模型慢、長對話快取太大，或訓練批次放不下，原因可能不同。本章先讀一種可辨認的運算耗時，再分別檢查生成快取、文件裝填、梯度累積與精度。注意力分塊、中間特徵重算及編譯也各有成本：每個短程式先核對運算關係，速度與最高記憶體則帶著硬體、形狀和量測範圍閱讀。長文部分區分分塊計算與限制連結，章末再問：能否先草擬幾個token，再由原模型一起核對，少花幾輪等待？

本章也直接讀本課函式庫的實作：[16.5](16.md#16.5)節錄產生讀取許可表的`attention_mask`；[16.3](16.md#16.3)、[16.4](16.md#16.4)與[16.8](16.md#16.8)則逐一指出`CausalAttention`（主體見[3.7](03.md#3.7)）裡接續cache、共用KV頭與改用SDPA的那幾行。

[第14章的循環深度](14.md#14.11)能增加每題計算，本章再找哪些工作可省下。[7.23](07.md#7.23)的思考投入（thinking effort）只是對解題資源的偏好，不等於實際秒數。第19章比較固定檔位與Auto時，除了解題跑了幾輪，Auto選檔前做判斷的計算也算進總時間；若先用low跑完、再改用high重跑，兩次成本都要記，見[19.17](19.md#19.17)。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
