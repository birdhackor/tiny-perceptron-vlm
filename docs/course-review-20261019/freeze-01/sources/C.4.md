## C.4 找得到也選得中嗎？

2+2 的三份候選是 3、3、4。正確答案 4 已經在集合裡，多數決卻會選出現兩次的 3。所以要分開問兩件事：候選裡有沒有正確答案，以及最後交出的是不是它。不分開的話，多抽幾份可能只是讓同一個錯答案多拿幾票。

下圖上方是這組候選與正確答案，往下分成兩條路：左邊是多數決，右邊是逐份驗算的驗證器，方框裡是各自交出的答案。

![同一組候選分成兩條路：多數決選3，驗證器選4。](../figures/rewrite-C-candidate-choice.svg)

下面的程式把兩條路各走一遍：

```python
from collections import Counter

candidates = [3, 3, 4]
majority = Counter(candidates).most_common(1)[0][0]
verified = next((x for x in candidates if x == 2 + 2), None)
print("集合包含正確答案", 4 in candidates)
print("多數決", majority, "答對", majority == 4)
print("驗證器", verified, "答對", verified == 4)
```

`Counter` 是 [1.4](01.md#1.4) 的計數工具，這裡數出 3 有兩票、4 有一票；`most_common(1)` 取最常見的一項，得到 `[(3, 2)]`，兩個 `[0]` 再取出答案 3，同樣的寫法見 [6.2](06.md#6.2)。所以多數決交出 3，答錯。驗證器那一行裡，`(x for x in candidates if x == 2 + 2)` 和前面各章的 `[… for … in …]` 清單寫法一樣，逐份檢查候選、只留下等於 2+2 的那些；差別是外面用圓括號，不先做出整張清單。`next(…, None)` 取出第一個通過的值，一個都沒有時就給後面的 `None`。這裡第一個通過的是 4，答對。

多數決只看出現次數，完全不懂等式。驗證器選得中，是因為這道算術題的正確答案能從題目直接算出來（`2 + 2`），這是很強的條件。換成「某家店現在的地址」這類問題，答案要查最新資料才知道，程式算不出來；把事先知道的答案寫進程式再拿來挑候選，也只能說明這一題挑得中，不能說明它遇到不知道答案的題目也挑得中。

真實候選也有同樣的情況。[C.1](0C.md#C.1) 的短答支線在 `(3+3)+0=?`（正確答案 6）抽 4 份，得到 `[5, 7, 5, 6]`：集合裡有 6，多數決卻選了兩票的 5。兩種選法面對的是同一批候選，差別只來自選法。

所以要分開記兩個比例。步驟支線每題抽 8 份時，24 道題中有 14 題集合命中（[C.3](0C.md#C.3) 的表）；多數決在這 14 題裡選對 12 題，所以「命中之後選對」是 12/14，「全體題目最後答對」是 12/24。兩個比例的分母不同，回答的是不同的問題，不能都叫「成功率」。驗證器在這一組選對 14 題，正好等於命中的題數。

練習：把 `candidates = [3, 3, 4]` 改成 `candidates = [3, 3, 5]`。先預測：第一行變成 False；多數決仍交出 3、答錯；驗證器找不到等於 4 的候選，印出 `None`、答錯。驗證器只負責挑，候選裡沒有正確答案時，它不會自己補一個 4。

<summary>補充：實驗裡的多數決、平票與驗證器</summary>

實驗的多數決只數能解析出最後整數的候選，取票數最多的答案，不要求超過半數；平票時取先出現的那個。例如每題 2 份候選時，步驟支線在 `(5+0)+3=?`（正確答案 8）先生成答案 10、再生成 8，各一票，多數決取先出現的 10 而答錯；驗證器檢查等式後選了 8。

步驟候選要通過 [C.2](0C.md#C.2) 的四項檢查，驗證器才接受；短答候選沒有步驟，只核對最後整數。正確答案由題目的 a+b+c 直接算出，驗證器交出第一份通過的候選。已知答案命中率只看最後答案：中間等式錯、最後答案碰巧對的候選會算進命中，卻不會被驗證器接受。本實驗兩支模型、四種 k 共 8 組紀錄裡，沒有出現這種候選（`final_correct_but_steps_invalid` 都是 0），所以驗證器選對的題數正好等於命中題數。這依賴「答案能直接算出」這個強條件，不能延伸到未知事實與開放論證。

多份候選彼此一致，或每條可見等式都正確，也不足以證明這些文字反映了模型內部實際的運算。逐題結果在[實驗紀錄 reasoning.json](https://github.com/birdhackor/tiny-perceptron-vlm/blob/main/docs/course-experiments/results/reasoning.json) 各支線的 `budgets[].samples`：`majority_answer` 與 `verified_answer` 是兩種選法交出的答案；每項 budget 的 `majority_accuracy_given_coverage` 是「命中之後多數決選對」的比例。
