## 7.15 學會新任務會忘記舊任務嗎？

一個模型先學會回答顏色和形狀的題目（任務 A），再只練加法（任務 B）。兩個任務共用同一組參數，練 B 的更新可能改到 A 所依賴的數字，造成**遺忘**。要發現它，得先在兩個任務上各測一次，再從同一個模型繼續訓練，之後用同一批 A 題與 B 題重測。

A 題沿用 [7.12](#7.12) 的題型：題目寫明物件的顏色與形狀，問其中一個屬性。答案字面上就在題目裡，對人很容易，模型要做的是找到被問的屬性、照格式回答。正因為簡單，它很適合用來看遺忘：只練加法之後，模型連這種題都可能答成數字（實測見補充）。B 題是 1+1 與 2+1。下面先建立記錄表，四格 None 是還沒測的成績；真正的評估除了問題，還要保存正確答案與固定的選字規則。

```python
measurements = {
    "訓練B之前": {"A舊任務": None, "B新任務": None},
    "只訓練B之後": {"A舊任務": None, "B新任務": None},
}
a_questions = ["紅色圓形是什麼形狀？", "藍色方塊是什麼形狀？"]
b_questions = ["1+1=?", "2+1=?"]
print("固定A題", a_questions)
print("固定B題", b_questions)
print("待填成績", measurements)
```

輸入是兩份固定的評估題與一張四格的記錄表。None 表示尚未測量，不是 0 分，也不是模型拒答；這段只建立比較用的表，沒有在背後訓練模型，所以不填假成績。表的兩列是「訓練B之前」與「只訓練B之後」，兩欄是 A 與 B 的成績，下面說的成績都指這四格之一。

真正的流程是：拿已學會 A 的模型當底座，在 A、B 題各測一次，保存檢查點（checkpoint，[5.7](05.md#5.7)）；再從它接著只用 B 資料更新，保存新的檢查點，用同一批 A、B 題重測。不能新建一個隨機模型，冒充「同一個模型繼續訓練」。這些評估題必須是留出的題目：不拿來更新參數，並寫明是驗證題還是測試題。

若「只訓練B之後」的 B 成績提高、A 成績下降，可以說新的學習伴隨舊任務退步。但若 A 在「訓練B之前」就不會，「只訓練B之後」的 A 成績再低，也說明不了遺忘。專案的實測中，A 的測試題從 5/10 降到 0/10，B 的測試題仍是 0/7：這只顯示舊任務退步，不支持新能力已經學好。是否正常結束與回答風格，也要和內容分開記。

練習在 a_questions 新增一題，例如 `"紅色方塊是什麼形狀？"`，但不加入任何訓練資料。先預測：這段程式只是擴大待測清單，四格仍是 None；再執行核對。你改變的是觀察範圍，不是模型訓練；真正重測時，兩個檢查點都要用更新後的同一份清單，不能一邊多一道難題。

<summary>補充：遺忘實驗的設定與成績</summary>

本課實跑的 A 屬性任務使用 [7.13](#7.13) 保留的底座，實際的 A 題是英文欄位格式，例如 `color=blue;shape=circle;pitch=low;shape?`，答案是 `circle`；B 則是 0 到 7 的短加法題。從同一份底座接著只用 49 筆 B 題更新 500 次後，A 的十題測試題由答對 5 題降到 0 題。原本應回答 `circle` 的屬性題，這時甚至會生成 `9` 並正常結束；舊任務的內容表現確實變差，不只是多加一句客氣話。

但不能把這份結果寫成「新能力學好了，代價是忘掉舊能力」。B 的七題測試題仍是 0 題答對，雖然它的平均代價已從 7.05820 降到 4.57756，訓練資料上的代價也降了。這次看到的是舊任務退步，而新任務還沒有在沒教過的加法組合上成功。兩個加數對調的題仍放在同一家族，所以 `2+3` 教過時、`3+2` 答對不會被算成獨立的新組合。[實驗紀錄（JSON）](https://github.com/birdhackor/tiny-perceptron-vlm/blob/main/docs/course-experiments/results/sft_ablation.json)的 `results.before` 是訓練 B 之前、`results.runs.b-only` 是只訓練 B 之後，各自的 `A_attributes` 與 `B_arithmetic` 底下有驗證題（`validation`）與測試題（`test`）的成績，`matches` 是答對題數。下一節把舊題混回來，再看兩邊完整的成績。
