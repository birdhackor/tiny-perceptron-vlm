## 17.3 每個權重只差0.2，輸出也只差0.2嗎？

同一權重表的兩列是`[0.7,0.2]`與`[-0.7,1.2]`。用刻度0.5還原成`[0.5,0]`與`[-0.5,1]`，每格絕對差都是0.2。現在拿兩筆輸入`[1,1]`與`[1,−1]`作比較：輸出也都只差0.2嗎？

先寫出誤差表`w−還原值`：第一列`[0.2,0.2]`，第二列`[−0.2,0.2]`。線性層的每個輸出，是一列權重與輸入逐項相乘再相加，所以輸出差也是一列誤差與輸入的點積。輸入`[1,1]`時，第一列是`0.2×1＋0.2×1＝0.4`，兩項誤差相加；第二列是`−0.2×1＋0.2×1＝0`，正負抵消。輸入`[1,−1]`時反過來：第一列`0.2−0.2＝0`，第二列`−0.2−0.2＝−0.4`。所以單格權重誤差不能直接當成輸出誤差的上限。

```python
import torch

w = torch.tensor([[0.7, 0.2], [-0.7, 1.2]])
scale = 0.5
restored = (w / scale).round() * scale
x = torch.tensor([[1.0, 1.0], [1.0, -1.0]])
original_output = x @ w.T
compressed_output = x @ restored.T
print("權重平均絕對誤差", round((w - restored).abs().mean().item(), 4))
print("原輸出", original_output.round(decimals=4).tolist())
print("還原權重輸出", compressed_output.round(decimals=4).tolist())
print("逐項輸出差", (original_output - compressed_output).round(decimals=4).tolist())
```

`x @ w.T`讓每筆輸入與每列權重做點積：輸出的第一列屬於第一筆輸入，兩欄分別對應兩列權重。`abs().mean()`先取絕對值再平均，叫**平均絕對誤差（mean absolute error，MAE）**；先取絕對值，正負誤差才不會互相抵消。權重MAE是0.2，逐項輸出差卻約`[[0.4,0],[0,−0.4]]`，正是上面手算的四個點積。

這次restored仍是浮點tensor，沒有存成int8，目的是只看數值誤差。輸出會印出0.8999999761581421這類FP32尾數，先核對正負號與約0、0.4的差別即可。

整理成公式是`輸出差 = x @ (w−restored).T`：輸入的大小與方向都會影響誤差。模型再經過更多層與啟用函式後，還要看最終答案，不能只憑權重MAE保證品質。

練習把程式的`x = torch.tensor([[1.0, 1.0], [1.0, -1.0]])`改成`x = torch.tensor([[1.0, 1.0], [1.0, -1.0]]) * 10`。先預測：權重MAE仍是0.2，非零的輸出差變成±4。同一份壓縮權重，在不同大小的輸入下影響不同。
