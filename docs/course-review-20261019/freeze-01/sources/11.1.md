## 11.1 接頭輸出不同，就算理解圖片了嗎？

文字描述「紅色圓形」時能回答紅，換成紅圓圖片時也應回答紅，再換成藍圓圖片時應改答藍。這三個對照分別檢查原文字能力、圖片接入，以及圖片內容的作用。只知道兩個輸出分數不同，還不夠。

先看一個更小的算例：兩份輸入各有 4 個特徵，一份全 0、一份全 1，經同一個接頭（projector）各變成 8 個特徵。

```python
import torch
from torch import nn

torch.manual_seed(0)
projector = nn.Linear(4, 8)
a, b = torch.zeros(1, 4), torch.ones(1, 4)
difference = (projector(a) - projector(b)).norm()
print("輸出形狀", tuple(projector(a).shape))
print("對輸入差異敏感", difference.item() > 0)
```

輸出形狀是 `(1,8)`；兩個輸出相減後的向量長度大於 0，所以印 True。`Linear` 用權重乘輸入，再加偏移（bias）：例如只看一個輸出、權重 `[1,2,0,0]`、偏移 0.5，全 0 輸入得 0.5，全 1 輸入得 1＋2＋0＋0＋0.5＝3.5。隨機權重同樣會讓不同輸入得到不同輸出，但這裡既沒有正確答案（ground truth），也沒有文字模型，所以不能證明它懂紅藍。

「尺寸相容」只說每位置的特徵數對得上；「模態對齊」還要確認這些線索能被文字核心用來生成正確內容。原文字題先失敗，就不能把後面所有失敗歸給圖片接頭；文字題成功而圖片題失敗，才進一步查圖片特徵與接頭。

練習把下面兩行插進第一段程式，放在 `difference = ...` 那一行之前，再從頭執行。先預測「對輸入差異敏感」會印什麼：

```python
with torch.no_grad():
    projector.weight.zero_()
```

`zero_()` 把權重全部改成 0，放在 `torch.no_grad()` 裡，這次修改就不記入梯度計算。所有輸入都乘上 0，輸出只剩同一組偏移，所以差向量長度是 0，「對輸入差異敏感」印 False，形狀仍是 `(1,8)`。這是手動設定的對照，不是訓練；若在 `difference` 算完之後才清零，已算好的 `difference` 不會自己重算。這個對照能找出「通路不傳遞差異」的情況，但仍不能單獨判斷是否懂圖片。
