## 14.2 正規化能否簡化？

同一位置的三個特徵是 `[2,2,2]`。我們想控制它的數值尺度，卻有兩種可能的答案：先拿掉共同平均，會得到 `[0,0,0]`；只把三項一起除以同一個數，例如都除以2，會得到 `[1,1,1]`。前者抹掉「一起偏向正值」的資訊，後者保留它，因此兩種正規化不是同一個規則少做一行運算。這裡的特徵是同一位置向量的各項數字；尺度沿這三項計算，不把其他位置混進來，做法可回顧[4.3](04.md#4.3)。

LayerNorm先算平均，逐項減掉平均，再除以標準差。對 `[2,2,2]` 而言，平均是2，減完得到全零；雖然標準差也是零，分母的小常數能避免除以零。**均方根正規化（RMSNorm）**採用另一規則：把每項平方，求平均，再開平方根，所得稱為均方根（Root Mean Square，RMS）。此例平方都是4，均方根為2，直接用原數字除以2便得到 `[1,1,1]`。它保留三項一起偏大的部分，不先把平均搬到零。

圖中的卡片 `[1,2,3]` 表示同一位置的三個特徵。上下兩塊分別列出先減平均再除標準差，以及直接除均方根的結果。完整層還可學習逐項縮放：γ（gamma）是每項乘上的倍率，β（beta）是每項加上的偏移，和4.3的γ、β相同；標準LayerNorm兩者都有，常見RMSNorm只有γ。這裡都固定γ為1，LayerNorm的β為0，先看兩條規則本身。

![沿同一位置的特徵調整尺度，兩種規則輸出形狀相同](../figures/rewrite-14-normalization.svg)

下列輸入每一列代表一個位置，三欄代表三項特徵。`mean(..., keepdim=True)`保留一欄，方便將同一個分母除到該列三個數字上。`-1`指定最後一個軸，也就是三個特徵；`F.layer_norm` 是[4.3](04.md#4.3)那個 `nn.LayerNorm` 的函式寫法，`(3,)` 告訴它對最後三項特徵做正規化。`eps`是避免全零輸入除以零的小常數，並不是要把正常數字改成零。`from torch import nn` 留給後面節錄的 `RMSNorm` 使用。

```python
import torch
import torch.nn.functional as F
from torch import nn

x = torch.tensor([[2.0, 2.0, 2.0], [1.0, 2.0, 3.0]])
eps = 1e-5
ln = F.layer_norm(x, (3,), eps=eps)
rms = x / torch.sqrt(x.square().mean(-1, keepdim=True) + eps)
print("LN", ln.round(decimals=4))
print("RMS", rms.round(decimals=4))
```

LN第一列為全零，第二列約 `[-1.2247,0,1.2247]`：1和3位於平均2的兩側。RMS第一列約全一，第二列約 `[0.4629,0.9258,1.3887]`，因為分母是 `sqrt(14/3)`，約2.1602。兩者形狀相同，數值與意義卻不同；把訓練好的LayerNorm直接換成RMSNorm，後面的參數未必能適應。省去平均與偏移可能簡化運算，但品質與速度需要在相同模型條件下量測。

函式庫的 `RMSNorm` 把 `rms` 那一行包成一個零件，另加上可學的γ：

```python
# 節錄自 tiny_perceptron/modern.py：RMSNorm
class RMSNorm(nn.Module):
    def __init__(self, width, eps=1e-5):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(width))
        self.eps = eps

    def forward(self, x):
        scale = (x.float().square().mean(-1, keepdim=True) + self.eps).rsqrt()
        return x * scale.to(x.dtype) * self.weight
```

怎麼讀零件類別見[3.7](03.md#3.7)。`__init__` 只建立一個可學的部分：`self.weight = nn.Parameter(torch.ones(width))` 是每個特徵一個倍率，也就是上面的γ，初值都是1；`nn.Parameter` 把這排數字登記成模型的參數，訓練時會被更新。它沒有β，所以比同寬的LayerNorm少一排偏移。`self.eps` 記下防止除以零的小常數。

`forward` 的第一行算每個位置的縮放倍數：`.square().mean(-1, keepdim=True)` 沿最後一軸求平方的平均，加上 `self.eps` 後，`.rsqrt()` 取平方根的倒數 `1/sqrt(...)`。第二行把 `x` 乘上這個倍數，等於除以均方根，再逐項乘上 `self.weight`。`x.float()` 與 `scale.to(x.dtype)` 處理數字格式：第16章（[16.7](16.md#16.7)）才講較短的數字格式，這裡只需要知道，平方與平均先用32位元浮點數算，算完再換回輸入原本的格式；本節的輸入本來就是32位元，這兩步不改結果。

```python
from tiny_perceptron.model import ModelConfig, TinyLM

norm = RMSNorm(3)
print("可學的參數", list(norm.state_dict()), "初值", norm.weight.tolist())
print("與手算的 rms 相同：", torch.allclose(norm(x), rms))
for kind in ("layer", "rms"):
    model = TinyLM(ModelConfig(width=64, layers=2, heads=4, norm=kind))
    print(kind, model.blocks[0].norm1, "總參數", model.description()["parameters"])
```

`state_dict()` 列出零件的參數名（3.7）：只有 `weight`。`RMSNorm(3)` 對第一段程式的 `x` 算出與手算 `rms` 相同的結果，印出 True；這裡用 `torch.allclose` 而不是逐位元比較的 `torch.equal`，因為函式庫乘 `rsqrt()`、手算除以 `sqrt`，兩種算法在浮點數的最後幾位可能差一點點。

接回 [4.5](04.md#4.5)：精簡版 `Block` 寫的是 `nn.LayerNorm(config.width)`，函式庫版那裡是 `norm = nn.LayerNorm if config.norm == "layer" else RMSNorm`，所以 `ModelConfig(norm="rms")` 會把每個block的 `norm1`、`norm2` 換成RMSNorm；[4.6](04.md#4.6) 的 `TinyLM` 也照同一個設定換掉最後LN。迴圈裡的模型用補充區那次實驗的大小（特徵寬度64、兩層、四頭），印出的 `norm1` 從 `LayerNorm((64,), …)` 變成 `RMSNorm()`。兩層各兩處、再加最後一處，共五處正規化，每處少64個偏移，總參數從141,568減為141,248，差 `5×64=320`；`description()` 回傳設定與參數總數，見 [4.8](04.md#4.8)。

練習在第一段程式 `x = torch.tensor(...)` 那一行下面加一行 `x = x + 10`，先預測LN與RMS兩個結果哪一個不變。重跑後比較：LayerNorm會消去新增的共同平均，第二列仍約 `[-1.2247,0,1.2247]`；RMSNorm只調尺度，第二列變成約 `[0.9146,0.9977,1.0808]`。第三段程式的 `RMSNorm(3)` 跟著手算一起變，仍印出 True。這能說明「正規化」這個名字並不保證各種方法等價。

[RMSNorm原論文第4節、式4](https://arxiv.org/pdf/1910.07467v1)給出只使用均方根的規則；論文中的速度結果仍取決於其模型與硬體。[14.1補充](14.md#14.1)那份實驗紀錄是在L4 GPU上的短訓；其中LayerNorm與RMSNorm（`baseline` 與 `rmsnorm` 兩組）的驗證代價為2.26331與2.25913，測試代價為2.29163與2.28631。bias就是前面的可學偏移β；此模型五處正規化各有64個偏移，移除它們後RMSNorm少 `5×64=320` 個參數。暖機後每步的中位數（`training.warm_step_median_seconds`）卻是13.062與13.952毫秒，這輪沒有測到速度收益；計時含前向計算、反向傳播、梯度核對與更新，不是只量一個正規化函式。這個很小的代價差也只有一個隨機種子：種子是產生隨機數的起始設定，固定它可重現模型初始化及抽樣的隨機序列；換種子可能換掉起點與看到例子的次序，結果也可能改變。這次只跑一個種子，還不能把小差距當成穩定的品質優勢，需換種子重跑才能檢查。
