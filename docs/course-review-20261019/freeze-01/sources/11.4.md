## 11.4 同一張圖片，換問題後應怎麼改答案？

同一張紅圓圖，問顏色希望答「紅」，問形狀希望答「圓形」。圖片沒變，問題決定要取哪項資訊；這才是圖片問答，而不只是每次念出完整描述。

![同一紅圓合成圖，顏色問題對應紅，形狀問題對應圓形](../figures/rewrite-11-same-image-questions.svg)

```python
records = [
    {"image": "red_circle", "question": "什麼顏色？", "answer": "紅"},
    {"image": "red_circle", "question": "什麼形狀？", "answer": "圓形"},
]
for row in records:
    print(row["image"], row["question"], "→", row["answer"])
print("同圖", records[0]["image"] == records[1]["image"])
print("答案不同", records[0]["answer"] != records[1]["answer"])
```

兩筆記錄的 image 相同、答案不同，兩項比較都印 True。image 欄的 `red_circle` 只是資料名稱，不是已送進模型的像素；實際資料要同時保存圖，或保存可以重建它的生成條件，不能只教問答文字就宣稱模型看圖。

訓練時把圖、問題與正確短答保持成對，只在回答位置算代價。若生成器有隨機選擇，也要記下種子、版本與參數，才能重建材料。分成訓練資料與測試資料時，同一張原圖的所有問答都要放在同一邊；否則圖片可能已在訓練中出現過，換個問法的題目卻被當成新圖來測。

再固定問題、換圖片：紅圓與藍圓都問顏色，答案應分別是紅與藍。同圖多問檢查模型會不會按問題挑資訊，同問換圖檢查圖片有沒有作用。若只有紅圓多問，模型可能靠「顏色題就答紅」猜中。

回答「紅色圓形」雖然包含正確的詞，對只問顏色的問題仍多答了內容。所以先訂短答規則：問什麼就只答什麼，再按這個規則評內容與範圍。

練習在第一段程式的 `records` 清單最後加第三筆 `{"image": "red_circle", "question": "什麼顏色和形狀？", "answer": "紅色圓形"}`。先預測：迴圈會多印一行；「同圖」與「答案不同」只比較第 0、1 筆，仍印 True、True。這一筆的問題同時要顏色與形狀，「紅色圓形」才是符合短答規則的正確答案；同樣四個字放在只問顏色的第一筆，就是多答。
