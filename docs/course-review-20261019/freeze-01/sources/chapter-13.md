# 第 13 章：把回答偏好變成訓練

對同一問題，你可能知道哪份回答更合適，卻很難只寫一份唯一的正確答案。本章先保存比較與理由，再讓這份偏好變成可計算的訓練訊號。

本章有兩條可選路。13.1–13.6先學直接偏好最佳化（DPO）：直接用偏好對調整回答的模型。13.10–13.16改用一個選回答卡的小任務，逐步看獎勵模型、優勢、機率比、裁切與價值模型，學近端策略最佳化（PPO）的流程。13.7–13.9檢查兩條路都會遇到的資料與能力取捨，13.17並排比較。它們不是成品必須依序套用的兩道工序。[7.18](07.md#7.18)已經介紹過DPO、RLHF與PPO這幾個名字和它們的關係，本章展開機制。

每個零件都直接讀本課函式庫的實作：`tiny_perceptron/alignment.py`的`sequence_log_probability`（[13.3](#13.3)）與`dpo_loss`（[13.5](#13.5)），以及`tiny_perceptron/posttraining.py`的`preference_loss`與獎勵模型（[13.10](#13.10)）、`bandit_advantage`（[13.11](#13.11)）、`ppo_clipped_objective`（[13.13](#13.13)）、`exact_kl`（[13.14](#13.14)），最後在[13.15](#13.15)接成一輪完整的選卡與更新。讀到忘了的名詞，可查[名詞頁](../glossary.md)。

先前必修的[C.1–C.5](0C.md#C.1)研究回答時多做工作的取捨；[C.6–C.7](0C.md#C.6)在本章之後接回可驗證回饋與更新。較高的思考投入（thinking effort）與較高的獎勵（reward）都不能直接當成答對，仍要另外驗證。
