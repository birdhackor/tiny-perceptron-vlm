## 4.4 讀完前文後，每位置自己的特徵怎樣加工？

注意力讓當前位置從其他位置帶回資料；接著還需要把手上的一排特徵組合成新特徵。這個工作在各位置獨立完成，叫**前饋網路**（Feed-Forward Network，FFN）。FFN 的結構就是 [2.5](02.md#2.5) 的多層感知器（MLP）：Linear、非線性、Linear，只是在每個位置各套用一次。

本節用同一套配方處理兩個位置，每個位置的四格都是 1。先將四格擴大為十六個中間特徵，經過非線性轉換，再縮回四格。擴張讓同一排輸入先產生更多不同的特徵組合，各自經非線性加工，再由縮回層混成四格修正。擴張的是特徵，不是文字位置；縮回則讓這份修正變回四格，和輸入同形狀，才能加回 [4.2](#4.2) 的主路。十六叫**中間寬度**（程式裡的 `hidden`），是特徵寬度四格（程式裡的 `width`）的四倍。

```python
# 精簡自 tiny_perceptron/modern.py：DenseFFN（省略 relu2 與 swiglu 分支）
import torch
from torch import nn
from torch.nn import functional as F


class DenseFFN(nn.Module):
    def __init__(self, width, hidden=None):
        super().__init__()
        hidden = hidden or width * 4
        self.up, self.down = nn.Linear(width, hidden), nn.Linear(hidden, width)

    def forward(self, x):
        h = self.up(x)
        h = F.gelu(h)
        return self.down(h)
```

怎麼讀一個零件類別見 [3.7](03.md#3.7)。`hidden = hidden or width * 4` 的 `or` 表示：沒有指定 `hidden`（預設 `None`）時，改用 `width * 4`，本例是 16。下一行一次建立兩個 Linear：`up` 是四格到十六格，`down` 是十六格到四格，兩者都照 `nn.Linear` 的預設帶偏移。`forward` 依序擴張、做非線性、縮回。

這裡的非線性，也就是 [2.4](02.md#2.4) 說的**啟用函式**（activation function），用的是**高斯誤差線性單元**（Gaussian Error Linear Unit，GELU）。它和 2.4 的 ReLU 一樣是非線性，差別在曲線平滑、負數不全部清成 0：GELU 把 1 變成約 0.841、-1 變成約 -0.159、-0.5 變成約 -0.154。本課沿用函式庫預設的 GELU，不在這裡比較優劣；第 14 章（[14.4](14.md#14.4)、[14.5](14.md#14.5)）才比較其他選擇。

```python
from tiny_perceptron.modern import DenseFFN as LibraryDenseFFN

torch.manual_seed(42)
layer = DenseFFN(4)
x = torch.ones(1, 2, 4)
y = layer(x)
print("擴張後", layer.up(x).shape, "輸出", y.shape)
print(y)
library = LibraryDenseFFN(4)
library.load_state_dict(layer.state_dict())
same = torch.allclose(y, library(x))
print("與函式庫版本相同：", same)
assert same and torch.allclose(y[:, 0], y[:, 1])
```

輸入形狀 `[1,2,4]` 經 `up` 成為 `[1,2,16]`，GELU 不改形狀，`down` 再縮回 `[1,2,4]`：

`[1,2,4] → up → [1,2,16] → GELU → [1,2,16] → down → [1,2,4]`

兩個位置輸入完全相同，又使用同一配方，因此輸出兩排逐格相同，斷言核對的是值，不只是形狀。權重從亂數開始，這些輸出沒有固定意義。函式庫版用 `load_state_dict` 載入同一組參數後算出相同結果（做法見 3.7）；它另有 `activation` 參數，可換成 14.4 的 relu2 或 14.5 的 swiglu，精簡版只留預設的 GELU。

這裡的 **Dense** 表示每個位置都用完整這套 FFN，不依當前字只選部分配方；第 15 章的 MoE 才會只選一部分。共享配方不等於位置互相讀取：改變位置 1，只會透過此 FFN 改位置 1，跨位置交流由注意力做。

練習在第二段程式最後加三行：`x[0, 1, 0] = 2`、`changed = layer(x)`、`print(torch.equal(changed[0, 0], y[0, 0]), torch.equal(changed[0, 1], y[0, 1]))`。先預測印出 `True False`：位置 0 不變，位置 1 改變，再執行核對。這分清「每位置內部加工」和「跨位置讀取」。
