## 13.5 DPO如何把一對偏好變成更新方向？

沿用13.4原模型的分數：更新開始前，策略模型與參考模型相同，都是較佳−4、較差−3。先算13.4的相對差距：

`margin=(策略較佳−策略較差)−(參考較佳−參考較差)`。

本例margin為`(−4−(−3))−(−4−(−3))=0`。DPO用`L=−log(sigmoid(beta×margin))`作代價；beta是正的縮放係數。`sigmoid(z)=1/(1+exp(−z))`把差距轉到0與1之間，0變0.5，較大正值接近1。因此相對更偏向較佳答案，代價就降低。

```python
import torch
from torch.nn import functional as F  # 本節節錄的dpo_loss會用到F
from tiny_perceptron.alignment import dpo_loss

chosen = torch.tensor([-4.0], requires_grad=True)
rejected = torch.tensor([-3.0], requires_grad=True)
loss = dpo_loss(
    policy_chosen=chosen,
    policy_rejected=rejected,
    reference_chosen=torch.tensor([-4.0]),
    reference_rejected=torch.tensor([-3.0]),
    beta=0.1,
)
loss.backward()
print("代價", round(loss.item(), 4))
print("較佳梯度", round(chosen.grad.item(), 4), "較差梯度", round(rejected.grad.item(), 4))
```

呼叫時用參數名稱寫明四個分數各是誰：策略較佳、策略較差、參考較佳、參考較差。它們都是整篇答案的log機率（13.3的整段分數）。beta 0.1、margin 0時，代價約0.6931（就是`log 2`），較佳分數梯度−0.05、較差+0.05。`backward()`做反向傳播，只算梯度，沒有更新任何語言網路。

`dpo_loss`的寫法如下：

```python
# 節錄自 tiny_perceptron/alignment.py：dpo_loss
def dpo_loss(policy_chosen, policy_rejected, reference_chosen, reference_rejected, beta=0.1):
    if beta <= 0:
        raise ValueError("DPO beta 必須為正")
    relative_margin = policy_chosen - policy_rejected - (reference_chosen - reference_rejected).detach()
    return -F.logsigmoid(beta * relative_margin).mean()
```

`if beta <= 0:`先檢查設定，beta不是正數就用`raise ValueError`停下。`relative_margin`那行就是上面的margin公式；參考那一組差距後面接了`.detach()`，表示把它當成固定數字：即使傳進來的參考分數仍在追蹤梯度，代價也不會沿它去改參考。`F.logsigmoid(z)`直接算`log(sigmoid(z))`，比先算sigmoid再取log更不怕數值太小；前面的負號讓它成為代價。`.mean()`把一批偏好對的代價平均，本例只有一對。

梯度可以用紙筆核對。`−log(sigmoid(z))`對z的變化率是`−(1−sigmoid(z))`；z是beta乘margin，而margin對策略較佳分數的變化率是1、對策略較差是−1，所以

`較佳分數的梯度=−beta×(1−sigmoid(beta×margin))`，較差分數的梯度正負相反。

代入beta 0.1、margin 0，得`−0.1×(1−0.5)=−0.05`。下面第一行用逗號一次設定`beta`與`margin`兩個名字，再按公式計算，並和第一段`backward()`算出的`chosen.grad`比較：

```python
beta, margin = 0.1, torch.tensor(0.0)
formula = -beta * (1 - torch.sigmoid(beta * margin))
print("公式算的較佳梯度", round(formula.item(), 4), "與backward相同", torch.allclose(formula, chosen.grad))
```

用學習率0.1做紙上下降，舊值減去學習率乘梯度：較佳變−3.995，較差變−3.005；策略差距從−1變−0.99，相對差距從0變0.01。真模型則透過共用的參數改變每步機率，不能獨立隨意改每篇分數。

候選排序與實際回答還要分開測。實驗紀錄中，`4+2=?`的正確候選6比錯候選7有更高整段機率，模型自由生成卻回答8。它並未被限制只能選這兩篇，因此「這一對排對」仍不是「回答算對」。

練習把第一段程式的`chosen = torch.tensor([-4.0], requires_grad=True)`改成`[-5.0]`，參考保持不變。先預測：margin變−1，代價升到約0.7444；較佳梯度約−0.0525，仍為負，下降方向仍是提高相對偏好。執行後，再把第三段的`margin`改成`torch.tensor(-1.0)`，核對公式也得到−0.0525。
