## 11.14 平均物件線索，還能知道左右順序嗎？

紅條在藍條左邊，交換後紅條在右邊。兩張圖的紅藍總量相同，但「紅在藍哪邊」的答案不同。如果圖片入口只平均同一區的像素，這項位置線索可能消失。

![同一區域中的紅藍條交換，平均摘要相同，左右關係不同](../figures/practical_order.svg)

```python
from tiny_perceptron.natural_concepts import picture_order_report

report = picture_order_report()
print("不同的數值個數（RGB分開計）", report["different_pixels"])
print("4乘4平均摘要相同", report["same_4_by_4_summary"])
print("完整像素序列相同", report["same_pixel_sequence"])
```

`picture_order_report` 是本課的報告輔助函式，放在 [tiny_perceptron/natural_concepts.py](../../tiny_perceptron/natural_concepts.py)；11.15、11.16 也用同一個檔案的函式。它不需要輸入，回傳一個字典，三個鍵依序就是上面印的三件事。它先用同檔的 `swapped_picture()` 畫出兩張 32×32 的 RGB 圖：甲在第 8 到 15 列、第 0 到 3 欄放紅條，緊接著在第 4 到 7 欄放藍條；乙把前 8 欄左右翻轉，變成藍左紅右。接著把每張圖平均成 4×4 的摘要，每格平均原圖 8×8 個像素；最後比較兩張圖逐值有幾個不同、摘要是否相同、攤平成一長串的完整像素是否相同。

程式印出 128、True、False。字典的鍵名 `different_pixels` 字面上是「不同的像素」，這個名字取得不精確：它實際數的是 RGB 三個通道分開計的數值，所以上面的程式把標籤寫成「不同的數值個數（RGB分開計）」。交換的範圍是 8 列×8 欄＝64 個像素位置，每個位置的紅、藍兩個通道都改變了（綠通道沒變），所以有 64×2＝128 個數值不同。這 64 個位置都落在摘要的同一格裡，也就是圖中虛線框的「平均格」。交換後格內紅與藍各自的總和不變，所以平均也不變；保留完整序列，則仍能分辨位置。這是資訊流的反例，沒有載入模型，也不證明保留了序列就會懂自然照片。

知道圖裡有「人、杯子、桌子」也類似，不足以回答誰拿著杯子、杯子在哪邊。關係問答需要相應的材料與答案；標出物件框是提供位置的一種方法，整張圖的特徵序列也可以學著利用關係。

練習想一想：若把甲的紅條移到另一個平均格（例如第 8 到 11 欄），移動前後的兩張圖，摘要還會一樣嗎？答案思路：不會。紅色的量從原來的格搬到新的格，兩格的紅色平均都改變；平均摘要只對「同一格裡」的交換看不見。接下來 [11.17](#11.17) 的服飾關係圖會用到這個問題：明確保留物件與位置，不把物件命名直接當成關係理解。
