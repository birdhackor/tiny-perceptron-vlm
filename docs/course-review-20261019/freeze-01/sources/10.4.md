## 10.4 相同圖塊，如何知道它在左邊還是右邊？

兩塊像素內容相同的紅圖，一塊在左、一塊在右；只看內容向量，分不清它們各在哪個位置。要回答「左邊是什麼」，就得把位置也留下。做法像替每塊貼上座位號碼：準備和內容向量等寬的位置向量，加進內容向量。

下面另設一份手算式材料：1 張圖、4 個位置、每位置 3 個特徵，用全 1 向量代表相同內容。位置提示先只用位置編號 0、1、2、3；加法會把每個位置的編號加到該位置的三個特徵上，靠的就是 [10.1](10.md#10.1) 介紹的廣播。這是方便手算的提示；正式的位置向量可以在同一個位置提供三個不同的數。

```python
import torch

patches = torch.ones(1, 4, 3)
position = torch.arange(4.0)[None, :, None]
x = patches + position
print("形狀", tuple(x.shape))
print("位置0", x[0, 0].tolist())
print("位置3", x[0, 3].tolist())
print("仍相同", torch.equal(x[:, 0], x[:, 3]))
```

`arange(4.0)` 產生 0、1、2、3；`[None, :, None]` 的 `:` 保留原本的軸，兩個 `None` 在前後各補一個軸，成為 `(1,4,1)`。最後一軸長度 1，與 `patches` 的 3 個特徵相加時會自動重複。輸出仍是 `(1,4,3)`，位置 0 得 `[1,1,1]`，位置 3 得 `[4,4,4]`，最後的相同比較是 False。

正式模型使用可訓練的位置向量：[10.5](10.md#10.5) 的圖片入口替 16 個位置各準備一排可學的數字（程式裡的 `position`），一開始是很小的亂數。模型不會天生知道哪個位置在哪裡。例如 [10.2](10.md#10.2) 那張 4×4 小圖切成四塊後，位置 3 是右下那塊；但「帶著位置 3 的提示就是右下」這個意義，要靠固定的切塊順序和訓練一起建立。這裡的四個位置也不能直接套到十六塊的圖上。

還要分清兩種重排。設左、右兩個位置的內容各只有一個數：紅塊記 1、黑塊記 0，位置提示左 0、右 10。原圖紅塊在左，相加得 `[1+0, 0+10]＝[1,10]`。若只交換內容、提示留在原位，得到 `[0+0, 1+10]＝[0,11]`：數字變了，代表紅塊真的搬到右邊。若內容帶著自己的提示一起換位，得到 `[0+10, 1+0]＝[10,1]`：還是原來那兩個數，只是存放順序換了，代表的仍是「紅塊在左」。前者改變圖的內容，後者只改變儲存順序。

練習把程式的 `x = patches + position` 改成 `x = patches`，預期位置 0 和位置 3 都是 `[1,1,1]`，最後一行變成 True。它確認少掉的是位置區別，不是圖片張數或特徵寬度。
