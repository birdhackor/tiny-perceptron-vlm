## 7.18 後訓練有哪些不同教法？

問題是「只回數字：1+2=?」。可以示範 3，也可以讓人比較「3」與「答案是3喔！」哪個好，或者先讓模型作答 4，再按正誤給 0 分。先看三種給模型的材料，再記方法的名字。

示範提供期望的回答；偏好比較提供同一題的兩份回答中哪一份較好；作答後的回饋提供一個分數。這個分數叫**獎勵**（reward），是依我們指定的規則打的分，不自動等於回答的真實品質。下面的資料都是手寫的。

```python
demonstration = {"question": "只回數字：1+2=?", "answer": "3"}
preference = {"question": demonstration["question"], "chosen": "3", "rejected": "答案是3喔！"}
feedback = {"question": demonstration["question"], "sampled_answer": "4", "reward": 0}
print("示範給什麼", demonstration["answer"])
print("偏好比較什麼", preference["chosen"], "勝過", preference["rejected"])
print("作答後得到什麼", feedback["sampled_answer"], feedback["reward"])
```

輸入是我們人工寫的字典：`chosen` 表示被選為較佳、`rejected` 表示較差，`sampled_answer` 記錄作答，這裡只是用 `4` 示意，沒有真的讓模型抽樣作答。輸出依序是示範 `3`、偏好 `3` 勝過附加句、錯答 `4` 得到 0。偏好裡的兩份回答數字都對，但後者違反了「只回數字」；回饋則採用這個例子的正確性規則。換了任務，不能沿用數字 0 就假裝已定義好完整的標準。

只有理想回答時，用它當示範就是 SFT。有偏好比較時，可以直接調整模型對兩份回答的傾向，**直接偏好最佳化**（Direct Preference Optimization，DPO）是其中一種方法；它需要可靠的比較，以及一個固定參考：訓練起點的模型副本，保留下來、不再更新，用來衡量新模型偏離了多少。

也可以先用人類的偏好比較，訓練一個**獎勵模型**：輸入題目與回答，輸出一個分數。接著讓要訓練的模型自己作答，由獎勵模型替這些回答打分，再依分數更新模型，讓高分的回答更常出現。這種「自己作答、依得到的分數調整」的訓練叫**強化學習**（Reinforcement Learning，RL）。分數的源頭是人類偏好時，整個流程叫**人類回饋強化學習**（Reinforcement Learning from Human Feedback，RLHF）。**近端策略最佳化**（Proximal Policy Optimization，PPO）則是強化學習裡的一種更新方法，每次只讓回答的機率改變一小步。RLHF 說的是回饋從哪裡來、流程怎麼接，PPO 說的是參數怎麼更新，兩個名詞的層次不同；細節在第 13 章。

![同一要求可用示範、比較或作答後評分提供訊號](../figures/rewrite-07-18-feedback-materials.svg)

這些是可選的教法，不必依序全跑。若分數來自程式驗算，即使用 PPO 更新，也不叫人類回饋。[InstructGPT](https://arxiv.org/pdf/2203.02155v1) 和 [DeepSeek-R1](https://arxiv.org/pdf/2501.12948v1) 給出不同的接續配方，方法的機制在[第 13 章](13.md#13.1)展開；後訓練也可能改善任務能力，必須另用新題查證。

練習把問題改成「用一句話解釋1+2」。先寫出新的示範回答；再重新判斷原本的偏好是否還合理：`chosen` 的「3」沒有解釋，`rejected` 的「答案是3喔！」也沒有，只把兩欄對調並不夠，要把 chosen 重寫成一句真正解釋加法的話，例如「1 加 2，就是從 1 往後數 2 個，得到 3」。最後說明：若用真人比較、程式驗算或另一個模型評分，回饋的來源各是哪一種？方法的縮寫不應遮住這個差別。

<summary>補充：後訓練不只改語氣</summary>

後訓練能改變的不只語氣。若示範包含解題步驟，或回饋能辨認答案的正誤，它也可能改善模型做某些任務的能力；成功與否仍要用新題檢查。另一個實際配方是 [DeepSeek-R1 論文的 2.2 與 2.3 節](https://arxiv.org/pdf/2501.12948v1)：一條路線從已完成預訓練的底座，直接用作答回饋做強化學習；另一條先用少量理想的解題示範，教出清楚的起始回答方式，再接後續訓練。這批起步時加入的示範稱為**冷啟動資料**。兩條路線說明 SFT 不是所有強化學習配方不可省略的前一步，不代表我們的微型模型能重現論文的能力。
