# 第 20 章：延伸——沿用成熟模型處理照片、讀字與語音提問

第 19 章的三個成品，所有神經零件都從隨機參數開始訓練。本章換一個起點：直接接手別人已經訓練好的成熟模型——讀照片與文字、生成回答的 Qwen3-VL-2B-Instruct，以及把語音轉成文字的 Whisper——研究怎麼使用、微調與驗收一個已經具備能力的模型。

Qwen 在本章是底座（base model），也就是已經訓練好、拿來當下一階段起點的模型（[7.11](07.md#7.11)）。我們曾在它旁邊訓練 LoRA：底座的參數全部不動，只另外學一小份加在旁邊的修正數字，做法見 [20.6](20.md#20.6)。這樣訓練出的兩個修正版本（稱為候選）都沒有通過驗證，所以目前交付的仍是原底座，理由見 [20.8](20.md#20.8)。

各節的 Python 都是在 CPU 上幾秒就跑完的小例子，每段只隔離一個機制，沒有載入 Qwen 或 Whisper；它們的輸出不能當成完整模型能力的證據。想在自己的電腦開啟成品，見 [20.2](20.md#20.2)；想重新訓練候選，另有[訓練指引](../../docs/natural-assistant/v4/TRAINING.md)。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
