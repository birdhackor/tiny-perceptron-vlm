## 13.9 新偏好改善時，哪些原能力也要檢查？

假設只教「遇到應拒絕題，哪種拒絕更徹底」，卻沒有正常請求的完成例子。新模型可能把所有題都拒絕。只教活潑，也可能忽略JSON限制。因為新舊任務共用同一組語言模型的參數，更新一項可能影響其他項。

先列訓練資料配方，再另列要測的能力。配方是計畫，測量表是證據，兩者不能互換。

```python
recipe = {"風格": 30, "格式": 30, "應拒絕題": 20, "正常題完成": 20}
metrics = {key: None for key in ["風格", "格式", "應拒絕題", "正常題完成", "原文字任務", "反附和"]}
print("每100對的計畫", recipe, "合計", sum(recipe.values()))
for key, value in metrics.items():
    print(key, "尚未量測" if value is None else value)
```

配方合計每100對：風格30、格式30、應拒絕題20、正常題完成20。這是手寫例子，不是通用推薦比例。`metrics`那行對清單裡每個名稱建一個欄位，值都先設成`None`，表示未知；0分才是測過而失敗。`metrics.items()`逐一取出每個欄位的名稱與值，分別叫`key`與`value`；迴圈裡的`"尚未量測" if value is None else value`表示：值是`None`就印「尚未量測」，否則印出數值。執行會印出六項「尚未量測」。

六項各有用途：前四項是配方正在教的，要確認真的學到；「原文字任務」是更新前就會的能力，要確認沒被破壞；「反附和」（[13.8](#13.8)）是這份配方沒教、卻可能被影響的行為。

相同對數也可能有不同學習量。例如兩邊各100個有效目標的30對，共6000個；兩邊各10個的30對只有600個。有效目標指計分的答案token與約定的EOS，不含問題與PAD位置。資料混合時，對數與有效目標數都要記錄。

訓練後用相同的測試題比較前後，六項逐一核對。配方比例描述的是訓練資料的組成：100對裡有20對是應拒絕題。這不表示模型會「每題有20%機率拒絕」；一題該不該拒絕，要看那一題本身，所以正常題與應拒絕題要分開測，各看各的結果。哪一項沒測，就保留「尚未量測」。

練習把`recipe`裡`"正常題完成"`的20移到`"應拒絕題"`，總數仍100：應拒絕題變40、正常題完成變0。測量仍印「尚未量測」；你能指出「可能什麼都拒絕」的風險，但需要真正測正常題才能知道它是否發生。
