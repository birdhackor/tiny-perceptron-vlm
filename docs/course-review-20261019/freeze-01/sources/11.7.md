## 11.7 新圖文能力進步時，舊文字能力有沒有退步？

手寫的成績表裡，圖文題從 2/10 變成 7/10，原文字題卻從 8/10 變成 6/10。新技能進步，可以和舊技能退步同時發生。把兩類並排，才知道學習共享文字參數的代價。

```python
recipe = {"文字有效目標": 750, "圖文有效目標": 250}
recorded = {
    "訓練前": {"文字答對": 8, "圖文答對": 2},
    "訓練後": {"文字答對": 6, "圖文答對": 7},
}
total_positions = sum(recipe.values())
ratios = {}
for category, positions in recipe.items():
    ratios[category] = positions / total_positions
print("示例訓練比例", ratios)
for phase, scores in recorded.items():
    print(phase, "文字", scores["文字答對"] / 10, "圖文", scores["圖文答對"] / 10)
```

recipe 把 1,000 個有效目標分成文字 750、圖文 250，印出比例 0.75、0.25；recorded 是人工示例成績，兩類各除以固定的十題，印出前後的正確率。這段只示範報告方式，不是真的用 75% 文字回放訓練出來的結果。

能力保留是指固定一批原文字題，在訓練前後各核對一次答案。訓練前確認包裝前後計算一致（[10.8](10.md#10.8)），不能代替這項檢查。舊的文字題可以混回訓練，這叫回放（見 [7.16](07.md#7.16)）；但拿來測量的文字測試題不能混進訓練。

專案實際做過的小實驗接續 [11.5](#11.5) 的三版，另加第四版「全部＋文字回放」：開放整個模型，訓練時每一筆有 0.5 的機率改抽一筆原文字訓練題，否則照常抽圖片問答題。原文字題是底座在第 7 章學過的純文字屬性題，例如問 `color=blue;shape=circle;pitch=low;pitch?` 應答 `low`；這裡用的是它的 10 題文字測試題。圖文題與文字題的分母不同：

| 更新範圍 | 有效目標 | 圖片測試題 | 原文字測試題 |
| --- | ---: | ---: | ---: |
| 只訓練接頭 | 3,830 | 3/12 | 5/10 |
| 接頭＋最後文字區塊 | 3,830 | 12/12 | 2/10 |
| 全部 | 3,830 | 9/12 | 1/10 |
| 全部＋文字回放 | 4,214 | 9/12 | 4/10 |

四版訓練前的原文字題都是 5/10。回放版較能保住這批文字題，但沒有完全回到起點。四版都練 160 步、每步 4 筆，回放版的有效目標卻多了 384 個，表示這次抽到的文字題答案平均比圖片題長；所以它不是嚴格隔離回放比例的因果比較。0.5 是每一筆抽到文字題的機率，不表示有效目標或計算時間各占一半。

實測時要逐題看哪個答案改對、哪個改錯，並固定生成方式，不能只看淨變化。例如回放版由 5/10 變成 4/10，淨變化只少一題；逐題看卻是兩題由對變錯、一題由錯變對：問 `color=red;shape=square;pitch=high;pitch?` 原本答對 `high`，訓練後答 `cire`；同一組的 `joint?` 原本答對 `square,high`，訓練後只答 `red`；`color?` 則由錯誤的 `blow` 改成正確的 `red`。混合代價下降，也可能只是較容易的那組佔比變大。

練習只把第一段程式的 recipe 改成 `{"文字有效目標": 500, "圖文有效目標": 500}`，預期兩個比例都印 0.5；recorded 保持原值，因為改計畫不會自行產生成績。
