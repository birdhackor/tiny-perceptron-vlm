## 14.5 怎麼讓特徵控制另一組特徵？

內容路徑算出 `[2,2,2]`，但我們想讓三項分別反號、關閉、放大，要怎麼控制？一個特徵很強，不代表在每段文字裡都應使用它。例如模型辨認出「可能是人名」的訊號，但上下文顯示這是商品名稱，便需要另一組訊號調整它。普通FFN先算出內容，再經[啟用函式](14.md#14.4)改變大小；我們也能準備兩條路，一條產生內容，另一條根據同一個輸入決定每項內容要放大、縮小或反號。後者叫gate（閘門），逐項相乘的組合叫gating。

先用確定的數字把這件事拆開。內容路徑輸出 `[2,2,2]`，閘門路徑輸出 `[-2,0,2]`。我們先對閘門套**SiLU**（Sigmoid Linear Unit，Sigmoid線性單元，也稱Swish）：它把x乘上 `sigmoid(x)`，而sigmoid把任意數字變成0到1之間。-2的sigmoid約0.1192，SiLU約-0.2384；0變0；2變1.7616。再與內容逐項相乘，得到約 `[-0.4768,0,3.5232]`。第一項反號、第二項消失、第三項變大。

這個組合稱為**SwiGLU**。名字由Swish與GLU組成；GLU是Gated Linear Unit，閘門式線性單元。本例用SiLU來做閘門。名稱裡的閘門容易讓人誤以為最後係數是0到1的機率；其實SiLU仍含原來的x，輸出可以負、也可以大於1。完整層先把特徵寬度D的輸入投影成中間寬度hidden的閘門和內容，兩者相乘後，再投影回D，讓後面的模型維持原形狀。

```python
import torch
import torch.nn.functional as F

from tiny_perceptron.modern import DenseFFN

content = torch.tensor([2.0, 2.0, 2.0])
gate = torch.tensor([-2.0, 0.0, 2.0])
factor = F.silu(gate)
print("閘門係數", factor.round(decimals=4))
print("調節內容", (content * factor).round(decimals=4))
d, h = 8, 16
print("普通FFN權重數", d * h + h * d)
print("SwiGLU權重數", d * h + d * h + h * d)
layer = DenseFFN(d, h, activation="swiglu")
print("函式庫的三張權重表", [list(m.weight.shape) for m in (layer.up, layer.gate, layer.down)])
```

前三個tensor是可追蹤的小例子；`content * factor`是相同位置逐項乘，不是矩陣乘法。前兩行輸出應是上述係數和內容。接著兩行不建立隨機模型，而直接數矩陣裡的數字（`d`、`h` 就是D與hidden）：普通FFN有 `d×h` 和 `h×d` 兩張權重表，得到256；SwiGLU多了一張 `d×h` 的閘門表，得到384。這裡只數權重表，不數偏移（bias，每項額外加的常數）。

最後兩行建立函式庫的 `DenseFFN(d, h, activation="swiglu")`（[4.4](04.md#4.4)），列出 `up`、`gate`、`down` 三張權重表的形狀 `[16, 8]`、`[16, 8]`、`[8, 16]`；`nn.Linear` 的權重是 `[輸出格數, 輸入格數]`，見 [2.3](02.md#2.3)。它在 `activation="swiglu"` 時多建一個 `self.gate = nn.Linear(width, hidden)`，`forward` 裡4.4的 `h = F.gelu(h)` 那一步改成 `h = F.silu(self.gate(x)) * h`：閘門路徑算出係數，逐項乘上 `up` 算出的內容，最後一樣由 `down` 縮回。這三個Linear另各帶一排偏移，所以函式庫版實際的參數比這裡數的多。

同樣的中間寬度hidden不等於同樣的模型大小。若要公平比較，可把SwiGLU的hidden減到普通FFN的約三分之二，讓三張表的總數接近原來兩張表，再分別訓練並量測。這也說明架構設計常需要同時考慮「函式做了什麼」與「花多少參數和計算」，不能只把零件換上去就宣稱有收益。

練習把 `gate` 改成全零的 `torch.tensor([0.0, 0.0, 0.0])`，先預測「調節內容」那一行，也就是 `content * factor` 的結果，是否仍為 `[2,2,2]`，再核對輸出：SiLU(0)=0，三項都變成0，整排內容被關掉。接著只把第一項改成2，也就是 `[2.0, 0.0, 0.0]`，確認只有第一項被放大成約3.5232，其餘仍是0。你不需要訓練模型，就能先分辨逐特徵控制與把整個向量乘同一音量的差別。
