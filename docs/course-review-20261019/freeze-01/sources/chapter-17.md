# 第 17 章：量化，用更少位元表示模型

如果每個權重用更少位元保存，同一套模型可以佔較少空間，但也會丟掉部分數值細節。本章從「多少byte」開始，沿著刻度、誤差、分組與打包追到實際運算，再比較訓練後量化（PTQ）、範圍校準與量化感知訓練（QAT）。最後回到生成結果：數值接近與任務行為相同，需要不同證據。

只量化權重是一條較小的入門路線；把中間特徵（activation，層與層之間傳遞的數字，[17.11](17.md#17.11)會定義）也量化、或在訓練時就模擬量化，按需要選用。壓縮與加速也分開看，硬體是否受益要量實際後端。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
