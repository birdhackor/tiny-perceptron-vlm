## 15.7 Router 怎麼收到學習訊號？

選中expert固定輸出2，目標卻是0；我們希望router下次減少這位的貢獻。選誰的整數索引不能像連續數字一樣微分，但[合併比例](15.md#15.5)仍可能改變輸出。本節用[梯度](../first-steps.md#W.6)追蹤這條路：微調router分數時，代價如何改變？再比較把唯一比例重新正規化成1會發生什麼。

假設兩位的router分數是 `[log(2),0]`。`math.log`是自然對數，問「約2.718的數e取幾次方會得到2」，答案約0.6931；softmax使用相反的自然指數 `exp`，所以 `exp(log(2))=2`、`exp(0)=1`，再各除以總和3，比例便是 `[2/3,1/3]`，top-1選第一位；完整的分數換比例例子可回看[15.3](15.md#15.3)。這位的輸出固定為2，目標是0，於是代價取輸出與0之差的平方，也就是輸出的平方。若保留原比例，輸出是 `2×2/3=4/3`，代價 `(4/3)²=16/9`；微調第一位的分數會改變2/3這個比例，因此代價的梯度能沿比例回傳給router。

但若top-1也把唯一比例除以選中總和，結果成為 `p/p=1`，不論p微小變大或變小，輸出都是2，代價都是4。這條路給router的梯度便為零。不是PyTorch忘記學習，而是我們把唯一可以連續改變的係數消掉了。

下面的 `gate` 是乘在expert輸出上的那個係數，MoE文獻常這樣叫它；和[14.5](14.md#14.5) SwiGLU的閘門一樣，是乘上去調整份量的數，只是這裡每位expert只有一個數。`p / p if renormalize else p` 是[7.1](07.md#7.1)的條件表達式：重新正規化時取 `p / p`，否則取 `p`；`prob.topk(1).values[0]` 取出最大的那個比例。

```python
import math
import torch

for renormalize in (False, True):
    scores = torch.tensor([math.log(2), 0.0], requires_grad=True)
    prob = scores.softmax(-1)
    p = prob.topk(1).values[0]
    gate = p / p if renormalize else p
    output = gate * 2
    loss = output.square()
    loss.backward()
    print("重新正規化", renormalize, "輸出", round(output.item(), 4), "梯度", scores.grad.round(decimals=4).tolist())
```

兩輪各建立一份scores，避免前一輪的梯度累加干擾。`requires_grad=True`讓PyTorch記錄從scores到loss的運算，`backward`沿這些運算做反向傳播（backpropagation），求出梯度。未重新正規化時輸出1.3333，梯度約 `[1.1852,-1.1852]`；若沿梯度的反方向更新，第一個分數減小、第二個增加，選中者的比例降低，符合我們想降低輸出的目標。重新正規化時輸出2.0，梯度兩項都是0。

這個數值例子不代表所有MoE都必須使用相同約定。其他方法可能設計不同的連續近似，或另加鼓勵路由的代價（例如[15.9](15.md#15.9)的輔助代價）；本教材的top-1保留原softmax比例，讓任務代價能透過gate教router。top-2沿用[15.5的重新正規化](15.md#15.5)：被選兩位的原比例若是a與b，係數是 `a/(a+b)` 與 `b/(a+b)`。a稍微變大時，分子與分母一起變大，但分子增加的份量占得多，係數仍會改變：例如a、b從0.7、0.2變成0.8、0.2，第一個係數從 `0.7/0.9≈0.7778` 變成 `0.8/1.0=0.8`。只剩一位時是 `p/p`，分子與分母永遠相同，係數恆為1。所以top-2重新正規化後仍保有學習路徑，不能把top-1的結論直接套到top-2。

練習把 `output = gate * 2` 改成 `output = gate * 1`，也就是expert輸出由2改成1。先預測未重新正規化的輸出減半成0.6667；代價對輸出的導數是 `2×輸出`，輸出對gate的導數就是expert輸出，兩者都減半，所以梯度變成原來四分之一，約 `[0.2963,-0.2963]`；重跑核對。重新正規化那條路仍是零梯度。這能分清「代價大小變了」與「router是否保有學習路徑」兩個問題。
