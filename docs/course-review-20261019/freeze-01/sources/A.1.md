## A.1 給幾個例子能改變回答嗎？

「請把3轉成另一個數字」不夠明確：翻倍、平方都說得通。先給1→2、2→4，再問3，能讓讀者猜到這次想用翻倍，紙上預期6；換成1→3、2→6，則預期9。例子和問題一起成為這一次的輸入，模型的參數（parameter）沒有因此更新。

這種只靠當前前文裡的任務線索、不更新參數就改變回答的方式，叫**上下文學習**（in-context learning，ICL）。沒有示例叫 zero-shot，給幾個示例叫 few-shot；shot 數的是提示裡的例子，不是訓練步數。有限的示例仍可能符合好幾種規律，所以我們對答案的預期，要和模型實際寫出的回答分開記錄。下面的程式只組出三份提示，沒有模型。

```python
question = "請依本次規則回答：3→?"
examples = ["1→2", "2→4"]
zero = question
few = "示例：" + "；".join(examples) + "。\n" + question
changed = "示例：1→3；2→6。\n" + question
print("無例子：", zero)
print("兩例子：", few)
print("換規則：", changed)
print("三份都以同一道問題結尾", all(p.endswith(question) for p in [zero, few, changed]))
```

`"；".join(examples)` 用分號把兩個例子接成一段（`join` 見 [W.2](../first-steps.md#W.2)），`"\n"` 是換行，所以示例在第一行、問題在第二行。最後一行 `all(...)` 括號裡的 `p.endswith(question) for p in [zero, few, changed]` 是生成式（見 W.2）：讓 p 依次是三份提示，逐一檢查字串 p 是否以這道問題結尾；`all` 要每一份都成立才得到 True。它核對的是：三份提示只改了示例，問題沒有被偷偷換掉。

若真的拿模型比較，參數、問題與生成設定都不動，只換示例；每換一次，把完整提示和模型回答各記一行。為了分辨模型是依示例的規則作答，還是只記得某一道題，還要換幾個示例裡沒出現過的數字再問，例如 4 或 7。示例的順序也算一個條件：同樣兩個例子換個先後，回答可能就不同，也要分開記錄。把示例從提示拿掉之後，模型不保證繼續沿用這次的規則；要讓它長期學會，得像 [7.1](07.md#7.1) 的監督式微調（SFT）那樣更新參數，那是另一種工作。

練習只把第一段的 `examples` 改成 `["2→4", "1→2"]`。先預測：「無例子」「換規則」兩行與最後的 True 都不變，只有「兩例子」那一行的示例順序對調；再執行核對。真的拿模型比較時，這就是要另外記錄的一個條件。

<summary>補充：RAG 實驗模型的示例測試</summary>

本單元的 **RAG 實驗**（RAG 在 [A.2](0A.md#A.2) 介紹，重做方式見 A.2 補充）訓練了一個小模型，訓練資料裡也有「依本次示例換算數字」的題目：有示例的題目給兩個示例，規則是把數字加上同一個差，再只留個位數；沒有示例的題目則要回答 `UNKNOWN`。例如示例 `0->2;1->3` 表示「加 2」，所以問 3 時應答 5；`0->5;1->6` 表示「加 5」，應答 8。提示用 `->` 兩個 ASCII 符號表示箭頭（ASCII 是一套從 0 到 127 的基本字元編號，包含英文字母、數字與常見符號；UTF-8 保存這些字元時，每個只用一個 byte），和正文示例的 `→`（一個字元）不同，兩種提示的編碼不能混為一談。

題目依要換算的數字分成家族（family，同一個數字的各種示例算一家，整家放在同一邊，見 [5.12](05.md#5.12)）：六個家族當訓練資料、一個當驗證資料、一個當測試資料。測試資料只有數字 3 這一家，所以這不能當成廣泛的上下文學習評測。用同一份訓練好的參數、每一步都選分數最高的 token，實際得到：

| 本次提供的示例 | 正確答案（ground truth） | 模型生成 |
| --- | --- | --- |
| 沒有示例 | `UNKNOWN` | `UNKNOWN` |
| `0->2;1->3` | `5` | `9` |
| 改成 `0->5;1->6` | `8` | `9` |
| 交換成 `1->3;0->2` | `5` | `8` |

三份有示例的回答都錯，交換順序還改變了輸出。這次確實改了輸入，也確實讓模型生成；結果不支持它已學會依新示例運用規則。四份完整提示、原始 ID 與 EOS（結束標記）保存在[實驗紀錄 rag.json](../../docs/course-experiments/results/rag.json)，這是機器可讀的完整結果，這四筆在 `results.icl_samples_same_model_weights`。正文的翻倍示例是人造的紙上例子，不是這份成績。
