# C：必修——步驟、候選、驗證與回答當下的計算

一道算術題可以先寫出步驟再作答，可以多試幾份再挑一份交出，也可以把「答對沒有」變成分數，拿去訓練模型。前幾件發生在模型作答的時候，參數不動；最後一件會更新參數。本單元用能在紙上核對的小例子，把這些工作逐一分開說明。

C.1–C.5 接在 [7.23–7.25](07.md#7.23) 之後讀，讀完回到[第 8 章](08.md)；C.6–C.7 要用到第 13 章的獎勵與策略，等讀完[第 13 章](13.md)再回來。這些方法都要理解；實際產品用不用、用哪一種，仍看需求而定。遇到不熟的詞，可以查[名詞頁](../glossary.md)。
