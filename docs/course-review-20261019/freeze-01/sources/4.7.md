## 4.7 一次算整段時，答案該怎樣對齊？

有完整序列 `[1,2,3,4]` 時，希望模型在看到 1 後猜 2，看到 1、2 後猜 3，看到 1、2、3 後猜 4。與 [1.3](01.md#1.3) 同樣只錯開一個位置：輸入 `[1,2,3]`，答案 `[2,3,4]`。這就是 1.3 的下一位置對齊（shift）：每個位置配上右邊那個位置當答案。

![完整四個 ID 取成三個輸入與三個答案，每個位置只能讀自己及以前](../figures/rewrite-04-shift-causal.svg)

圖中上方資料知道全部四個 ID，下面每題的可讀前文卻受因果許可限制。訓練可同時算三題，是因為答案已經提供給評分；這不表示每題有權讀後面的位置。生成不知道新答案，仍需逐字接長。

本課函式庫用 `shifted` 做這一步：

```python
# 節錄自 tiny_perceptron/data.py：shifted
def shifted(ids):
    """只 shift 一次：輸入第 t 格猜原序列的第 t+1 格。"""
    if len(ids) < 2:
        raise ValueError("至少需要兩個 token 才有下一字目標")
    ids = torch.tensor(ids, dtype=torch.long)
    return ids[:-1], ids[1:]
```

`shifted` 收一串 ID。函式第一行用三個引號包住的是說明文字，其中「第 t 格」指序列第 t 個位置。`len(ids) < 2` 時用 `raise ValueError(...)` 停下（[3.7](03.md#3.7) 說過 `raise`）：至少要兩個 ID 才有一道下一字題；訊息裡的 token 是第 6 章才正式介紹的文字單位（[6.1](06.md#6.1)），這裡就是一個 ID。`torch.tensor(ids, dtype=torch.long)` 把清單轉成整數 tensor，`torch.long` 是整數型別，查表用的 ID 必須是整數。最後 `ids[:-1], ids[1:]` 就是 1.3 的兩個切片，分別當輸入與答案回傳。

```python
import torch
from tiny_perceptron.model import TinyLM, ModelConfig, masked_loss

torch.manual_seed(42)
x, y = shifted([1, 2, 3, 4])
model = TinyLM(ModelConfig(vocab_size=5, width=8))
logits = model(x[None])["logits"]
loss = masked_loss(logits, y[None])
print("問題答案", list(zip(x.tolist(), y.tolist())))
print("分數形狀", logits.shape, "平均代價", loss.item())
loss.backward()
```

`shifted` 回傳輸入 x 與答案 y，兩者各三個 ID。`TinyLM` 的內容見 [4.6](#4.6)。`x[None]` 加筆數軸，形狀成為 `[1,3]`，模型得到形狀 `[1,3,5]` 的分數；字表五候選，合法 ID 是 0 到 4。

第一行印 `(1,2)、(2,3)、(3,4)`，指各輸入位置與答案；`zip` 的配對見 1.3，`.tolist()` 把 tensor 轉成一般清單（[W.3](../first-steps.md#W.3)）。`masked_loss` 把每個位置的分數和同一位置的答案做交叉熵，再取平均，不會再錯開一次，錯開已由 `shifted` 做完；標成 -100 的答案會被跳過，怎麼跳過與它的實作見 [5.2](05.md#5.2)。本例三個答案都計入，這次平均代價約 1.827。

`loss.backward()` 只將這個代價對各參數的敏感度存起來，這次沒有 `step()` 或手動更新。模型尚未學會這段序列；示範目的是讓資料→模型→代價→梯度整條路接通。

若工具已 shift，模型內又 shift 一次，就會把「看 1 猜 2」改成「看 1 猜 3」。反過來把 `y=x.clone()`，長度仍吻合、程式仍能跑，卻改成複製目前字。先逐題讀對應，比看到代價是正數更有用。

練習把第二段程式的 `shifted([1, 2, 3, 4])` 改成 `shifted([1, 2, 3, 4, 0])`。先手寫四對，預測配對為 `(1,2)、(2,3)、(3,4)、(4,0)`、分數形狀 `[1,4,5]`，再執行核對。
