## 17.12 中間特徵的範圍，在何時決定？

中間特徵每次輸入都不同，刻度要依哪個範圍決定？事先收集的材料裡，特徵是`[−0.5,0.2,0.8,1]`，最大絕對值1；新輸入是`[−0.2,0.4,3]`，出現了3。沿用事先的範圍，3會被截到1；按這次輸入重選範圍，刻度又會變粗。

先用一批代表實際使用情境的輸入跑模型、記下中間特徵的範圍，叫**範圍校準（range calibration）**。它本身不更新模型參數，也和第9章讓信心對上正確率的機率校準是兩件事。本節把範圍事先決定的叫**固定範圍（static）**，每次看到輸入才決定的叫**動態範圍（dynamic）**。

```python
import torch

calibration = torch.tensor([-0.5, 0.2, 0.8, 1.0])
evaluation = torch.tensor([-0.2, 0.4, 3.0])
fixed_max = calibration.abs().max()
dynamic_max = evaluation.abs().max()


def simulate(x, maximum):
    scale = maximum / 7
    return (x / scale).round().clamp(-7, 7) * scale


for name, maximum in (("固定範圍", fixed_max), ("動態範圍", dynamic_max)):
    restored = simulate(evaluation, maximum)
    overflow = (evaluation.abs() > maximum).sum().item()
    print(name, "最大絕對值", maximum.item(), "超出項數", overflow, "還原值", restored.round(decimals=4).tolist())
```

`calibration`是事先收集的範圍校準材料，`evaluation`是新輸入。這個算例用4-bit對稱碼−7到7：`simulate`以`maximum/7`當刻度，讓碼7對應正的maximum；除以刻度、取整後，`clamp(-7,7)`把超出範圍的碼壓到兩端，所以還原值最多到±maximum。`(evaluation.abs() > maximum).sum()`數出有幾項超出範圍。

固定範圍是1，超出1項，還原值約`[−0.1429,0.4286,1]`；動態範圍是3，沒有超出，還原值約`[-0.0,0.4286,3]`；`-0.0`就是0，浮點數保留了原本的負號。動態範圍保住了3，卻把−0.2歸零；「沒有超出」不是唯一的品質標準。

固定範圍省去每次估範圍的工作，但範圍校準的資料若低估了實際常見的範圍，就可能頻繁截斷。動態範圍要額外統計當下的特徵，碼的數量仍然有限。範圍校準也可以按百分位數選界線，例如取涵蓋99%已收集絕對值的位置，允許極少數值被截斷，換取較細的刻度。

範圍校準的資料應涵蓋實際會遇到的內容、長度或音量；測試資料另外保留，不參與挑選。若看了測試結果再反覆選範圍，那組分數就已受到挑選的影響。

練習在程式的`calibration = torch.tensor([-0.5, 0.2, 0.8, 1.0])`方括號裡最後多放一個`3.0`，變成五個數；不是把每個數都加3。evaluation不變。先預測：固定範圍也變成3，兩種方法的還原值相同，都是`[0,0.4286,3]`（0會印成`-0.0`）。這是受控算例；實際做範圍校準時，不能先看測試題錯在哪裡，再回頭把那些輸入補進範圍校準的資料，否則測試就不再是沒參與挑選的檢查。
