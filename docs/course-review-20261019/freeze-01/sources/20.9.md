## 20.9 回答出現正確名詞，就算看懂照片了嗎？

圖裡有一個人和一輛腳踏車，人可能正在騎車，也可能只是站在車旁。說出兩個正確的名詞，還不能回答「人在做什麼」。照片問答要依請求核對物件、動作或關係，再查回答多出來的細節有沒有畫面支持。

![兩幅人工場景物件相同，人物姿勢與人車關係不同。](../figures/natural_photo_evidence.svg)

圖上的場景 A 與 B 物件相同，人與車的關係不同。下面假設題目給的是像場景 A 那樣的照片：人在騎車。`truth` 是這張照片的正確答案，`cards` 是兩張回答卡，也就是兩份待評分的回答：第一張說人在騎車，第二張說人站在車旁——後者描述的其實是場景 B。

```python
truth = {"objects": {"人", "腳踏車"}, "activity": "騎車"}
cards = [
    {"objects": {"人", "腳踏車"}, "activity": "騎車"},
    {"objects": {"人", "腳踏車"}, "activity": "站在車旁"},
]
for index, card in enumerate(cards):
    objects_match = card["objects"] == truth["objects"]
    activity_match = card["activity"] == truth["activity"]
    print("回答卡", index, "物件吻合", objects_match, "活動符合本題", activity_match)
```

`{"人", "腳踏車"}` 是一個 set，兩個 set 只要成員相同就相等，不管寫的先後。`enumerate` 逐張取出回答卡時順便給編號（W.2）。兩張卡的物件都吻合，只有第一張的活動符合「騎車」：若只核對名詞，兩張會拿到一樣的分數。程式沒有讀圖，只把評分的差別隔離出來。真正評分時允許同義的措辭，但不能把「站在車旁」當成「騎車」。

練習把 `cards` 第二張的 `"objects"` 改成 `{"人"}`，先預測「回答卡 1」的物件吻合也變成 False：漏掉腳踏車的回答，連名詞這一關都過不了。

同樣的判尺用在 [20.4 的兩隻貓訓練照片](20.md#20.4)：問數量時，答「兩隻」就完成了；問左邊那隻貓的姿勢，就核對牠是否抬起前腳。若再補一句「牠在等主人回家」，那是畫面以外的推測，回答變長不代表更完整。換一張實際照片時，即使問題、歷史與設定都不變，答案也要依新畫面重新核對；少量換圖只支持那一組對照。要報告能力，還要用沒參與本課訓練與選版的照片，分別檢查描述、可見事實問答等用途；家族怎樣整組分到驗證或測試資料，見 [20.5](20.md#20.5)。
