## 14.9 所有位置都壓近，會遇到什麼取捨？

上節把十六張卡的位置除以2，讓它們落在較短的座標範圍。代價是原本相鄰的兩張卡，新座標只差0.5。如果位置是靠轉角表示，這0.5的差會讓指針少轉多少？先把RoPE裡的指針與實際數字對起來，就能看清這個取捨。

模型替每張卡算出的Query和Key，都是一排用來比對內容的數字。RoPE將其中的特徵成對處理。例如四個數字`[1,0,1,0]`，可分成`[1,0]`與`[1,0]`兩組。每組用第一個數當水平座標、第二個數當垂直座標，就得到一支朝右的箭頭。這支箭頭可以像指針一樣繞原點旋轉；它是特徵的示意，不是卡片裡另外藏著一座鐘。

不同組使用不同轉速。在這個方便讀圖的手算例子，第一組每往後一個位置就轉60度，第二組轉15度。轉一整圈是360度，所以第一組六個位置轉完一圈，第二組要二十四個位置。旋轉頻率描述的就是相同位置增加量下，轉動得多快；每個位置轉角較大的組較快，叫**快組**，轉角較小的叫**慢組**。實際RoPE用許多組轉速，這裡先挑兩組看差異。

現在只比較位置0與1，並把兩支原始特徵都固定為朝右，隔離位置本身的作用。原來快組相差60度、慢組相差15度。位置插值後，兩張卡的座標是0與0.5，所以快組差角變成`0.5 × 60 = 30`度，慢組變成`0.5 × 15 = 7.5`度。兩組的速度雖然不同，差角卻都被同一比例減半。

下圖每個鐘面的虛線都朝右，代表位置0；實線代表原文字中緊鄰它的第二張卡。左欄使用原刻度，右欄把刻度除以2。上排先看快組60度變30度，再看下排慢組15度變7.5度。虛線只是共同起點，不代表模型一定把這個位置選成答案。

![快慢兩組指針在位置插值後，相鄰卡片的旋轉差都減半](../figures/rewrite-14-9-nearby-angles.svg)

上面的60度、15度是方便讀圖的手算轉速。函式庫的 `rope` 也一樣：每頭四個特徵時有兩對，照14.1的 `frequency` 公式，轉速是每個位置 `10000**0=1` 弧度與 `10000**(-2/4)=0.01` 弧度。下面把朝右的兩支箭頭 `[1,0,1,0]` 放在位置1，先照原刻度轉，再把位置除以2轉一次：

```python
import torch

from tiny_perceptron.modern import rope

x = torch.tensor([1.0, 0.0, 1.0, 0.0]).reshape(1, 1, 1, 4)
for scale in (1, 2):
    turned = rope(x, torch.tensor([1.0]) / scale)[0, 0, 0]
    degrees = torch.rad2deg(torch.atan2(turned[1::2], turned[0::2]))
    print("位置1除以", scale, "：兩對轉了", degrees.round(decimals=3), "度")
```

`reshape(1, 1, 1, 4)` 排成 `[筆數, 頭, 位置, 每頭格數]`，只有一個位置。`torch.tensor([1.0]) / scale` 是傳給 `rope` 的位置：原刻度是1，插值後是0.5。`turned[0::2]`、`turned[1::2]` 照14.1的切片取回兩對的水平與垂直座標；`torch.atan2(垂直, 水平)` 由兩個座標反推箭頭轉了幾弧度，`torch.rad2deg` 再換成度。位置0的箭頭沒有轉，所以印出的就是相鄰兩張卡的差角：原刻度約57.296度與0.573度，除以2後約28.648度與0.286度，快慢兩對一起減半。

較小差角並沒有把兩張卡變成同一張。它們的文字特徵仍可不同，多組旋轉也會一起提供位置資訊。但模型在訓練中學過的比對關係，可能使用原來的近距離差角；換成更密的刻度後，這些關係需要適應。若為了放進更多文字而縮得更多，近處原本相差一個位置的兩張卡，在位置數字中就靠得更近。不能只因為最遠的座標回到原來的範圍，就忽略近處也被改動了。

快組與慢組一起使用，也提供了設計的方向。快組在很短的位移內就出現明顯角度變化；慢組在較長的範圍仍緩慢改變。單支指針轉完整圈會回到相同方向，所以不能單靠快組那一支判斷所有遠近；模型還要結合其他轉速與內容。延長範圍時，可以思考讓某些組保留較多原轉速，而由另一些組承擔較多縮放，而非所有組一律減速。

練習把位置縮放改成除以4，仍比較原位置0與1。先預測兩組差角，再用每個位置的轉角乘0.25核對：快組是15度，慢組是3.75度。接著把程式的 `(1, 2)` 改成 `(1, 4)`，核對函式庫的兩對也變成原來的四分之一：約14.324度與0.143度。下一節的YaRN就從不同轉速應承擔不同縮放開始。
