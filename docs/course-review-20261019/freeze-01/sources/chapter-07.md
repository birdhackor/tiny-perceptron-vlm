# 第 7 章：從續寫文字到回答問題

從一筆「1+1=?→2」開始，追蹤誰在說話、回答的第一個 token 在哪個位置被預測，以及哪些內容只供讀取、哪些答案要計代價。接著處理填充、結束與截斷，再把這些約定接到監督式微調（SFT），並用留出的驗證題與測試題檢查成果。章末比較預訓練與後訓練的教法、數清前文與回答各佔多少容量，最後改一個訓練問題：讀到同一處時，除了下一個 token，能否也練習預測再下一個？

學會回答與長度上限後，[7.23–7.25](07.md#7.23)把思考投入（thinking effort）納入必修，分辨請求偏好、實際計算與答案品質；接著必修[C.1–C.5](0C.md#C.1)，比較步驟、候選與驗證的成本。讀到忘了的名詞，可以查[名詞頁](../glossary.md)。
