# 可直接貼用的寫作 prompt

依 [SKILL.md](../SKILL.md) 與使用者本輪的階段、範圍及讀者背景撰寫教材。每節先保留原本學習問題與各項承諾，按當下用途判導覽／操作性質／設計理由的深度。方法理由先用一句不依賴所選方法名稱、可判符合與否的話說清希望的答案或工作，再從已懂材料開始。按實際依賴安排：重要設計、規則、轉換與限定的必要前提在哪裡？包含沒有名稱的使用約定和狀態變化；規劃不必放入學生正文，不提前交首次閱讀者。

入口以必要背景與短歷史建立大局觀，再接階段動機。每小節聚焦一個主要學習問題；先展示材料、任務與答案，再引入表示、公式與程式。沿用例子；更換材料、表示、方法或評分時交代理由與保留的關係。必要概念在首次用於推理或使用規則前，介紹名稱、當下意義、角色及理由；完整名稱不能代替解釋，尚未需要的完整內部推導可待教。

介紹方法時，分開自查「機制／性質」與「需要／用途」：做法改變什麼，以及原文或使用者要求的哪個需要用得到它，各自核對來源與連結；純性質教學不另編應用。主動指出原需要、關鍵作用發揮的條件及新舊做法的工作。各項理由只驗收其實際支持的承諾；同段另有設計或用途，須一併接起，不以一個有用特例包辦其餘。可用一般性說明、圖或由已教前提直接推得的關係，不固定例數。新性質不能反過來當原需要，概括好處不能代替解釋。新動作至少說清當下要用的行為，目的不代替操作；限定以自己的對象說明與前文的關係。改換已教方法仍交代最低選擇目的；公平描述舊方法，不虛構它無法完成同一需要。

按原問題選例子，讓必要的變化、保持關係與分工直接可見，說明關鍵作用實際發揮在哪種工作情況，再連回一般方法。特例可教特例，不包辦未呈現的更廣用途。算出結果、理解共同規則、理解設計理由與證明實際效果分開驗收；局部操作或性質教完，接回最近尚未答完的原學習問題；所需答案與工作不能由新性質反過來定義。寫完核對原先承諾，不事後縮成例子剛好支持的目的。不固定數字組數。明確假設可示意機制，不要求實測；效果主張才需相應證據與條件。

任意編號、介面約定與狀態如何更新，在使用前交代；已教前提可正常推得者不用重寫證明。限定先比對前文已排除什麼誤解；換主詞或層次者說清新增關係與當下用途。技術正確但打斷理解者改寫或移位，冗餘不自動升必要。入口導覽教夠角色與後續方向，不要求推導全部歷史成因。必要直覺、算例與圖放在正文首次需要處且相鄰，完整推導、變體與重做紀錄可補充。圖、文字、數字與程式一致，當前必要對象及跨表示對應可辨認；分清類型標籤、不同對象與同一量重用。只建立必要區別，允許明確位置及正常推論，不要求每框異字，不只憑數值相等判為同一對象。實際桌面和手機合理可讀。

審閱與紀錄依 [review-protocol.md](review-protocol.md)，判準可參照[跨領域校準例](calibration.md)。通用規則不放待審教材的修正答案；首次閱讀者不取得同款示範、作者結論、舊問題或技術答案。先保存獨立初判，再交叉覆核，最後比較歷史問題。必要理解仍需猜測或拼湊時具體列待修；合理推得留下必要推論，未知不自動算通過或缺陷。後文釐清追加位置，不改早期紀錄。未做檢查不宣稱通過，skill 更新不代表教材已驗收。

綜整審閱時，主 Agent 另從未報問題的通過圖親看原位圖文，抽查必要對應的證據，依審閱流程保存覆核範圍；也要核對每項可選建議的具體理解收益，連同必要項記處置與理由；用最小充分改動權衡篇幅和新增先備，不因可選而略過，也不一律採用、擴寫或升成必要。可選分級不決定應放選讀；保留原始發現與分級，作者依核實後的處置修改。
