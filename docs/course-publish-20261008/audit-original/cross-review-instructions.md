# 封存後交叉覆核

本檔不提供預期答案。只在全書三輪來源初判均已封存後使用。

先重新確認自己 initial 與 main-notes 的 seal；不修改這些原始記錄。讀取同組 reader-main、reader final、technical initial、continuity initial 以及該組已存在的獨立補件。對已報必要問題和所有可選項逐項覆核，不以票數或原分級決定。去重可按同一理解關係合併，但留下全部 origin IDs。

每項附最強原文證據、實際必要前文、原承諾、已完成部分、剩餘最小缺口或反證。分開機制與需要來源；不要從新方法的產物自編原需要，也不要只因頁名是操作就縮掉正文的採用理由。前文已教可正常推論，未教領域知識或任意約定不可算已教。正文與選讀依選定路線與理解用途判，不要求全部完整重做配方搬到正文。

給出覆核後必要性與處置建議（採用／延後／保留原文／待查），說明具體理解或操作收益、最小改動與新增負擔，及 paragraph/page/chapter/order 規模。未驗範圍不自動判錯或放行。覆核自己 initial 的 strongest passes 和主要需要關係，不只追問題；保存幾個最強反例或通過理由。

圖或版面有爭議時，親看指定原位 PNG 或做相稱的局部互動；先 view_image，後續呼叫才寫判斷。不要用 DOM、source 或檔名代替實看，不把一般捲動能讀取的暫時遮擋直接稱為無法閱讀。原本未驗者若補查，另附範圍。

不得讀既有歷史審閱結論、不得改教材或原始結果、不得訓練或再派 agent。本輪是互見後覆核，不能算第二份獨立發現。新發現標記時點與可見資訊。

寫 `reports/cross-GROUP.json`，列 reviewer、讀過的各來源報告 SHA、issues/dispositions（完整 origin IDs）、通過覆核、未知範圍及修補級別。另寫獨立 SHA seal。回報是否有 page/chapter/order 改寫必要。可以保持精簡，但不得省掉可選項裁定。原始來源判斷與歷史比對保持分離。
