## 7.20 下一個之外，還能一起練習預測什麼？

讀到「雨」，下一個字可能是「停」；若訓練材料的完整句子是「雨停了」，再下一個則是「了」。以前每個位置只交一份下一步答案。現在想讓模型讀同一段前文時，也為稍遠的未來做準備，可以多交一份「再下一步」的答案。

這種訓練稱為 **Multi-Token Prediction（MTP，多 token 預測）**。它改的是學習目標：在同一個前文位置，要求模型預測不止一個未來token。希望這些額外練習能讓共用特徵包含對後續有用的線索；是否真的改善能力，要看資料、架構與訓練條件。先看目標怎麼改，不把它當成已學會整句話。

本例特別指定每個中文字各是一個token，另有開始標記〈B〉與結束標記〈E〉；它們也各佔一格。訓練序列是「〈B〉／雨／停／了／〈E〉」。斜線只表示分格。讀到「雨」的特徵只能使用〈B〉和雨，不能先讀到停與了。

把這份特徵送到兩條預測分支。第一條預測下一項停；第二條預測隔兩格的了。**預測分支也叫輸出頭（output head）**，是把特徵轉成詞表分數的網路，不是[注意力頭](03.md#3.7)。兩條分支共用讀前文的核心，卻各有自己的預測任務。

![讀到雨的同一份因果特徵分給兩條輸出分支；下一項目標是停，隔兩格目標是了](../figures/p7-7.20-future-targets.svg)

圖中的「停」與「了」是用來核對的標準答案，不是事先塞給共同核心的輸入。這個平行版本中，第二條分支也不先接第一條猜出的停；兩條都從相同的已讀前文預測。它們可以猜錯，也可能彼此不搭配。

| 核心目前讀到哪裡 | 下一項的答案 | 隔兩格的答案 |
| --- | --- | --- |
| 〈B〉 | 雨 | 停 |
| 〈B〉／雨 | 停 | 了 |
| 〈B〉／雨／停 | 了 | 〈E〉 |
| 〈B〉／雨／停／了 | 〈E〉 | 沒有這份目標 |

表中第一欄每次往前一格，兩條分支的標準答案也跟著移動。整批訓練可以同時算很多位置，但[因果遮罩](03.md#3.6)仍限制每一格只讀當時的前文。「原本一次就算很多格」和「同一格多交未來答案」是不同改動。

練習把句子改成「雨又停了」，每字仍各一token。讀到「雨」時，兩條分支各應學什麼？第一條是又，第二條是停。這時第二條還不能直接拿了當答案；它的距離是隔兩格，不是「永遠猜句子的最後一字」。

[Gloeckle等人2024原論文第2節](https://arxiv.org/pdf/2404.19737v1)使用共享核心及獨立未來分支。原文分支含Transformer層，再共用將特徵映成詞表分數的矩陣；本圖只展開任務關係，不把分支限定為一個線性層。原論文的比較還會調整核心與分支的層數，不能把增加分支說成免費增加能力。

只用第一條分支，也能照常逐token生成。額外分支能否拿來加速，另需草稿與驗證程序，見[16.14](16.md#16.14)。
