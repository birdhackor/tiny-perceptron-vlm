# 第一階段定稿：內容安排與成品範圍

## 先確定教學的工作

從「接下一個字」開始，依序建立可調參數、上下文、注意力、初始 Transformer、資料與訓練、對話。每個主題只在讀者遇到具體問題時擴展；現代架構、加速與壓縮仍放在基礎之後。局部教材可以切換小模型，不要求整本書始終訓練同一份權重。

主線最後回到同一個自行訓練的小助理，串接有限的文字、圖片、語音與工具。目的在於看懂零件如何真正合作，並處理少數教過類型的新例子。第 20 章的成熟模型應用清楚標成延伸，不擔任主線畢業成品。

既有 pre-train／post-train、SFT、RLHF／PPO／DPO、Dense／MoE、工具、量化與蒸餾保留。不重複新增同名介紹，也不要求成品先後套用所有互為替代的方法。

## 新增小節

保留既有編號以便書籤接續，新節採各主題後續編號。章內正文與導覽在第三階段再整體整合；本表只定義第二階段要寫的內容。

| 小節 | 學習問題 | 本節的單一重點 | 材料／必要圖解 |
| --- | --- | --- | --- |
| 7.19 | 回答能寫多長，和前文能放多少，有何不同？ | 新回答上限與整段可用範圍不同 | 16 格的序列化訊息，角色標記、歷史、預留回答與提前結束；不只重複 A.7 的加法 |
| 8.14 | 答案對了，為什麼仍沒完成要求？ | 內容正確之外，指定範圍也要符合 | 提供可讀的文字告示，對照只取中文與多抄英文；不把尚未教的 OCR 當前置 |
| 8.15 | 同一份材料，如何依不同要求作答？ | 任務由請求與材料共同決定 | 同一清單，全部列出或只取指定項 |
| 8.16 | 範圍、格式與結束，如何各自教與檢查？ | 示範和驗收包含所要求的行為 | 好答案及各種只違反一項的答案 |
| 11.17 | 有限物件與短字詞，如何做成可學的看圖問答？ | 明確任務、有限答案與有用特徵的對應 | 少數服飾商品圖、短字詞，區分單物件與關係問題 |
| 11.18 | 指定哪一塊文字，如何只讀那一塊？ | 選取區域與讀出字詞分開理解 | 兩個文字區域與清楚標示的指定框 |
| 12.15 | 幾種真人語音問題，如何從零學會回應？ | 有限語音意圖可以直接接到文字回答 | 波形／頻譜→自訓練入口→同一文字核心 |

| 14.7 | 為什麼位置公式算得出，長文章卻未必讀得好？ | 訓練範圍、設定容量與任務能力不同 | 學過與新出現的位置／相對距離 |
| 14.8 | 位置插值如何延長窗口？ | 位置座標縮放，不是刪掉文字 | 16張卡片仍在，刻度縮回熟悉範圍 |
| 14.9 | 所有位置都壓近，會遇到什麼取捨？ | 鄰近位置的分辨與較遠範圍有取捨 | 先交代成對特徵、角度與頻率，再畫快慢旋轉指針及相鄰位置的角度 |
| 14.10 | YaRN如何兼顧近處與遠處？ | 不同旋轉維度採不同縮放，另調注意力尺度 | 分頻處理的示意；推導放選讀 |
| 16.12 | 滑動窗口省下什麼，也限制了什麼？ | 本層直接可見範圍與層間傳遞不同 | 八位置的可見配對與兩層傳遞 |
| 16.13 | 分塊處理，是否代表看不到其他塊？ | 執行分塊與限制資訊連結是兩件事 | 承接 16.9 的分塊運算，對照完整／滑窗／區塊局部的配對圖 |
| A.8 | 同一條線索，放在哪裡會有差嗎？ | 控制位置來看資料是否被穩定使用 | 同總長度、線索、問題與生成上限，只改首／中／尾位置 |

| A.10 | 對話很長，最新的條件如何驗收？ | 更改、時間與資料不足各要驗收 | 舊時間→新時間，另問未曾提供的事項 |

## 第三階段的改寫範圍

所有既有課文、閱讀入口、暖身、操作頁與名詞頁逐項整理。保留有意義的既有機制示範，不為了變新而重做已知實驗。

- 開頭先說清楚一件人能理解的事，前置連結與安裝／重做資訊放補充區；當下必需的回顧留在使用位置。
- 10.5以明確的顏色或形狀任務建立答案，數字編碼在對應已清楚後才出現；展示素材、分類流與回傳訊號。梯度計算與參數更新分清楚。六類與服飾的長配方移到操作／查證頁，不讓一節跳三個目的。
- 圖解補足素材、對應與機制，而非為了有圖而有圖。桌面正文必需細節可直接讀，手機也可理解，動畫停下仍有資訊。
- 使用成熟知識解釋用途與取捨，主文刪除無學習用途的逐步數字、實驗進度與失敗流水。保留能教一個明確差異的結果或錯例。
- 第19章逐項呈現共同模型、資料、訓練階段、輸入／輸出及工具；成品事實在第五階段完成後另回填。
- 第20章保留來源與實際流程，明確說明這是沿用既有模型的延伸，不當主線的能力證據。

## 主線成品的有限任務

以下是第五階段的設計目標，尚不是新成品已具備的能力。主線組件從隨機權重建立，訓練來源可查。預定小MoE加Dense對照；層數、寬度與參數量由之後的受控試跑決定。

| 任務組 | 初始範圍 | 驗收 | 明確界線 |
| --- | --- | --- | --- |
| 文字與指令 | 短問答、照抄、條件式選取、簡短格式、缺資訊時澄清 | 分開檢查答案、指定範圍、格式、EOS；使用新問法與題目家族 | 不聲稱通用中文助理或任意程式問答 |
| 物件與關係 | Fashion-MNIST的褲子、包、短靴；用原始素材製成兩物件位置場景 | 新原始影像、左右互換、問題改問另一物件；移除／錯配圖像對照 | 服飾商品圖與自製關係場景，不是任意自然照片理解 |
| 中文短字詞 | 12字「大小上下左右開關入出人口」，2–4字、少數行、指定區域 | 留出字體或版面變體；內容、範圍、換行各自記錄 | 自製招牌及已知字表；固定框不代表一般文字偵測 |
| 真人短語音 | MInDS-14中文少數銀行意圖，預計3類；回覆短中文提示或澄清 | 留出原始錄音、按來源ID綁定變體；打字／語音共用對話；移除／錯配聲音對照 | 語音意圖問答，不稱通用ASR；沒有speaker ID，不聲稱跨說話者驗收 |
| 使用工具 | 小整數加法、要求工具、讀回結果、工具關閉時說明 | 第一段請求、工具實際執行與第二段回答各保存 | 計算器是可檢查的程式，不將工具答案冒充模型自己的計算 |

MInDS銀行意圖只有公開語音情境；模型不接真實帳戶，也不生成未知餘額。若採用轉寫，先核對原來源是自動轉寫，不能稱人工聽寫真值。資料沒有某個來源欄位，就明確保留未知，不補造來源身份。

資料分割以原始素材與衍生家族為單位，過去公開的最後題作回歸，不拿來調新模型後仍稱未見測試。新成品最後題預先保留；每項同時看短回答完整性與任務正確，不以平均分遮住未具備的能力。

第一階段不預設所有任務都會達標。如果第五階段需要收斂範圍，先在驗證題決定、明確记錄；不能打開最後題後挑漂亮案例，或用成熟模型補上失敗再當作自行訓練成功。

## 寫作與驗收的界線

新內容在第二階段先存獨立稿件，不邊寫邊修改舊章。第三階段才整合入同源課文、圖解、Notebook與網站導覽。第四階段先易讀，再技術，再銜接；修正後重查受影響內容，既有過期pass只保留作歷史。

閱讀時間在最後文本穩定後重估。GPU工作只在第五階段，沿用已授權預算與持久帳本；文字／排版更新不重跑訓練。
