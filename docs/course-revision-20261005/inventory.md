## 4. 10.5的直接問題與同類風險

### 4.1 10.5須先決定任務，再拆節

來源：[10.5](../../course/chapters/10.md#10.5)。當前開场說「兩張圖片一張紅方塊、一張藍圓形，讓它預測各自編號」，之後才在程式出現`[0,1]`。這還沒有說清要分類形狀、顏色、兩種組合或兩張素材的身分。紅與方、藍與圓綁定，也無法單獨證明學到形狀。

該節後續從`backward()`沒有更新的示範，轉成六類、訓練／驗證／測試新位置，再轉到新視覺入口＋文字底座的Fashion-MNIST生成回答。三段用不同材料、模型、答案與證據，標題「可用的視覺特徵」不足以替初學者說明每次切換。

建議拆成三個問題，編號先不凍結：

| 候選小節問題 | 材料／希望得到什麼 | 必要可見內容 |
| --- | --- | --- |
| 指定分類任務後，猜錯如何把訊號傳回圖片入口？ | 展示原圖與人類類別名，再定義0／1；只驗證梯度通路 | 兩圖、標簽與數字對應；明說未更新 |
| 更新後，六種已知組合能否在新位置辨別？ | 六類颜色×形状，明確按位置留出 | 六類圖格＋類名；同一類在train/validation/test三種位置的實際示意 |
| 真實服飾輪廓改成文字標籤後，哪裡仍會失敗？ | Fashion-MNIST命名；這是新任務與新訓練起點 | 至少一筆真實服飾圖、真值、實際錯誤回答；30／10／10切分的簡明圖表 |

主文10.5沒有圖引用；六類素材、數字標籤和位移差異不應只讓讀者想像。第三段若保留為補充，也仍需顯示其實際材料，不能只留下`3/10`。

### 4.2 需在第三／第四階段檢查的共通類型

| 類型 | 本輪看到的具體例子 | 改寫方向 |
| --- | --- | --- |
| 任務比數字晚出現 | 10.5「各自編號」；圖／聲音任務跨實驗時答案含義改變 | 在首次編號／loss之前交代輸入與人類答案；任務改變重新說明 |
| 一個標題切換多個實驗 | 10.5梯度→六類分類→服飾回答；12.8投影→單音分類→真人數字 | 一小節一個主要學習問題；用明確過渡說明為何換任務 |
| 圖／素材沒有回答讀者的問題 | 10.5六類與位移無圖；12.8的說話者切分圖不能代替可聽的真人素材 | 檢查實際素材、空間/時間差異、標簽對應；已有圖不等於素材充分 |
| 前置連結變成另一份長清單 | 19.4一次指向兩階段、遮罩、存檔、MoE與13.17角色；19.2先回15.2/15.10/15.11 | 順序讀者用一句必要回顧即可；跳讀補課路徑放導覽框，保留概念前置 |
| 表面順序與建議路徑不一致 | 第7章章首建議7.11→7.17→7.18→7.12 | 大綱把最少流程地圖放到需要處，第三階段維持舊編號並調整導覽 |
| 完整參數稀釋教學變化 | 10.5六類實驗一次列尺寸、patch、寬、參數、步數、batch、seed、學習率；12.8真人支線又帶入176位置擴充 | 主文說明本次主要變化及關鍵限制；完整可重做配方放操作頁 |
| 同一限制在多處重複出現 | EOS≠答對分散在7.9、8章、11.13、12.8、A.7、19/20章 | 用共同判分框架連續教會一次；後文只保留該任務的新失敗證據 |
| 失敗數字佔據主線 | 5.8機制之後接規則續寫與TinyStories；7.10截斷之後接UltraChat；18.10蒸餾之後接0/2域外GSM8K | 一次保留最能說明學習問題的反例；不同任務獨立展開。低分本身不是易讀性問題 |
| 示範／更新／能力證據未形成直觀層次 | 19.4短代碼用隨機Dense，正式成品MoE接續；13章PPO選整篇卡片 | 明確說明局部模型為何更簡單、代碼證明什麼，再用單獨結果確認能力 |
| 跨章依賴讓成品入口過重 | 19章依賴B工具、15MoE、13偏好、10–12模態；20.3又從19.2取total/active | 成品前提供最短核心；更深比較、另一條成品路線不會成為強制前置 |

上述例子是規劃風險與直接閱讀發現，尚未逐節完成第四階段的易讀／技術／銜接審閱。尤其「參數多」「失敗多」不能單靠計數判定不合格；要看每項是否幫助當前學習問題。

M與Q是第19／20章第三階段重整時的銜接候選，不另增同名成品章。具體成品材料與任務，以outline.md的第五階段範圍為準。

### I：一次完成指令、回答與停止

依賴：1.14逐步生成→6.6/6.7結構／文字單元→7.1–7.5回答位置→7.9/7.10→8.5格式。用一套「取給定記錄中的指定欄位」材料貫穿；不要另換成算術能力來解釋格式失敗。

| 次序 | 一個主要學習問題 | 新增價值／可見檢查 |
| --- | --- | --- |
| I1 | 同一份資料只改「要哪個欄位」，什麼回答才算服從？ | 把內容／指定範圍／格式拆開；與8.5既有JSON規則互補 |
| I2 | 正確內容已輸出，但沒有結束標記，算完成嗎？ | 同一答案展示EOS、提早EOS、上限截停；保留原始ID與可見文字 |
| I3 | 完整提示和答案預留，怎樣共同占用上下文？ | 把A.7的算術橋梁接到實際序列化／token計數；包含歷史與格式 |
| I4 | 上限太短、太長或答案EOS被切掉，各改變哪件事？ | 訓練截斷與生成截斷分開；易懂長度條顯示被保留/遗漏部分 |
| I5 | 內容、格式、正常結束與整題成功，如何在同一批題分別記錄？ | 每項有分母與反例；不再到各章重複重新解釋 |

I1–I5是在已有零件間增加同任務連續教材，不能寫成現有7.9完全沒有EOS教學。

### L：上下文變長之後，能否用對線索？

依賴：2.5窗口→4.1位置上限→6.8窗口與tokenizer区別→I3/I4→14.1相對位置；量測依5.9與16.3/16.9按需補足。先教長度與行為，再教延伸方法。

| 次序 | 一個主要學習問題 | 材料與最小比較 |
| --- | --- | --- |
| L1 | 長度上限、訓練見過的長度與實際能用的線索，是同一件事嗎？ | 一份有明確答案的短記錄逐漸加干擾；分清可接受輸入與答對 |
| L2 | 只把位置表或設定上限改大，為何仍不等於學會長文？ | 展示原長度／新增位置／訓練長度圖，不由形状成功填能力結論 |
| L3 | 線索放開頭、中間、末尾，答案會不同嗎？ | Lost in the Middle受控設計：同事實、同問題、同總長度，位置是主要變化 |
| L4 | 是線索位置，還是整段更長造成退步？ | 單獨掃總長度；保留答案長度與輸出預算，避免混在同一組 |
| L5 | 相對位置如何協助延伸，還需要補哪些訓練？ | 從14.1直覺接一個可理解的延伸办法；先進RoPE縮放細節放補充 |
| L6 | 全文、分段檢索與摘要各保留／丟掉哪些必要條件？ | 從同一道任務比較提供給模型的證據；與A支線銜接，非重複新增RAG |

第二階段可以先寫可人工核對的設計、示意與預期觀察項；新增模型能力或數字只在第五／第六階段取得實際證據後填入，不先承諾中間位置一定最差。

### V／O／H：從玩具材料到有限真實材料

依賴：10–12章對應表示與監督概念、I分項判分。原則是先縮任務，不以換更大模型代替材料說明。已有20章能力驗收不需要複製為另一整章。

| 次序 | 一個主要學習問題 | 新增的有限教學包 |
| --- | --- | --- |
| V1 | 一張真實圖裡，哪個可見事實支持這個短答案？ | 少量實際圖片、單一問題、真值與不可推論部分；來源與split留記錄 |
| V2 | 問題固定只換圖，答案是否隨可見線索改變？ | 控制素材配對與不看圖基準；接11.8，不重新定義消融 |
| V3 | 縮圖或裁切後，模型還收到回答所需的線索嗎？ | 實圖前後並排；題目與真值不變，解釋是否仍可回答 |
| O1 | 只抄指定區域，與抄整張圖，是不同指令嗎？ | 一張少字圖，框出實際区域，同圖改请求；先教答案範圍 |
| O2 | 少一字、錯一字、換順序，如何用已學判尺區分？ | 與11.13/11.16已教CER和整串匹配接續；不新設重複公式課 |
| O3 | 中文小筆畫和多行順序，哪一步需要保留位置？ | 真實／合成材料明標；少量中文樣本與不同讀序分開 |
| H1 | 真人短錄音的答案是單詞、逐字稿，還是回應？ | 可聽短音、原話、任務及答案卡並排；先区分任務 |
| H2 | 換一段未用於訓練的真人錄音，原任務是否仍然成立？ | 按原始錄音切分、衍生版本綁定；只有資料明確提供說話者身份時，才另談跨說話者留出。不把單音與意圖／短句混合計分 |
| H3 | 否定詞或數字聽錯，後面的回答會怎樣改變？ | 正確文字、實際ASR逐字稿、兩路回答並排；接12.14/20.12 |

局部教學模型在寫作時可以按問題替換；具體規模與樣本量依可讀性、可用材料與第五階段資源設計選定。現在不把已有Fashion-MNIST/FSDD失敗歷史擴寫成主線，也不把現成Qwen/Whisper當作從零小模型的隱藏答案器。

## 6. 建議閱讀順序：主線清楚，支線可選

本輪採「已有節號＋暫代號」而非直接改章號。第三階段確認新的小節內容後，才統一教材、Notebook、lesson-index、路線表與相互連結。

1. **看得見的文字問題**：W.2/W.3按需暖身→1章→2章→3章→4章。完成「同一段文字如何變成問題／答案並更新」；小程式不用等待整合成品。
2. **最小可靠實驗**：5.1、5.2、5.7–5.12為核心，5.16/5.17在混合／凍結前補足→6章核心。更新器細節和大規模比較不作為下一步硬門檻。
3. **會回應且能完成的有限助理**：先把7.17/7.18流程地圖放到SFT入口附近→7.1–7.11→I1–I5→7.12–7.16→8.5/8.6與9章核心。風格8.1–8.4/8.7可接着展開；LoRA、裁判與校準為選讀。
4. **輸入變長與必要線索**：14.1最少RoPE直覺→L1–L6；所需cache與注意力內存從16章按需補讀。RAG留為A支線，長上下文不等於把A全文強制搬入主線。
5. **真正需要圖／聲音的任務**：10.1–10.8→11.1–11.13→V/O短練習；12.1–12.10→H短練習→12.11–12.14。圖／聲可各自入門，12.12在兩者都學過後讀。

第13章保留兩種可選擇閱讀順序：先DPO13.1–13.9，或由7.18地圖先學評分員13.10，再學PPO13.11–13.16、最後13.17對照。不能把兩路排成最終成品必須依次執行的訓練流水線。
