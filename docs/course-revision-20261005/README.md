# 教材改版：先完成教學，再完成成品

本輪依使用者 2026-10-05確認的順序進行。最高標準是數學不錯的高中生或有基本數學能力的大學生能沿閱讀順序理解。本輪目標不是重做論文，而是把成熟知識教清楚，再用自行訓練的有限成品驗收整合。

## 六個階段

| 階段 | 工作 | 完成條件 |
| --- | --- | --- |
| 1 | 大綱、新增內容、知識來源與成品範圍 | 有保留／新增／拆分／延伸清單、微小節學習問題及來源支持，成品任務和驗收清楚 |
| 2 | 新增教材 | 新內容有完整說明、具體例子、必要圖解設計與適當的短示範，沒有把未做訓練寫成成果 |
| 3 | 既有教材改寫 | 正文與新內容連成一條閱讀路徑，移除工程流水，補足必要素材和圖解 |
| 4 | 審閱及修正 | 分段初讀、技術查證、前後銜接各完成，問題有實際處理；未檢查項目明確標記 |
| 5 | 模型工程與訓練 | 主線神經組件自行訓練，固定範圍內的文字、圖像、語音與工具逐項驗收，保存來源與權重 |
| 6 | 事實回填及發布 | 能力卡、操作頁、推論權重與實際實作一致，網頁及 Notebook 同源，重新估算閱讀時間 |

同一階段可分工。不同階段不混做：先寫完新內容，再改寫舊內容；先完成教材審閱，再開始新成品訓練。第五階段的結果主要更新能力與操作說明，不由一輪小模型的得分重寫業界知識。

## 教材與實驗的分工

成熟方法的用途、機制與限制依原論文及官方來源。簡短可手算或 CPU 操作的例子讓讀者看見一件事；長時間訓練另放操作頁。數字只在幫助理解時進正文，完整配方與歷史紀錄留作查證。

不再把以下事情混為一項「成功」：程式能運作、梯度能傳回、參數真的更新、模型會正常結束、答案內容正確、指定範圍與格式符合，以及未見素材上的能力。

文字與版面改動不觸發 GPU 重訓。模型、資料或行為宣稱改動時，僅執行相應驗收。小實驗未呈現來源論文的收益，要檢查條件，不能宣布成熟方法無用，也不捏造一致的實驗結果。

## 主線與延伸

主線沿用第 19 章從零建立小 MoE 的方向，擴充為少量可說清楚的實際情境。文字核心、視覺入口、語音入口與接頭的學習來源都必須可追蹤；固定的頻譜計算與計算工具是程式，不藏另一個成熟模型。

第 20 章 Qwen／Whisper 路線保留為「利用已有模型的延伸應用」。其上游能力不算作主線自己學會的成果，既有驗收也不改寫成新的自行訓練結果。
