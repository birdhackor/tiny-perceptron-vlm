# 小小感知機：從接話開始理解模型

輸入「今天天氣」，手機會提供幾種接法。程式怎麼猜下一個字？這套教材把問題縮到幾個字，讓你看見它如何整理例子、分配機率、衡量猜錯的代價，再修改自己的猜法。接著才逐步加入較長前文、對話、圖片、聲音與工具。

## R.1 先讀一節，不必先安裝

從[第一節：文字怎麼變成可還原的編號？](chapters/01.md#1.1)開始。材料是「貓看狗，狗看貓。」：先替字編號，再換回原句。你可以在紙上列字表，確認兩次「貓」使用相同編號，最後能還原原文。這件事弄清楚後，再看程式怎麼做。

網站上各節程式的下方都附有 CPU 實際執行的輸出，可以直接當書讀，不必安裝工具。想自己改數字再跑時，可以下載那一節的 Notebook（一份把文字與可執行程式放在一起的文件）在本機執行，或在 Colab 開啟同一份內容；Colab 需要 Google 帳號，雲端執行也還沒有經過本課實測。兩種方式的步驟見 [W.1](first-steps.md#W.1)。

不熟 Python 時，先看[W.2 的清單與字典](first-steps.md#W.2)。遇到數字表的形狀，再看[W.3](first-steps.md#W.3)。數學暖身可以隨用隨查；正文會在需要時解釋術語，你不用先背一份名詞清單，忘了某個詞再查[名詞頁](glossary.md)。

第一節讀完，可以試著解釋：為什麼同一個字需要固定編號？編號和字的意義有什麼不同？說得出來，就已經完成這一小步。

## R.2 依你想理解的問題選路

第一次接觸語言模型，先沿第 1–4 章閱讀：從出現次數猜字，改成可調數字，再學會查看前文，最後組成第一個 Transformer。這個名稱表示一種零件組合，等你看過它的做法，再記名字就很自然。

各主題也可以分開學。有時一張小數字表就能說明機制；討論圖片時，可以換成簡單圖卡。局部範例各自成立，最終整合專題才追蹤同一個模型如何接續學習。

## R.4 理解零件，再驗收整合

一個只有幾個數字的小例子，能讓你追蹤每一步。例如查表得到向量，再把向量混合成下一字的分數。它的價值是把機制看清楚；真正訓練時，再用許多例子反覆更新，並留下不參與更新的題目檢查能力。

譬喻幫我們找到起點，實際數字讓譬喻落地。例如[暖身 W.5](first-steps.md#W.5) 把加權和比作飲料配方，實際計算仍是逐項相乘再加總；這類說法不代表模型像人一樣理解內容。每節會指出眼前結果能支持哪件事，讓你逐步學會判讀。

模型中會隨訓練調整的數字稱為參數（parameter）；習慣上也把整組參數叫權重，例如保存它們的「權重檔」。第 19 章的三個成品——MoE 助理、Looped 解題器、機率判斷器——都由本課從隨機的初始參數開始，用我們提供的資料訓練，沒有借用別人已訓練好的參數。三者任務不同，先看[19.13](chapters/19.md#19.13)選路，再看[19.17](chapters/19.md#19.17)怎樣用 Auto 讓它們合作。它們只會少數教過的題型，也各有沒做好的地方；MoE 助理的能力與限制見[19.12](chapters/19.md#19.12)，下載與重做見[19.11](chapters/19.md#19.11)；另外兩個成品的實測見[19.20](chapters/19.md#19.20)，下載與版本核對見[19.19](chapters/19.md#19.19)。第 20 章則練習接手 Qwen、Whisper 這類別人已訓練好的成熟模型，和自己從零訓練的成品分開驗收。

後面各章會教很多方法，它們各自回答不同問題，有些還可以互相替代。第一次完成小助理，不必把每個方法都套一次：先看任務需要什麼，再選架構、訓練訊號與交付方式。各局部實驗的操作見[操作頁](training.md)。
